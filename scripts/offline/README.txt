인터넷이 막히거나 느린 교실에서 쓰는 묶음이에요. 사이트 전체(차시·용어사전·교사용 자료실),
파이썬 실행기(Pyodide와 OpenCV·numpy·Pillow), 손·얼굴·자세 인식 모델, ESP32 펌웨어, 글꼴,
작은 웹 서버가 모두 들어 있어서 인터넷 연결 없이 실습할 수 있어요.


1. 시작하기 (Windows 10·11)
────────────────────────────
  ① 받은 zip 파일을 오른쪽 단추로 눌러 [압축 풀기](또는 [모두 압축 풀기])를 해요.
     압축 파일 안에서 바로 실행하면 안 돼요. 꼭 먼저 풀어요.
  ② 풀린 폴더 안의 "시작하기.bat"를 두 번 눌러요.
     - 보안 경고 창("게시자를 확인할 수 없습니다" 또는 "Windows의 PC 보호")이 뜨면 [실행]
       (또는 [추가 정보] → [실행])을 눌러요. 인터넷에서 받은 파일이라 한 번 묻는 거예요.
       이 파일은 같은 폴더의 server\serve.ps1(작은 웹 서버)만 실행해요.
  ③ 검은 창(서버 창)이 열리고, 잠시 뒤 브라우저가 http://localhost:8080/ 을 열어요.
     8080번을 다른 프로그램이 쓰고 있으면 8081, 8082 …처럼 다음 번호로 열고, 창에 그 주소를 보여 줘요.
     시작하기.bat를 한 번 더 누르면 새 서버를 열지 않고, 켜져 있는 서버를 브라우저로 다시 열어요.
  ④ 수업하는 동안 검은 창을 닫지 마세요. 닫으면 사이트가 멈춰요(작게 줄여 두면 돼요).
     끝낼 때는 검은 창을 닫아요.

  - 브라우저는 Chrome이나 Edge 최신판을 권해요. 다른 브라우저가 열렸다면 검은 창에 보이는 주소를
    Chrome·Edge 주소창에 그대로 적어요.
  - 관리자 권한은 필요 없어요. 컴퓨터 설정을 바꾸지 않고, 설치하는 것도 없어요.
  - 이 서버는 이 컴퓨터 안에서만 열려요. 다른 컴퓨터에서는 접속할 수 없어요.
    교실의 컴퓨터마다 이 폴더를 복사해 각자 시작하기.bat를 실행해요(카메라·보드 연결은 "localhost"에서만 허락돼요).


2. 인터넷 없이 되는 것 · 안 되는 것
───────────────────────────────────
  되는 것
  - 배우기(차시 45편), 용어사전, 교사용 자료실(가린 편집본 PDF 포함), 사이트 검색
  - 영상처리 실습실: 웹캠(처음에 카메라 허용을 물어요), 샘플 입력, 내 그림 파일, 손·얼굴·자세 인식, 재생 입력
  - ESP32 실습실: 가상 보드와 부품, 블록 모드, 실제 보드 연결(USB 케이블 — Chrome·Edge), 펌웨어 굽기
  - 통신: "같은 컴퓨터 탭" 통로(대시보드, 4단원 통합 실습실, 두 탭 사이 통신), 블루투스(컴퓨터에 블루투스가 있을 때)
  - 가상 데스크톱(pyautogui), 음성 예제(글자 입력으로)

  안 되는 것(인터넷이 필요해요)
  - MQTT "공개 중계 서버"(대신 기본값인 "같은 컴퓨터 탭"을 써요)
  - 음성 예제의 "서버 인식"과 처음 쓰는 "기기 안 인식"(글자 입력은 늘 돼요)
  - 시작하기 > 점검 페이지의 인터넷 항목(jsDelivr·중계 서버 시험은 실패로 나와요 — 정상이에요)
  - 사이트 밖으로 가는 링크(GitHub, 라이선스 원문 주소 등)


3. 안 될 때
───────────
  - 압축을 풀 때 "경로가 너무 깁니다"·"파일 이름이 너무 깁니다"가 나와요
      → Windows는 폴더 경로가 아주 긴 곳에는 파일을 풀지 못해요. zip 파일을 바탕 화면이나 C:\ 바로 아래처럼
        짧은 곳으로 옮긴 뒤 다시 풀어요.
  - 실습실이 "ModuleNotFoundError"(cv2·numpy 같은 모듈이 없어요)라고 하거나 준비가 끝나지 않아요
      → 탐색기가 긴 경로의 파일을 말없이 빠뜨렸을 수 있어요. zip을 바탕 화면이나 C:\ 바로 아래로 옮겨 다시 풀고,
        시작하기.bat를 다시 실행해요(반디집·7-Zip으로 푼 깊은 폴더는 이 판의 서버가 그대로 열어요).
  - 인터넷이 끊긴 컴퓨터에서 SmartScreen(스마트스크린)을 쓸 수 없다는 창이 떠요
      → 받은 파일을 확인하는 Windows 기능이 인터넷에 닿지 못한 거예요. [실행]을 눌러요.
  - 검은 창이 잠깐 떴다가 사라지거나 "스크립트를 실행할 수 없습니다"가 보여요
      → 학교 보안 정책이 PowerShell 스크립트를 막은 거예요. 전산 담당 선생님께 이 폴더의
        server\serve.ps1 실행을 허락해 달라고 부탁하거나, 4절의 다른 방법을 써요.
  - "압축 파일 안에서 바로 실행한 것 같아요"
      → 압축을 모두 푼 뒤, 풀린 폴더의 시작하기.bat를 실행해요.
  - 브라우저에 "사이트에 연결할 수 없음"이 떠요
      → 검은 창이 열려 있는지, 창에 보이는 주소(포트 번호까지)와 같은지 확인해요.
  - 백신 프로그램이 경고해요
      → 이 폴더의 파일은 사이트 파일과 두 개의 작은 스크립트(server\serve.ps1, server\serve.py)뿐이에요.
        전산 담당 선생님과 함께 확인해 주세요.
  - 실습실이 "파이썬 엔진을 받지 못했어요"라고 해요
      → 검은 창이 닫히지 않았는지 보고, 페이지를 새로고침(F5)해요.
  - 다른 판의 오프라인판을 같은 주소로 썼다면, 주소 끝에 ?sw=off 를 붙여 한 번 열면 저장된 옛 파일을 지워요.


4. 다른 방법으로 시작하기
────────────────────────
  PowerShell이 막혔거나 macOS·Linux라면 파이썬 3(3.8 이상)으로 같은 서버를 열 수 있어요.

  - Windows(파이썬을 설치한 컴퓨터): 이 폴더에서 명령 프롬프트를 열고
        py server\serve.py
  - macOS·Linux: 터미널에서 이 폴더로 옮겨 가서
        python3 server/serve.py
    (브라우저가 열리지 않으면 http://localhost:8080/ 을 직접 열어요. 끝낼 때는 Ctrl+C)

  - 그 밖의 작은 웹 서버(예: miniserve)를 쓸 수도 있어요. 이때는 site 폴더를 내보내고, 주소는 꼭
    http://localhost:<포트>/ 로 열어요(다른 이름·다른 컴퓨터 주소로 열면 카메라·보드 연결이 막혀요).
    .wasm 파일은 application/wasm, .mjs·.js 파일은 text/javascript로 보내야 파이썬 실행기가 떠요.
    이런 도구는 이 묶음에 들어 있지 않아요 — 쓰려면 전산 담당 선생님과 공식 누리집에서 받아요.
