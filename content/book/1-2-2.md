## 학습 목표

- 검지 끝의 좌표로 선을 그리는 프로그램을 만들 수 있다.
- 키보드 입력 또는 손가락 움직임에 따라 선 그리기 기능을 켜고 끌 수 있는 프로그램을 만들 수 있다.

## 1 손 움직임 인식하기

스마트폰으로 게임을 하거나 화면을 이동할 때 손동작만으로 조종한 경험이 있을 것이다. 이제는 화면을 직접 터치 하거나 음성 명령을 사용하지 않아도 손짓만으로 기기를 제어하는 기술이 보편화되고 있다.

공중 제스처 기능을 활용하면 스마트폰 화면을 건드리지 않고도 전화를 받거나 음악을 바꿀 수 있으며, VR 게임에서는 컨트롤러 없이 손동작만으로 물건을 잡거나 다양한 기능을 쓰는 것이 가능하다. 이런 사례는 영상 인식 기술이 일상생활 속에 점점 자연스럽게 스며들고 있음을 잘 보여 준다.

:::용어풀이[공중 제스처(in-air Gestures)]
허공에서 손동작으로 컴퓨터나 스마트폰과 같은 기기를 조작하는 기술을 뜻한다. 사용자와 기기 간 상호 작용을 위한 수단 중 하나이다.
:::

그렇다면 기기는 어떻게 우리의 손동작을 이해하고 반응할 수 있을까? 이 모든 기능이 가능한 이유는 바로 :용어[컴퓨터 비전] 기술 때문이다. 컴퓨터 비전은 사람의 눈처럼 카메라로 들어온 영상을 분석해 얼굴이나 손 모양을 인식하고, 움직임을 추적해 디지털 명령으로 바꾼다. 특히 최근에는 인공지능과 결합하면서 단순한 영상 분석을 넘어 사람의 행동을 예측하거나 특정 제스처에 반응하는 지능형 시스템으로 발전했다.

:::그림생략[교과서 33쪽 사진: 휴대폰 화면을 손으로 조작하는 모습]
왼쪽 휴대폰에는 손가락이 화면의 사진을 누르는 모습이, 오른쪽 휴대폰에는 손이 화면을 옆으로 밀어 다음 사진(산 풍경)으로 넘기는 모습이 보이는 사진 두 장이에요. 저작권 때문에, 그리고 사람의 얼굴이 나와 이 사이트에는 싣지 못했어요. 책 33쪽에서 보세요.
:::

실제로 이러한 시스템을 구현하기 위해서는 손이나 얼굴처럼 움직이는 대상을 정확히 인식하고, 그 위치나 형태를 수치화하는 과정이 필요하다. MediaPipe와 같은 도구를 활용하면 웹캠을 통해 입력된 영상을 분석해 손가락 관절 위치를 추적하고 이를 실시간 좌표로 변환하는 것이 가능하다.

::쪽[34]

다만, 이때 주의해야 할 점은 영상을 처리할 때 사용하는 :용어[픽셀 좌표계]와 수학 시간에 배우는 좌표 평면 구조가 다르다는 점이다. 수학에서는 원점이 왼쪽 아래에 있고 Y축이 위쪽으로 증가하지만, 컴퓨터의 픽셀 좌표계는 원점이 왼쪽 위에 있고 Y축이 아래쪽으로 증가한다.

**수학 좌표계와 픽셀 좌표계**

![수학 좌표계 그림. y축이 위쪽으로, x축이 오른쪽으로 늘어나는 좌표 평면에서 원점 (0, 0)은 왼쪽 아래, 점 (3, 1)은 오른쪽 위에 있다](/images/lessons/1-2-2/book-math-coordinates.webp "교과서 34쪽")

▲ 수학 좌표계

![픽셀 좌표계 그림. 모니터 화면의 왼쪽 위 모서리가 화면 좌표 (0, 0)이고 오른쪽으로 x축, 아래쪽으로 y축이 늘어나며 마우스 좌표 (x, y)가 화면 안에 표시되어 있다](/images/lessons/1-2-2/book-pixel-screen-coordinates.webp "교과서 34쪽")

▲ 픽셀 좌표계

| 구분 | 수학 좌표계 | 픽셀 좌표계(OpenCV) |
| --- | --- | --- |
| 원점 위치 | 중앙(0, 0) | 왼쪽 위(0, 0) |
| X축 방향 | 오른쪽으로 증가 | 오른쪽으로 증가 |
| Y축 방향 | 위쪽으로 증가 | 아래쪽으로 증가 |

또 MediaPipe가 제공하는 손가락 위치는 0과 1 사이의 :용어[상대 좌표]이므로, 이를 실제 화면 크기에 맞게 픽셀 좌표로 변환해야 한다.

예를 들어, 상대 좌표가 (1, 1)이고 화면 해상도가 1280×800이라면 변환된 픽셀 좌표는 (1280, 800)이 된다.

**픽셀 좌표 변환하기**

```python
h, w, _ = frame.shape      # h: 높이(세로), w: 너비(가로)
x_pixel = int(landmark.x * w)      # X축 변환
y_pixel = int(landmark.y * h)      # Y축 변환
```

수학에서 두 점을 연결해 선을 그리는 것처럼 OpenCV에서는 'cv2.line()' 함수를 사용해 두 점을 선으로 연결할 수 있다.

**점을 선으로 연결하기**

```python
cv2.line(img, (x1, y1), (x2, y2), color, thickness)
```

❷ 손가락 끝이 상대 좌표 (0, 0)에서 (1, 1)로 이동하면 선은 어떤 방향으로 그려질지 예상해 보자.

## 2 손 움직임 인식하기 프로그램 개요

이번 실습에서는 인공지능 기반 손 인식 기술을 활용하여 검지 끝의 움직임을 실시간으로 추적해 그 경로를 화면에 선으로 표시하는 프로그램을 만들어 본다.

MediaPipe Hands는 손의 각 관절 위치를 0\~1 사이의 상대 좌표로 제공하며, 이 좌표를 화면 해상도에 맞춰 픽셀 단위로 변환한 후, OpenCV의 'cv2.line()' 함수를 이용해 이동 경로를 선으로 연결한다. MediaPipe Hands에서 검지는 관절 번호 5(기저부)부터 8(손끝)까지로 구성되는데, 관절 번호 8번을 활용하면 검지 끝의 움직임을 따라 선을 그릴 수 있다.

이번 실습에서는 이 과정을 단계적으로 구현하면서 손가락 움직임을 디지털 선으로 표현하는 원리를 이해하게 된다. 또한, 영상 속 좌표계와 수학에서 배우는 좌표계의 차이점도 비교하며 학습한다. 좌표계 이해는 단순히 선을 그리는 데 그치지 않고, 추후 제스처 인식이나 :용어[인터페이스] 제어와 같은 확장된 응용에도 중요한 요소가 된다.

## 기본 실습 | 검지로 공중에서 그림 그리기

OpenCV와 MediaPipe를 활용하여 손의 움직임을 인식하고, 검지 끝 위치를 실시간으로 추적해 화면 위에 선을 그리는 프로그램을 만들어 보자.

웹캠을 통해 입력된 영상은 프레임 단위로 처리되며, 손가락이 움직인 경로를 따라 선이 그려진다. 마치 공중에 그림을 그리듯 화면을 직접 터치하지 않아도 허공에서 손가락만으로 자유롭게 드로잉할 수 있다.

:::용어풀이[드로잉(Drawing)]
컴퓨터 프로그래밍에서 드로잉은 단순히 예술적인 '그림 그리기'를 뜻하는 것이 아니라 화면 위에 선, 도형, 글자 등을 그리는 작업을 말한다.
:::

### 단계 1 | 라이브러리 불러오기 및 설정하기
```python {start=1}
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import numpy as np

# 손 인식 설정하기
mp_hands = mp.solutions.hands
hands = mp.solutions.hands.Hands()

# 변수 초기화하기
canvas = None
prev_x, prev_y = 0, 0
```
:::코드설명
- **줄 2** OpenCV 라이브러리 불러오기
- **줄 3** MediaPipe 라이브러리 불러오기
- **줄 4** NumPy 라이브러리 불러오기
- **줄 7** 손 인식 모듈 불러오기
- **줄 8** 손 인식 객체 생성
- **줄 11** 손 그림을 위한 빈 이미지(캔버스)
- **줄 12** 이전 좌표 초기화
:::

### 단계 2 | 웹캠 연결 및 프레임 전처리하기
```python {start=13}
# 웹캠 연결하기
cap = cv2.VideoCapture(0)

# 프레임 읽기
while True:
    ret, frame = cap.read()
    if not ret:
        break

# 화면 변환 처리하기
    frame = cv2.flip(frame, 1)
    h, w, _ = frame.shape
    if canvas is None:
        canvas = np.zeros_like(frame)

# 색상 변환 및 손 인식 처리하기
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    result = hands.process(rgb)
```
:::코드설명
- **줄 14** 웹캠 연결
- **줄 18** 프레임 읽기
- **줄 19** 프레임 읽기 실패 시 종료
- **줄 23** 좌우 반전(거울처럼 보이기)
- **줄 24** 프레임의 높이, 너비 정보 추출
- **줄 26** 초기 캔버스 설정
- **줄 29** BGR을 RGB로 변환
- **줄 30** 손 인식 수행
:::

:::말풍선
'np.zeros_like(frame)'은 현재 프레임과 같은 크기의 검은 화면(캔버스)을 만들어 그림을 그릴 수 있도록 해.
:::

::쪽[37]

### 단계 3 | 손 위치 추적하여 선 그리기
```python {start=31}
    if result.multi_hand_landmarks:
        lm = result.multi_hand_landmarks[0].landmark
        x, y = int(lm[8].x * w), int(lm[8].y * h)

# 선 그리기
        if prev_x != 0 and prev_y != 0:
```

- **줄 33** 검지 끝 좌표
- **줄 36** 이전 좌표가 있으면
- **줄 37** 선 그리기
- **줄 38** 다음 선을 그리기 위해 현재 좌표 저장
- **줄 40** 손이 없을 경우 값 초기화

## 심화 실습 | 검지 드로잉 제어 기능 추가하기

손가락 움직임으로 그림을 그리는 프로그램으로, 기본 실습 기능에 드로잉을 제어하는 기능을 추가해 보자.

기본 실습에서는 손가락이 인식되면 자동으로 선이 그려졌지만, 주먹을 쥐고 있어도 선이 생기거나 원치 않을 때에도 계속 그림이 그려지는 문제가 있었다. 심화 실습에서는 'd' 키를 눌러 그리기 기능을 켜고 끌 수 있도록 제어 기능을 추가함으로써 이러한 문제를 해결한다.

:::말풍선
해당 프로그램에서는 손가락을 펼쳤을 때만 그림이 그려지고, 키보드로 ON/OFF 제어와 초기화, 색상 전환 등으로 확장이 가능하도록 할 거야.
:::

### 단계 1 | 라이브러리 불러오기 및 설정하기
```python {start=1}
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import numpy as np

# 손 인식 모듈 초기화하기
mp_hands = mp.solutions.hands
hands = mp_hands.Hands()

# 선 그릴 캔버스 및 이전 좌표 초기화하기
canvas = None
prev_x, prev_y = 0, 0
drawing_enabled = False
```
:::코드설명
- **줄 2** OpenCV 라이브러리 불러오기
- **줄 3** MediaPipe 라이브러리 불러오기
- **줄 4** NumPy 라이브러리 불러오기
- **줄 7** 모듈 변수 할당
- **줄 8** 한 손 인식 객체 생성
- **줄 11** 손가락 궤적을 그릴 캔버스
- **줄 12** 이전 프레임의 좌푯값 초기화
- **줄 13** 'd' 키로 그리기 모드 on/off
:::

:::말풍선
'drawing_enabled' 변수를 'False'로 초기화하여 사용자가 원하는 경우에만 그림을 그릴 수 있도록 on/off 기능을 추가했어.
:::

### 단계 2 | 프레임 캡처 및 전처리 하기
```python {start=14}
# 웹캠 열기
cap = cv2.VideoCapture(0)

# 프레임 반복 읽기
while True:
    ret, frame = cap.read()
    if not ret:
        break

# 화면 변환 처리하기
    frame = cv2.flip(frame, 1)
    h, w, _ = frame.shape
    if canvas is None:

# 색상 공간 변환 및 손 관절 추적하기
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    result = hands.process(rgb)
```

- **줄 15** 웹캠 연결
- **줄 19** 웹캠 프레임 읽기

- **줄 24** 좌우 반전 (거울처럼 보이기)
- **줄 25** 프레임 크기 정보 추출
- **줄 27** 초기 캔버스 설정
- **줄 30** BGR을 RGB로 변환

### 단계 3 | 손 추적 및 선 그리기
```python {start=32}
# 손이 감지되었을 때
    if result.multi_hand_landmarks:
        lm = result.multi_hand_landmarks[0].landmark

# 검지 좌표 추출(픽셀 좌표로 변환)
        x = int(lm[8].x * w)
```

### 단계 4 | 결과 출력 및 종료 처리하기
```python {start=49}
# 실시간 영상과 캔버스를 합성해 출력하기
    output = cv2.addWeighted(frame, 0.5, canvas, 0.5, 0)
    cv2.imshow("Draw (Toggle: d)", output)

    if key == ord('q'):
```

:::학습활동[인공지능을 활용한 손 인식 프로그램 확장하기]
완성한 프로그램을 바탕으로 검지 드로잉 기능을 다양한 방식으로 확장해 보고, 그 결과를 비교하며 표현의 다양성과 정확도 측정 방법을 탐색해 보자.

1. 키보드의 'r', 'g', 'b' 키 입력에 따라 선 색상이 실시간으로 변경되도록 프로그램을 수정해 보자.

   예 'r' 키 → 빨강, 'g' 키 → 초록, 'b' 키 → 파랑

2. 화면에 '별', '하트', '원' 등 그림을 제시하고, 손으로 따라 그려서 기준 그림과 얼마나 비슷하게 그렸는지를 수치로 평가해 보자.

3. 손가락의 z축 거리 좌푯값을 이용하여 카메라에 가까우면 선이 굵어지고, 멀어지면 선이 얇아지도록 두께를 자동 조절해 보자.

4. 그림 그리기를 완료한 뒤 키보드로 저장 명령을 눌러 자신이 그린 그림을 이미지 파일로 저장하는 기능을 추가해 보자.
