**문제로 점검**

**1** 다음은 ‘얼굴 인식 제어 시스템’의 동작 원리를 순서와 관계 없이 나열한 것이다. 정보 처리 과정에 따라 올바르게 배열한 것은?

(가) ESP32가 블루투스로 수신한 좌푯값에 따라 서보모터를 움직여 레이저 포인터의 방향을 조절한다.

(나) MediaPipe 라이브러리가 웹캠 영상에서 얼굴 특징점을 분석하여 머리의 움직임을 x, y 좌표로 변환한다.

(다) 컴퓨터에 연결된 웹캠이 사용자의 얼굴을 실시간으로 촬영하여 영상 프레임을 생성한다.

(라) 계산된 좌표와 클릭 신호를 블루투스를 통해 무선으로 ESP32에 전송한다.

- ① (가) - (다) - (나) - (라)
- ② (다) - (나) - (라) - (가)
- ③ (나) - (라) - (가) - (다)
- ④ (다) - (가) - (라) - (나)
- ⑤ (라) - (나) - (다) - (가)

**2** 지능화 사물 개발 프로젝트에서 사용된 핵심 라이브러리와 그 역할에 대한 설명으로 가장 적절하지 않은 것은?

- ① OpenCV: 웹캠으로부터 실시간 영상 프레임을 입력받는 등 전반적인 영상 처리를 담당한다.
- ② MediaPipe: 구글에서 개발한 AI 기술로, 영상 속에서 얼굴을 탐지하고 478개의 정교한 랜드마크(특징점)를 추적한다.
- ③ PyAutoGUI: 사용자의 눈 깜빡임이나 머리 움직임 신호를 바탕으로 PC의 마우스 커서를 자동으로 움직이거나 클릭을 실행한다.
- ④ 블루투스: PC에서 분석된 얼굴 특징점 좌표를 아두이노로 작성된 프로그램에 유선으로 전송하여 안정성을 높인다.
- ⑤ 마이크로파이썬: 하드웨어인 ESP32를 제어하는 데 사용되며, 블루투스로 수신한 데이터를 처리하여 서보모터를 작동시키는 역할을 한다.

**3** 다음은 얼굴의 움직임을 실제 마우스 좌표로 변환하는 핵심 파이썬 코드이다. 코드에 대한 분석으로 옳은 것을 있는 대로 고른 것은?

```python
# 기준점으로부터 얼마나 움직였는지 계산
move_x = eye_center_x - reference_center[0]
move_y = eye_center_y - reference_center[1]
# 얼굴 움직임을 화면 좌표로 변환
mouse_x = move_x / face_move_range_x
    * screen_width + screen_width // 2
mouse_y = move_y / face_move_range_y
* screen_height + screen_height // 2
# 마우스를 계산된 위치로 이동
pyautogui.moveTo(int(mouse_x), int(mouse_y))
```

(가) ‘reference_center’는 프로그램 시작 시 고정된 (0, 0) 좌표를 의미한다.

(나) ‘face_move_range_x’ 변수의 값을 작게 설정하면 마우스가 더 민감하게 반응한다.

(다) ‘screen_width // 2’를 더하는 것은 화면 좌표의 기준점을 왼쪽 위 (0, 0)에서 화면 중앙으로 옮기기 위함이다.

(라) ‘pyautogui.moveTo()’ 함수는 MediaPipe 라이브러리에 포함된 함수 중 하나이다.

- ① (가), (나)
- ② (나), (다)
- ③ (다), (라)
- ④ (가), (다), (라)
- ⑤ (나), (다), (라)

**4** 이 프로젝트에서 PC와 ESP32 간의 블루투스 통신을 위해 설계한 프로토콜(통신 규칙)에 대한 설명으로 가장 적절한 것은?

- ① 데이터의 시작을 알리기 위해 헤더 역할을 하는 “START” 문자열을 사용한다.
- ② x 좌표, y 좌표, 클릭 신호를 각각 독립적인 블루투스 채널로 동시에 전송한다.
- ③ 모든 데이터를 하나의 문자열로 합치고, 각 데이터는 쉼표(,)를 기준으로 구분하여 전송한다.
- ④ 데이터의 신뢰성을 높이기 위해 JSON 형식을 사용하여 “x”: 367, “y”: 323과 같이 키와 값으로 구성된 데이터를 전송한다.
- ⑤ ESP32가 PC의 블루투스 주소를 찾아 직접 연결을 요청하는 방식으로 통신을 시작한다.

**5** 다음은 ESP32가 블루투스로 수신한 데이터 data를 처리하는 마이크로파이썬 코드의 일부이다. 다음 코드가 실행된 후, 변수 ‘mouse_y’에 저장되는 값으로 옳은 것은?

```python
data = "DATA,480,275,1,0"
mouse_x = 0
mouse_y = 0
```

```python
f data:
  try:
    parts = data.split(',')
    if len(parts) == 5 and parts[0] == "DATA":
      mouse_x = int(parts[1])
      mouse_y = int(parts[2])
      double_click = int(parts[3])
      right_click = int(parts[4])
  except:
    pass
```

:::웹정정[f data:]
출판본 291쪽 5번 문제의 코드 첫 줄은 `f data:`로 인쇄돼 있어요. 파이썬에서는 `if data:`라고 써야 해요(앞의 i가 빠진 오타). 원문은 그대로 두었어요.
:::

- ① 0
- ② 1
- ③ 275
- ④ 480
- ⑤ DATA

**프로그래밍으로 점검**

**6** 다음은 영상 처리 인공지능을 종료하거나 기준점을 재설정하는 기능을 하는 코드이다. ‘q’ 키뿐만 아니라 ESC키(27)를 눌렀을 때에도 프로그램이 종료되게 하려면 코드를 어떻게 수정해야 하는지 빈칸을 채우시오.

```python
key = cv2.waitKey(5) & 0xFF
if key == ord('q'):
    break
elif key == ord('r'):
    reset_all_variables()
    print("기준점 재설정...")

if key in (________________): # 27 = ESC
    break
```

6 27, ord(‘q’)

7 `mouse_x`, `mouse_y`

**1** 웹캠을 통해 사용자의 얼굴을 실시간으로 입력받고, MediaPipe로 얼굴의 특징점을 인식한 뒤 화면의 x, y 좌푯값을 블루투스로 ESP32에 전송한다. ESP32는 전송받은 x, y 좌푯값으로 출력 장치를 제어하게 된다.

**2** 블루투스는 근거리 장치 사이의 통신을 무선으로 주고받는 방법이다.

**3** 화면의 중앙을 중심점으로 잡으면 사람의 얼굴을 항상 중심점에 맞추어야 하는 불편함이 생긴다. 따라서 고정된 좌표로 잡지 않고, 처음 화면에 인식된 얼굴의 위치를 가변적인 좌표인 ‘reference_center’로 잡는다. ‘pyautogui.moveTo()’ 함수는 파이썬 라이브러리로 컴퓨터의 그래픽 유저 인터페이스(GUI)를 제어할 수 있게 해 주는 라이브러리이다.

**4** PC와 하드웨어 사이에 전송할 데이터가 여러 개인 경우 데이터 전송 포맷을 정해 주어야 하므로, 데이터 사이에 쉼표(,)를 기준으로 구분하여 전송한다.

**5** 받은 데이터를 쉼표(,)로 쪼개고, 데이터의 길이가 5이면서 0번째 데이터가 ‘DATA’인 경우이다. 따라서 1번째 데이터는 ‘mouse_x’에 저장하고, 2번째 데이터는 ‘mouse_y’에 저장하므로 정답은 275가 된다.

**6** 이 코드는 사용자가 누른 키값이 ‘q’의 아스키코드인 ‘113’이거나 ESC의 코드인 ‘27’일 때 프로그램을 종료하도록 하는 명령이다. 즉, if key in (ord(‘q’), 27): 조건이 참이 되면 break가 실행되어 반복문이 끝나고 프로그램이 종료된다.

**7** 사전에 약속한 전송 포맷은 ‘DATA’라는 접두어 뒤에 마우스의 x 좌표, y 좌표, 그리고 더블 클릭 여부와 우클릭 여부를 순서대로 붙여 보내는 방식이다. 따라서 빈칸에는 마우스 좌푯값인 mouse_x, mouse_y가 들어가야 한다.
:::
