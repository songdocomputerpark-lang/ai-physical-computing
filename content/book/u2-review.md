**12** 다음 코드는 ESP32에서 네오픽셀을 제어하여 LED 8개를 빨강-초록-파랑 순서로 반복 점등하는 프로그램이다. 빈칸에 들어갈 알맞은 코드를 쓰시오.

```python
import machine, neopixel, time
np = neopixel.NeoPixel(machine, Pin(5), ___①___)
colors = [(255, 0, 0), (0, 255, 0), (0, 0, 255)]
while True:
    for i in range(np, n):
        color = colors[i % ___②___]
        np[i] = color
    np.___③___()
    time.sleep(0.5)
```

:::웹정정[12번 코드와 13번 줄 번호]
출판본 181쪽 12번 코드는 `neopixel.NeoPixel(machine, Pin(5), …)`와 `range(np, n)`으로 적혀 있어요. 그대로는 실행되지 않고, 뜻은 `machine.Pin(5)`와 `range(np.n)`에 가까워요. 13번 코드의 줄 번호는 7번 다음에 4, 5, 6으로 되돌아가요(8~10번이어야 해요). 원문 글자는 그대로 두고 줄 번호만 이어서 달았어요.
:::

**13** 다음은 ESP32에서 버저를 이용하여 도-레-미 음계를 차례대로 0.5초씩 연주하는 코드이다. 빈칸에 들어갈 알맞은 코드를 쓰시오.

```python
from machine import Pin, PWM
import time
buzzer = PWM(Pin(15))
notes = [262, 294, 330]
for n in notes:
    buzzer.freq(___①___)
    buzzer.duty(512)
    time.sleep(0.5)
    buzzer.___②___(0)
    time.sleep(0.1)
```

**피지컬 컴퓨팅** 180\~181쪽

**문제로 점검**

1 ⑤ 2 ③ 3 ② 4 ② 5 ⑤ 6 ⑤ 7 SDA, SCL 8 ⑤ 9 ③ 10 R, G, B (Red, Green, Blue) 11 속도를 세밀하게 조절할 수 있다.

**프로그래밍으로 점검**

12 ① 8, ② 3, ③ write

13 ① n, ② duty

**1** 센서는 주변 환경 정보를 감지(입력)해 전기적 신호로 변환한다.(예: 온도, 거리, 터치) 액추에이터는 소프트웨어의 제어 명령을 물리적 동작(출력)으로 바꾼다.(예: 모터 회전, LED 발광, 버저 음 출력)

**2** OLED는 각 화소가 스스로 빛을 내기에 백라이트가 필요없다. 결과적으로 명암비가 높고, 어두운 화면에서 저전력이다.

**3** 둘 다 광(빛) 출력이라는 공통점을 가진다.

**4** ESP32의 GPIO 핀 제어는 Pin 객체를 생성한 뒤 value() 메서드를 통해 값을 제어한다.

- led.value(1) → LED 켜기
- led.value(0) → LED 끄기

**5** WS2812B 계열은 단일 데이터 라인으로 여러 LED를 직렬 연결하고, 프레임 내 각 픽셀 데이터를 순차 전달해 개별 색 제어가 가능하다.

**6** 피에조 버저는 주파수에 따라 진동하며 음이 달라진다.

**7** SDA(Serial Data), SCL(Serial Clock)이 I2C의 기본 2선이다.

**8** 서보모터는 PWM 신호를 이용해 특정 각도로 정밀 제어가 가능하다. 일반 DC 모터(①)보다 속도가 중요한 것이 아니고, 진동모터(②)는 진동용, 서보모터는 보통 0\~180도(④ 아님) 범위에서 동작한다.

**9** 팬 모터의 속도는 전압의 세기에 따라 달라지는데, ESP32에서는 디지털 신호로 아날로그 효과를 내는 PWM 방식을 활용한다. 듀티 사이클을 조절하면 팬의 회전 속도를 조절할 수 있다.

**10** 대부분의 라이브러리는 RGB이다.(일부 하드웨어는 내부 전송 순서가 GRB이지만 논리 채널은 RGB로 취급함.)

**11** 단순한 ON/OFF는 ‘최대 속도’와 ‘정지’만 가능하지만, PWM을 사용하면 듀티 사이클을 바꿔 다양한 속도 제어가 가능하다.

**12**

- ① neopixel.NeoPixel()의 두 번째 인자는 LED 개수를 의미한다.
- ② 색상 리스트 colors는 길이가 3이므로 i % 3을 통해 빨강-초록-파랑이 반복된다.
- ③ 네오픽셀은 값을 넣은 후 반드시 np.write()를 호출해야 LED가 실제로 켜진다.

**13**

- ① buzzer.freq()에서 괄호 안에는 재생할 음계의 주파수를 넣어야 하므로, 리스트에서 꺼낸 값 n이 들어가야 한다.
- ② 음계 출력을 잠깐 중단하려면 buzzer.duty(0)을 사용한다.
:::
