**1** 시리얼 통신에서 기본적으로 연결되는 두 신호선으로 옳은 것은?

- ① TX, RX
- ② CLK, CS
- ③ SDA, SCL
- ④ VCC, GND
- ⑤ MOSI, MISO

**2** 인공지능 프로그램에서 숫자 1과 문자 ‘1’을 구분해야 하는 이유로 옳은 것은?

- ① 저장 방식이 다르다.
- ② 전송 속도가 다르다.
- ③ 저장 장치의 용량이 다르다.
- ④ 아스키코드 값이 서로 다르다.
- ⑤ 이미지 처리 시 오류가 발생한다.

**3** ESP32에서 UART2를 사용하는 이유로 옳은 것은?

- ① UART2는 속도가 더 빠르다.
- ② UART1은 블루투스 전용이다.
- ③ UART0은 전원 공급 전용이다.
- ④ UART0은 Thonny와 연결되어 있다.
- ⑤ UART2는 자동으로 포트를 찾아준다.

**4** 인공지능과 하드웨어 통신에서 전송 주기를 조절해야 하는 이유로 옳은 것은?

- ① 데이터가 큰 이미지 파일로 변환된다.
- ② 전송 주기를 늘리면 전력 소모가 증가한다.
- ③ 전송 주기를 줄이면 데이터 보안이 강화된다.
- ④ ESP32가 자동으로 주기를 최적화하지 못한다.
- ⑤ 버퍼에 데이터가 과도하게 쌓여 지연이 발생할 수 있다.

**5** 데이터 전송 시 줄바꿈 문자(\n)를 붙이는 이유로 옳은 것은?

- ① 데이터를 압축한다.
- ② 전송 용량을 줄인다.
- ③ 속도를 빠르게 한다.
- ④ 무선 신호를 강화한다.
- ⑤ 메시지의 끝을 표시한다.

**6** 시리얼 통신에서 PC와 보드가 데이터를 교환하기 위해 반드시 일치해야 하는 것으로 옳은 것은?

11 ① write ② encode 12 120 250 13 x < 100

**1**

- ①외 나머지 선택지는 다른 통신 방식의 신호선임.
- ② SPI 통신에서 사용
- ③ I2C 통신에서 사용
- ④ 전원 공급선
- ⑤ SPI 통신

**2** 문자 ‘1’은 아스키코드 값 49(0x31), 숫자 1은 1(0x01)로 저장된다. 즉 문자와 숫자는 내부적으로 다른 바이트 값으로 구분된다.

**3** UART0는 Thonny 실행·출력용으로 기본 사용된다. 따라서 사용자 통신을 위해 UART2를 활용한다.

**4** 인공지능 프로그램이 무한 반복으로 계속 데이터를 보내면 ESP32 입력 버퍼에 데이터가 쌓여 지연(delay)이 발생한다. 따라서 전송 주기를 조절해야 한다.

**5** 줄바꿈 문자는 하나의 메시지 끝을 알려주어 데이터를 구분할 수 있게 한다.

**6** 보드와 PC의 통신 속도가 일치해야 올바른 통신이 가능하다.

**7** ble.read()는 새 데이터가 없으면 None을 반환한다. ③, ④는 보통 None이 아니라 깨진 데이터나 예외로 나타난다.

**8** bleak는 파이썬에서 BLE 장치와 무선 통신을 가능하게 하는 라이브러리다.

**9** [예시 답안] 전원이 켜지거나 보드가 리셋될 때 가장 먼저 실행되는 시작 파일로, 통신 설정이나 초기화 코드를 자동으로 실행한다.

**10** [예시 답안] PC와 보드가 올바르게 연결된 포트를 지정해야 데이터 송수신이 가능하기 때문이다. 잘못된 포트를 설정하면 통신이 이루어지지 않기 때문이다.

**11** write()로 전송, 문자열을 바이트로 변환하려면 .encode(‘utf-8’) 필요하다.

**12** 문자열 ‘120, 250\n’에서 개행을 제거하고 쉼표로 분리해 120과 250으로 정수 변환하여 120 250을 출력한다.

**13** 문자열 ‘80, 200\n’을 분리해서 x = 80, y = 200을 얻고, 조건 x < 100이 참이므로 ‘LED ON’을 출력한다.
