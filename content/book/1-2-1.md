## 1 웹캠으로 영상 인식하기

사람은 언어 외에도 표정이나 손동작과 같은 움직임을 통해 감정이나 의도를 전달한다. 최근에는 이런 움직임을 컴퓨터가 인식하고 반응하는 기술이 발전하면서 손동작이나 몸짓으로 기기를 조작하는 모습을 흔히 볼 수 있다. 기계가 단순히 명령을 수행하는 단계를 넘어 사람과 더욱 자연스럽게 상호작용하는 방향으로 나아가고 있는 것이다.

우리가 매일 사용하는 스마트폰에도 실제 이러한 기술이 적용되고 있다. 인물 모드, 얼굴 인식, 필터 기능 등 다양한 영상 인식 기능이 스마트폰에 들어있어 사용자의 표정이나 위치를 인식해 자동으로 화면을 조정하거나 실시간으로 시각적 효과를 적용할 수 있다. 사진을 찍을 때 얼굴에 초점을 맞추거나 얼굴 위치를 추적해 강아지 귀와 같은 재미있는 효과를 덧입히는 것도 이러한 기술을 활용한 예이다.

:::용어풀이[필터 기능]
사진이나 영상의 색감, 톤, 분위기를 원하는 스타일로 변경하여 더욱 매력적으로 만드는 기능이다.
:::

▲ 영상 인식 기술 활용 예

영상 인식 기술은 영화 속에서도 자주 등장한다. 슈퍼히어로 영화에서 주인공이 특수 슈트를 착용한 채 허공에 3D 영상을 띄워놓고 다양한 정보를 확인하거나, 손짓이나 음성 명령만으로 기기를 조작하는 장면을 본 적이 있을 것이다. 실제로 OpenCV나 MediaPipe와 같은 인공지능 :용어[라이브러리]를 활용하면 특별한 장비 없이 일반적인 웹캠만으로도 얼굴이나 손, 몸의 움직임을 실시간으로 인식할 수 있다.

::쪽[26]

MediaPipe의 Hands 모듈은 손의 위치를 감지하고, 손가락 관절의 :용어[랜드마크]를 추출하는 기능을 제공한다. 랜드마크를 선으로 연결해 손의 형태를 시각적으로 표현할 수 있으며, 이를 활용해 키보드 입력이나 마우스 조작, 음량 조절 등 다양한 동작 제어가 가능하다. 이러한 기능들을 구현하기 위해서는 먼저 Hands 모듈에서 제공하는 주요 함수들의 동작 원리를 이해하는 것이 중요하다.

**Hands() 함수** 손을 인식하고 랜드마크를 추출하는 객체를 생성하는 함수다. 다음과 같이 설정 값을 지정할 수 있다.

- static_image_mode: 정지 이미지(True) 또는 실시간 영상(False) 중 어떤 방식으로 손을 감지할지 설정한다.
- max_num_hands: 동시에 감지할 손의 최대 개수를 설정한다.
- min_detection_confidence: 감지 결과에 대한 신뢰도 기준(0\~1)을 설정한다. 값이 클수록 확신이 높을 때만 손을 인식한다.

:::용어풀이[BGR과 RGB 색상 형식]
BGR과 RGB는 디지털 이미지에서 색상을 표현하는 두 가지 방식이다. RGB는 빨강(Red), 초록(Green), 파랑(Blue) 순서로 색상 정보를 저장하는 방식이고, BGR은 파랑(Blue), 초록(Green), 빨강(Red) 순서로 저장하는 방식이다. OpenCV는 BGR 형식을 사용하지만 MediaPipe는 RGB 형식을 사용하므로, 두 라이브러리를 함께 사용할 때는 색상 형식을 변환해 주어야 정확한 색상 처리가 가능하다.
:::

**process() 함수** 입력된 이미지를 분석하여 손이 있는지 확인하고, 손의 랜드마크 좌표를 반환한다. 일반적으로 이미지는 OpenCV의 BGR 형식을 RGB 형식으로 변환한 후 사용해야 하며, 반환되는 좌표 정보는 다음과 같다.

**반환 좌표 정보**

```text
landmark {
    'x': 0.52    # 화면 가로 위치(0: 왼쪽, 1: 오른쪽)
    'y': 0.60    # 화면 세로 위치(0: 위쪽, 1: 아래쪽)
    'z': -0.03   # 카메라로부터의 상대 거리(음수: 가까움, 양수: 멀어짐)
}
```

**draw_landmarks() 함수** 인식된 랜드마크 좌표와 연결선을 이미지 위에 시각적으로 표시하며, 이미지를 직접 수정하고 반환값은 없다.

:::해보기[화면 속 손 모양이 만들어지는 원리 이해하기]

## 2 웹캠으로 영상 인식하기 프로그램 개요

이번 실습에서는 OpenCV를 활용해 웹캠 영상을 화면에 출력하고, MediaPipe Hands로 손가락 관절 위치를 인식한 뒤 선으로 연결하는 활동을 진행한다. :용어[프레임] 좌우 반전, 화면 출력, 종료 조건 설정 등 OpenCV의 주요 영상 처리 기능을 익히면서 웹캠과 연동되는 프로그램의 구조도 함께 이해하게 된다.

MediaPipe Hands는 손의 움직임을 시각화하고, 손가락 관절 좌표를 자동으로 인식해 연결선을 그릴 수 있는 기능을 제공한다. 이러한 좌표 정보를 활용하면 손의 위치나 제스처를 분석하여 특정 동작에 반응하는 프로그램도 만들 수 있다.

OpenCV는 영상 데이터를 :용어[픽셀] 단위로 처리하여 정보를 분석하고 추출할 수 있는 :용어[컴퓨터 비전] 라이브러리다. 영상을 불러오거나 저장하는 작업은 물론 색상 조절, 흐림 효과, 윤곽선 검출, 얼굴 감지, 물체 인식 등 다양한 영상 분석 기능을 지원한다.

## 심화 실습 | 손의 랜드마크 표시하기

MediaPipe와 OpenCV를 활용하여 웹캠에 비친 손을 인식하고, 손가락 관절의 주요 위치를 화면 위에 점과 선으로 표시하는 프로그램을 만들어 보자.

웹캠에서 입력되는 영상은 프레임 단위로 처리되며, 손가락의 움직임에 따라 실시간으로 랜드마크를 추적해 시각적으로 표현한다.

::쪽[30]

### 단계 1 | 라이브러리 불러오기 및 모듈 초기화하기
```python {start=1}
# 라이브러리 불러오기
import cv2
import mediapipe as mp

# 손 인식 모듈 불러오기
mp_hands = mp.solutions.hands

# 손 인식 객체 생성 및 설정하기
hands = mp_hands.Hands(
    static_image_mode=False,
    max_num_hands=1,
    min_detection_confidence=0.5
)

# 랜드마크 그리기 유틸리티 불러오기
mp_drawing = mp.solutions.drawing_utils
```
:::코드설명
- **줄 2** OpenCV 라이브러리 불러오기
- **줄 3** MediaPipe 라이브러리를 불러오고 mp로 이름 설정
- **줄 6** MediaPipe의 손 추적 모듈 불러오기
- **줄 10** 영상 스트림에서 연속 프레임 처리

### 단계 2 | 웹캠 화면 인식해 랜드마크 출력하기
```python {start=17}
# 웹캠 연결하기
video = cv2.VideoCapture(0)

# 프레임 읽기 및 손 인식 처리하기
while True:
    ret, frame = video.read()
    if not ret:
        break

    frame = cv2.flip(frame, 1)
    rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    result = hands.process(rgb_frame)

# 손 랜드마크와 연결선 그리기
    if result.multi_hand_landmarks:
        for hand_landmarks in result.multi_hand_landmarks:
            mp_drawing.draw_landmarks(
                frame, hand_landmarks, mp_hands.HAND_CONNECTIONS
            )
```

:::학습활동[인공지능을 활용한 손 인식 프로그램 탐구하기]
완성한 심화 실습 프로그램을 바탕으로 손의 랜드마크를 인식하는 방법을 다양하게 탐색해 보자.

1. 프레임을 처리할 때 잠시 멈추며 키보드 입력을 받는 부분을 찾아보고, 여기서 '대기 시간'을 조절했을 때 손 인식의 반응 속도와 안정성 및 정확도가 어떻게 달라지는지 비교해 보자.

2. 동시에 인식할 수 있는 손의 최대 개수를 지정하는 변수를 찾아보고, 이 값을 1, 2, 3, 4 등으로 바꿔 실행해 보자. 그런 다음 여러 개의 손을 카메라 앞에 내밀어 실제로 몇 개까지 인식되는지 설정 값별로 기록해 보자.

3. 손으로 판단하기 위한 최소 기준을 정하는 변수를 찾아보고, 이 값을 0.3, 0.5, 0.7, 0.9 등으로 바꿔 실행해 보자. 손이 아닌 물체가 인식되는 경우나 실제 손이 인식되지 않는 경우를 관찰하며, 실제 손만 안정적으로 인식되는 적절한 값의 범위를 찾아보자.
