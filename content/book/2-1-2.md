## 학습 목표

- ESP32와 :용어[LCD]의 :용어[I2C] 통신 원리를 이해할 수 있다.

## 1 LCD의 이해

:용어[LCD](Liquid Crystal Display, 액정 화면)는 액정 물질을 이용하여 문자, 숫자, 그림, 동영상 같은 정보를 표시하는 장치로, 전기 신호에 따라 빛의 투과율을 조절하여 화면을 만든다. LCD는 스스로 빛을 내지 않으므로, 화면을 눈으로 보기 위해서는 백라이트가 필요하다.

:::용어풀이[투과율]
빛이나 물체가 어떤 재질이나 물질을 통과하는 정도를 나타내는 비율이다.
:::

:::용어풀이[백라이트]
LCD에 표시하는 정보가 잘 보이도록 LCD 뒤에서 빛을 비추는 조명을 말한다.
:::

LCD는 여러 줄의 정보나 복잡한 화면을 동시에 표현할 수 있어 사용자 :용어[인터페이스] 구현에 효과적이다. 또한 다양한 크기와 :용어[해상도]로 제작할 수 있고 낮은 전력으로 구동되며 얇고 가벼운 구조로, 휴대용 기기에 널리 사용된다.

## 2 프로그램 개요

LCD의 기본적인 작동 원리를 이해하고, 이를 직접 제어해 보는 경험을 통해 궁극적으로 응용 시스템을 구현하는 것을 목표로 한다.

먼저 동작 테스트 단계에서는 LCD 제어와 관련된 명령 함수가 포함된 라이브러리를 ESP32 보드에 설치한 후, LCD에 문자와 숫자를 다양한 방식으로 출력해 보면서 장치가 정상적으로 작동하는지 확인한다.

기본 과제에서는 첫째, for문을 활용하여 count 값을 일정 범위 동안 1씩 증가시키며 출력해 보고, 둘째, :용어[RTC](실시간 시계) 내장 함수를 활용하여 현재 시간을 LCD에 실시간으로 표시해 본다.

심화 과제에서는 if문과 터치 센서를 활용하여 조건에 따라 LCD에 출력되는 내용을 제어함으로써, 다양한 상황에 맞게 LCD를 활용하는 능력을 키운다.

:::용어풀이[터치 센서]
손가락이나 물체가 접촉했을 때의 변화를 감지하여 전기 신호로 전달하는 입력 장치이다.
:::

### 단계 5 | LCD에 다양한 방식으로 출력하기

:::코드설명[LCD 화면 제어 함수]
- `cd.hide_cursor()`: 커서 숨기기
- `lcd.blink_cursor_on()`: 커서 깜박이기
- `lcd.blink_cursor_off()`: 커서 깜박이기 중단
- `lcd.display_on()`: 숨겨진 화면 나타내기
- `lcd.display_off()`: 현재 화면 숨기기
- `lcd.backlight_on`: 화면 백라이트 켜기
- `lcd.backlight_off`: 화면 백라이트 끄기
- `lcd.move_to(x, y)`: 커서를 x열 y행으로 이동(인덱스는 0부터 시작)
:::

:::웹정정[cd.hide_cursor()]
출판본에는 `cd.hide_cursor()`로 적혀 있어요. 실제 함수 이름은 `lcd.hide_cursor()`예요(앞의 l이 빠진 오타). 원문은 그대로 두었어요.
:::

```python
# 라이브러리 불러오기
from machine import Pin
from machine import SoftI2C
from i2c_lcd import I2cLcd
from time import sleep_ms

# 화면 초기화하기
i2c = SoftI2C(scl=Pin(22), sda=Pin(21),\
              freq=400000)
lcd = I2cLcd(i2c, 0x20, 2, 16)
lcd.clear()
```

:::코드설명
- **줄 2** ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
- **줄 3** I2C 통신을 사용하기 위한 모듈 불러오기
- **줄 4** LCD 제어 함수가 포함된 외부 라이브러리 불러오기
- **줄 5** 밀리초 단위로 지연을 주기 위한 함수 불러오기
- **줄 7\~8** I2C의 클록 신호를 보내는 SCL 핀을 GPIO 22번, I2C의 데이터 신호를 주고받는 SDA 핀을 GPIO 21번에 설정
- **줄 9** I2C 통신 속도를 400 kHz로 설정
- **줄 10** '0x20'은 LCD I2C 모듈의 주소, 2, 16은 문자 출력 가능한 영역이 2행 16열
- **줄 11** 화면 전체에 출력된 내용을 삭제하고, 커서 위치를 초기화
:::

```python {start=12}
# 문자 출력하기
lcd.putstr('Hello LCD!')
```

:::코드설명
- **줄 13** 'lcd.putstr()' 함수를 활용하여 특정 문자 출력
:::

::실습실[esp32/u2/2-1-2-lcd-text-check.py]

```python {start=12}
# 숫자 출력하기
x = 123
lcd.putstr("number: " + str(x))
```

:::코드설명
- **줄 13** 변수 x에 숫자 123을 저장
:::

::실습실[esp32/u2/2-1-2-lcd-number-check.py]

```python {start=12}
# 키보드 출력하기
name = input("name: ")
lcd.putstr("Hello, " + name)
```

:::코드설명
- **줄 13** 'input()' 함수는 사용자로부터 문자열을 입력받음.
- **줄 14** 'lcd.putstr()' 함수를 통하여 Hello와 키보드로 입력받은 문자열을 함께 출력
:::

::실습실[esp32/u2/2-1-2-lcd-keyboard-check.py]

- **줄 3** I2C 통신을 사용하기 위한 모듈 불러오기
- **줄 4** LCD 제어 함수가 포함된 외부 라이브러리 불러오기
- **줄 5** 실시간 시계 기능을 사용하기 위한 모듈 불러오기
- **줄 6** 초 단위로 지연을 주기 위한 함수 불러오기

### 단계 2 | 장치 설정하기

```python {start=7}
# LCD 설정하기

lcd = I2cLcd(i2c, 0x20, 2, 16)

# RTC 설정하기
rtc = RTC()
rtc.datetime((2025, 6, 21, 6, 11, 0, 0, 0))
```

:::코드설명
- **줄 8** SDA 핀과 SCL 핀을 각 GPIO 21번, 22번에 설정하고, I2C 통신 속도를 100 kHz로 설정
- **줄 9** '0x20'은 LCD I2C 모듈의 주소, 2, 16은 문자 출력 가능한 영역이 2행 16열
- **줄 12** RTC 기능을 이용해 날짜와 시간을 수동으로 설정
- **줄 13** (년, 월, 일, 요일, 시, 분, 초, 0)
:::

### 단계 3 | LCD에 RTC 출력 제어하기

```python {start=14}
# LCD 제어하기
while True:
    t = rtc.datetime()
    time_str = "{:02}:{:02}:{:02}"\
               format(t[4], t[5], t[6])
    lcd.clear()
    lcd.putstr("Time: " + time_str)
    sleep(1)
```

:::코드설명
- **줄 16** 현재 시간 정보를 받아옴.
- **줄 17** `'{:02}'`는 2자리 숫자로 0을 채워 출력
- **줄 18** 각각 시, 분, 초 정보를 가리킴.
- **줄 19** 화면을 초기화하고, 커서를 (0,0)으로 이동시켜 시간이 중복 표시되는 것을 방지
- **줄 20** 화면에 'Time:시간' 형태로 출력하게 함.
:::

:::웹정정[format 앞의 점]
출판본 129쪽의 17~18번째 줄은 `"{:02}:{:02}:{:02}"\` 다음 줄에 `format(...)`이 이어져요. 파이썬에서는 `"{:02}:{:02}:{:02}".\`처럼 `format` 앞에 점(.)이 있어야 해요. 원문은 그대로 두었어요. 실습실 예제는 점이 있는 코드예요.
:::

## 심화 실습 | 터치 센서로 출력값 제어하기

터치 센서로 입력을 감지하여 LCD에 카운터가 표시되는 프로그램을 만들어 보자.

### 단계 1 | 동작 테스트

:::연결레시피[터치 센서 연결하기]

| 터치 센서 | 실드 |
| --- | --- |
| GND | GND |
| VCC | VCC |
| S | 17번 핀 |

:::

::회로[2-1-2-2]

```python
# 버튼을 통해 출력값(0↔1) 변화시키기
from machine import Pin
from time import sleep
touch = Pin(17, Pin.IN)
while True:
    print("Touch value:", touch.value())
    sleep(0.2)
```

:::코드설명

### 단계 4 | LCD 터치 상태 설정하기

```python {start=15}
while True:
    touch_state = touch.value()

    # 터치 감지 (엣지 감지: 0 → 1)
    if touch_state == 1 and prev_touch == 0:
        counter += 1
        lcd.clear()
        lcd.putstr("Counter: {}".format(counter))
        sleep(0.3) # 디바운싱
    prev_touch = touch_state
    sleep(0.05)
```

:::코드설명
- **줄 16** 현재 상태 읽기
- **줄 22** 출력 형식을 'Counter: counter 값'으로 고정하고, counter 값만 변화되도록 함.
- **줄 24** 현재 상태를 이전 상태로 저장
:::
