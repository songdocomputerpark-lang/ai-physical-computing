## 1 블루투스 통신으로 데이터 전송

블루투스는 짧은 거리에서 무선으로 데이터를 주고받는 기술이다. 블루투스 통신은 보통 문자열(String) 형태나 바이트(Byte) 단위로 데이터를 주고받는다. 송신 측에서는 값을 문자로 바꾸어 전송하고, 수신 측에서는 이를 다시 숫자 데이터로 변환해 활용한다.

:::말풍선
특히 :용어[BLE](Bluetooth Low Energy)는 저전력으로 통신이 가능해 웨어러블 기기나 스마트 가전제품에서도 널리 사용돼.
:::

:::용어풀이[Thonny에서 MAC 주소 확인하기]
ESP32를 PC에 연결한 상태에서 Thonny를 실행한다.

```python
import network
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.config('mac')
```

**실행 결과**

`b'\xXX\xXX\xXX\xXX\xXX\xXX'`

이 값을 블루투스 주소 형태인 ‘XX:XX:XX:XX:XX:XX’으로 변환하여 코드에 입력한다.
:::

## 5 ESP32 boot.py 실행 코드 만들기

PC(파이썬, OpenCV·MediaPipe)에서 전송한 좌표 문자열 ‘x, y’를 ESP32가 수신한다. 수신된 문자열은 split(‘,’)으로 분리한 뒤 int()로 변환해 x와 y 값으로 파싱한다. ESP32는 x < 100, y < 100 등 임곗값 조건에 따라 빨강, 초록, 파랑 LED를 켜거나 끄는 프로그램을 구현한다.

### 단계 1 | 블루투스 시작 및 핀(LED) 준비하기

:::말풍선
‘import ESP32BLE’는 ESP32에서 BLE 수신과 데이터 읽기, LED 제어 기능을 제공해.
:::

```python
import ESP32BLE
from machine import Pin
from time import sleep
# 블루투스 통신 초기화
ble = ESP32BLE.init('ESP32')
# r, g, b 핀 설정
r = Pin(25, Pin, OUT)
g = Pin(26, Pin, OUT)
b = Pin(27, Pin, OUT)
# LED 핀 배열
led = [r, g, b]
```

:::코드설명
- **줄 1** ESP32 보드에서 블루투스 기능을 사용하기 위한 라이브러리 불러오기
- **줄 2** 핀(Pin) 제어를 위한 라이브러리(LED 같은 부품 제어용)
- **줄 3** 일정 시간 멈추기(sleep)를 위한 라이브러리
- **줄 5** ESP32를 블루투스 기기로 설정하고 이름을 ‘ESP32’로 지정
- **줄 7** 빨강 LED를 핀 25번에 연결 (출력 모드)
- **줄 8** 초록 LED를 핀 26번에 연결 (출력 모드)
- **줄 9** 파랑 LED를 핀 27번에 연결 (출력 모드)
- **줄 11** 리스트로 묶어서 led[0]=빨강, led=[1]=초록, led=[2]=파랑으로 사용 가능
:::

:::웹정정[Pin(25, Pin, OUT)]
출판본 196쪽의 7~9번째 줄은 `Pin(25, Pin, OUT)`처럼 `Pin.OUT`의 점(.)이 쉼표로 적혀 있어요. 그대로는 실행되지 않아서 `Pin(25, Pin.OUT)`이라고 써야 해요. 원문은 그대로 두었어요.
:::
