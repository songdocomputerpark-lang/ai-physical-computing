## 1 인공지능 영상 인식 기술과 원리

인공지능 영상 인식은 컴퓨터가 이미지나 동영상을 분석하여 사람처럼 내용을 인식하고 이해하는 기술이다. 단순히 이미지를 화면에 표시하는 것을 넘어 영상 속 사물이나 사람, 장소 등을 구별하고 의미를 파악한다. 이러한 영상 인식 기술은 보안, 의료, 스마트 시티, 자율주행 등 다양한 분야에서 활용되고 있다.

:::용어풀이[인공지능 영상 인식 활용 예]
- 보안: 얼굴 인식을 통한 출입 통제
- 의료: 영상 진단 및 환자 상태 분석
- 스마트 시티: 교통 흐름 분석, 이상 상황 감지
- 자율주행: 주변 도로 상황을 인식해 주행 지원
:::

영상 인식이 가능하려면 단순히 화면을 보는 것을 넘어 영상 속에서 의미 있는 특징을 뽑아내는 과정이 필요하다. 예를 들어 얼굴을 인식할 때 눈, 코, 입의 위치와 형태를 분석하는 것처럼 인공지능은 영상에서 특정 :용어[패턴]이나 시각적 특징을 추출한다. 이를 :용어[특징 추출](Feature Extraction)이라 하며, 인공지능 영상 인식의 정확도와 신뢰성을 좌우한다.

:::그림생략[교과서 13쪽 사진: 얼굴 영상, 특징 추출, 얼굴 인식, 감정 상태 단계]
왼쪽부터 사람 얼굴 사진(얼굴 영상), 눈·코·입에 특징점이 찍힌 얼굴과 부위별 확대 사진(특징 추출), 행복·슬픔·분노·당황 글자가 적힌 감정 상태 표(얼굴 인식)가 화살표로 이어진 그림이에요. 사람의 얼굴이 나와 이 사이트에는 싣지 못했어요. 책 13쪽에서 보세요.
:::

▲ 인공지능을 통한 얼굴 영상의 특징 추출과 감정 인식 과정

:::용어풀이[특징 추출 기법]
- 밝기 차이 분석: 밝기가 급격히 변하는 부분을 경계로 인식함. 예 얼굴 인식(눈, 코, 입 경계 감지)
- 패턴 분석: 줄무늬나 질감 등 특정 패턴을 감지함. 예 지문 인식(곡선 패턴 분석)
- 모서리 및 선 탐지: 직선이나 곡선을 감지해 형태를 분석함. 예 자율주행(도로 차선 감지)
:::

인공지능 영상 인식 기술은 이러한 특징 추출 원리를 바탕으로 여러 응용 기술이 결합하여 작동한다.

| 기술 종류 | 기술 설명 | 기술 활용 예 |
| --- | --- | --- |
| 물체 인식 | 영상 속에서 특정 물체를 탐지하고 구별하는 기술 | 주변 환경 인식, 작업 자동화에 활용됨. |
| 얼굴 인식 | 사람 얼굴의 특징을 분석해 신원을 식별하는 기술 | 얼굴 특징을 추출하고 데이터베이스의 정보와 비교함. |
| 행동 인식 | 사람이나 사물의 움직임을 분석하여 행동을 해석하는 기술 | 걷기, 뛰기 등 연속된 행동을 감지함. |
| 문자 인식 | 영상 속 문자를 디지털 데이터로 바꾸는 기술 | 글자의 형태를 분석해 컴퓨터가 읽을 수 있게 변환함. |
| 의료 영상 분석 | 의료 영상을 분석해 질병을 진단하거나 치료를 지원하는 기술 | 몸속 조직이나 이상 부위를 찾아내고 변화를 살핌. |

## 2 딥러닝 기반의 인공지능 영상 인식 기술

:::용어풀이[CNN 활용 예]
스탠퍼드대학교에서 개발한 CheXNet(2017)은 CNN 알고리즘을 활용한 흉부 X-ray 영상 진단 모델이다. 이 시스템은 10만 장이 넘는 X-ray 영상을 사용해 훈련하였으며, 그 결과 영상 의학 전문의 수준에 준하는 높은 진단 정확도를 보여 주었다.
:::

인공지능 영상 인식 기술은 :용어[기계학습]과 :용어[딥러닝]이라는 인공지능 학습 방법을 바탕으로 작동한다. 특히 딥러닝 기술 중에서도 :용어[합성곱 신경망], 즉 :용어[CNN](Convolutional Neural Network)은 이미지와 영상 데이터를 분석하는 데 특화되어 있으며, 현재 영상 인식 분야에서 핵심적인 역할을 하고 있다.

CNN은 사람의 시각 인식 과정을 모방한 기술로, 영상을 여러 단계로 나누어 분석한다. 예를 들어, 사람이 사물을 인식할 때 먼저 선, 색상, 모양과 같은 단순한 특징을 파악한 뒤 이를 종합해 전체 대상을 인식하는 것처럼 CNN도 초기에는 단순한 :용어[윤곽선]을 감지하고, 이후 이를 결합하여 더 복잡한 패턴과 객체를 식별한다.

기존의 :용어[컴퓨터 비전] 기술은 사람이 직접 색상, 모서리, 질감 등 특징을 정해 주고 이를 기반으로 인식을 수행했으나, CNN은 이러한 특징을 자동으로 학습하고 추출한다. 즉, 사람이 개입하지 않아도 데이터만 충분히 주어지면 CNN이 스스로 중요한 시각적 정보를 찾아내기 때문에 복잡하고 다양한 이미지 인식 문제를 더욱 정밀하고 유연하게 처리할 수 있다.

:::용어풀이[컴퓨터 비전]
컴퓨터가 이미지나 비디오 데이터를 분석해 시각적 정보를 이해하고 해석하는 기술 분야로 인간의 시각을 컴퓨터로 구현한 것이다.
:::

그렇다면 CNN은 어떤 방식으로 작동할까? CNN 영상 인식에서 핵심이 되는 연산은 :용어[합성곱](Convolution)이다. 합성곱은 이미지에 필터(또는 커널)를 적용하여 중요한 특징을 추출하는 방식으로, 마치 돋보기를 통해 이미지를 자세히 살펴보는 것과 같다. 이 과정을 거치면 중요한 정보는 강조되고, 불필요한 정보는 줄어들어 최종적으로 객체를 더욱 정확하게 인식할 수 있게 된다.

또한, 컴퓨터는 이미지를 수많은 :용어[픽셀]의 집합으로 인식한다. CNN은 이 픽셀 정보를 바탕으로 윤곽선, 색상, 질감 등의 시각적 특징을 단계적으로 학습하며 그 의미를 파악해 나간다.

:::용어풀이[픽셀(Pixel)]
디지털 이미지의 가장 작은 단위, 한 장의 이미지는 수천에서 수백만 개의 픽셀로 이루어진다. 각 픽셀은 색상과 밝기 정보를 가진다.
:::

![CNN을 이용한 특징 추출 과정 그림. 최종 단계는 전체적인 형태를 분석하여 영상 속 객체를 분류하고, 예측 결과는 고양이이며 뒤쪽은 귀, 코, 눈 등의 복잡한 특징을 학습한다. 중간 단계는 감지된 특징들을 조합해 보다 복잡한 패턴이나 질감 인식. 초기 단계는 선이나 모서리처럼 단순하고 기본적인 시각적 특징을 감지하며 앞쪽은 곡선, 모서리 등의 단순한 특징을 학습한다. 입력은 고양이 그림이다](/images/lessons/1-1-2/book-cnn-stages.webp "교과서 14쪽")

## 3 CNN 기반 영상 인식 기술의 활용

CNN을 기반으로 한 영상 인식 기술은 다양한 분야에서 활용되며, 대표적인 예로 딥러닝 객체 인식 모델인 YOLO(You Only Look Once)와 영상 처리 :용어[프레임워크](Framework)인 MediaPipe가 있다.

:::용어풀이[프레임워크(Framework)]
특정 기능을 쉽게 구현할 수 있도록 미리 만들어 놓은 도구나 뼈대를 말한다. 개발자는 프레임워크가 제공하는 기본 구조와 기능을 활용해 효율적으로 프로그램을 만들 수 있다.
:::

YOLO는 이미지를 한 번만 분석하여 여러 객체를 실시간으로 탐지할 수 있는 딥러닝 모델로, 빠르고 효율적인 성능이 특징이다. 이 기술은 자율주행 자동차에서 보행자나 장애물, 신호등 등을 빠르게 인식하고 반응하는 데 사용된다. 또한 보안 시스템에서는 침입자나 위험 요소를 즉각적으로 식별해 대응할 수 있으며, 증강 현실(AR) 게임에서는 화면 속 여러 객체를 실시간으로 탐지하여 몰입감 있는 상호작용을 구현한다.

MediaPipe는 :용어[오픈 소스] 기반 영상 처리 프레임워크로, 실시간으로 얼굴, 손, 자세 등의 신체 특징을 추적하는 기능을 제공한다. 특히 경량화된 CNN 모델을 기반으로 하기 때문에 스마트폰과 같은 모바일 환경에서도 원활하게 작동한다. AR 필터 기능에서는 사용자의 얼굴을 실시간으로 인식해 가상 이미지를 덧씌우고, 피트니스 앱에서는 운동 중 사용자의 자세를 정확히 분석해 필요한 피드백을 제공한다.

**랜드마크(Landmarks)**

MediaPipe에서 :용어[랜드마크]란 이미지나 영상 속에서 사람의 얼굴, 손, 몸 등의 특정 부위 위치를 숫자로 표현한 기준점을 말한다. 예를 들어, 손가락 마디나 눈, 코, 입의 위치, 몸의 관절 등이 각각 하나의 랜드마크로 표시되며, 이를 통해 인공지능이 사람의 움직임이나 표정을 정확하게 인식하고 분석할 수 있다.

- ▶ **손 랜드마크(Hand Landmark)** 손의 21개 주요 지점을 추적하여 손가락의 움직임과 손 모양을 정확하게 인식할 수 있게 해 준다.
- ▶ **얼굴 랜드마크(Face Landmark)** 얼굴의 478개 지점을 추적하여 얼굴 표정, 시선 방향, 입 모양 등을 정밀하게 분석할 수 있게 해 준다.
- ▶ **자세 랜드마크(Pose Landmark)** 사람의 33개 주요 관절을 추적하여 전신 자세와 움직임을 분석할 수 있게 해 준다.

![손 랜드마크는 손목의 0번부터 손가락 끝까지 번호가 붙은 점 21개를 선으로 이은 모양이고, 얼굴 랜드마크는 얼굴 둘레와 눈, 코, 입에 번호가 붙은 점 478개를 찍은 모양이며, 자세 랜드마크는 몸의 관절 33곳에 점을 찍어 선으로 이은 모양이다](/images/lessons/1-1-2/book-landmark-diagrams.webp "교과서 16쪽")

MediaPipe는 Android, iOS, 데스크톱 컴퓨터 등 여러 기기에서 안정적으로 작동하며, Python, JavaScript, C++ 등 다양한 프로그래밍 언어를 지원한다. MediaPipe를 활용하면 웹캠을 통해 Python 코드 몇 줄만으로도 실시간 손 인식 기능을 실행할 수 있으며, 손의 21개 관절 위치(랜드마크)를 감지해 화면에 시각적으로 표시할 수 있다.

MediaPipe는 고성능 영상 인식 기능을 누구나 쉽게 구현할 수 있도록 도와주며, 의료 진단, 스마트 시티, 산업 자동화, 가상 현실(VR), 증강 현실(AR) 등 다양한 분야에서 활용되고 있다.

:::말풍선
아래와 같이 간단한 코드만으로도 실시간 손 인식이 가능해. 현재 사용 중인 python은 3.10.4 버전이고, mediapipe는 0.10.21 버전이야.
:::

**MediaPipe를 활용한 실시간 손 인식 코드**

![프로그램 창 속 편 손바닥 위에 손가락 마디마다 빨간 점이 찍히고 점들이 흰 선으로 이어진 손 인식 결과 화면](/images/lessons/1-1-2/hand-tracking-result.webp "교과서 17쪽")

```python {start=1}
import cv2
import mediapipe as mp

hands = mp.solutions.hands.Hands()
draw = mp.solutions.drawing_utils

cap = cv2.VideoCapture(0)

while True:
    ret, img = cap.read()
    if not ret:
        break

    result = hands.process(img_rgb)

    if result.multi_hand_landmarks:
        for hand in result.multi_hand_landmarks:
            draw.draw_landmarks(
                img,
                hand,
                mp.solutions.hands.HAND_CONNECTIONS
            )

    cv2.imshow('Hand', img)

    if cv2.waitKey(1) == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```
:::코드설명
- **줄 4** 손 인식 모델 초기화
- **줄 5** 랜드마크 그리기 도구 불러오기
- **줄 7** 웹캠 연결
- **줄 10** 프레임 읽기
- **줄 14** 손 인식 처리
- **줄 17** 손이 감지되었을 때
- **줄 18** 손 관절 그리기
- **줄 24** 영상 출력
- **줄 26** 'q' 키를 누르면 종료
- **줄 29** 웹캠 자원 해제
- **줄 30** 모든 창 닫기
:::

:::웹정정[img_rgb]
출판본 17쪽 코드의 14줄 `result = hands.process(img_rgb)`는 `img_rgb`를 만드는 줄이 없어서 그대로 따라 쓰면 NameError가 나요. 실제로는 13줄 앞에 `img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`처럼 색 순서를 바꾼 사진을 만들어 두어야 해요. 원문은 그대로 두었어요. 실습실 예제는 최신 사용법으로 다시 쓴 코드라 색 순서를 바꾸는 줄이 들어 있어요.
:::
