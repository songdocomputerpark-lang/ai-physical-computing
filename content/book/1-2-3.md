## 학습 목표

- 손가락 위치를 인식하고 손가락 끝 좌표 사이의 거리를 계산할 수 있다.
- 손가락 거리 값을 활용하여 원의 크기를 실시간으로 조절하는 프로그램을 만들 수 있다.

## 1 손가락 거리 인식하기

스마트 기기에서 사진을 확대하거나 축소할 때, 두 손가락을 벌리거나 오므리는 동작을 사용하는 경우가 많다. 이런 방식은 누구나 쉽게 이해할 수 있는 직관적인 조작법으로, 우리 일상 속에서 자주 사용되고 있다.

특히 화면을 직접 터치하지 않고 손의 움직임만으로 기능을 제어할 수 있는 비접촉식 :용어[인터페이스]는 기술의 발전과 함께 더욱 정교해지고 있다. 공상과학 영화에서 주인공이 허공에 손가락을 대고 3D 이미지를 조작하는 장면은 이제 현실이 되었으며, 스마트 안경이나 VR 기기에서도 손가락 동작만으로 다양한 애플리케이션을 손쉽게 조작할 수 있게 되었다.

:::용어풀이[3D 이미지]
평면이 아닌 입체적인 깊이감을 가진 영상으로, 가로, 세로, 높이의 3차원 공간 정보를 담고 있어 실제 물체처럼 입체적으로 보이는 이미지를 말한다.
:::

:::그림생략[교과서 42쪽 사진: 태블릿 화면의 꽃 사진을 손가락으로 확대하는 모습]
태블릿 화면에 핀 분홍색 꽃 사진을 두 손가락으로 벌려 확대하는 사진이에요. 출판본 42쪽의 이 사진은 권리 때문에 싣지 않았어요.
:::

손동작 인식 기술의 핵심은 손가락 사이의 거리를 이용하여 다양한 작업을 수행하는 데 있다. 손가락 사이 거리 값은 수치로 표현할 수 있기 때문에 이를 화면 요소의 크기, 색상, 위치 등과 연동하여 직관적인 조작이 가능하다. 예를 들어 스마트폰에서 손가락 사이 거리의 변화를 통해 이미지를 확대하거나 축소하고, VR이나 AR 환경에서 3D 객체의 크기를 조정하거나 HUD 화면을 제어할 수 있다.

:::용어풀이[HUD(Head-Up Display)]
운전자나 사용자가 시선을 다른 곳으로 돌리지 않고도 필요한 정보를 볼 수 있도록 앞쪽 화면에 표시하는 디스플레이 시스템이다.
:::

:::그림생략[교과서 42쪽 사진: 자동차 앞유리에 속도 등을 표시하는 HUD 화면]
자동차 계기판 위에 속도 등을 보여 주는 HUD 화면 사진이에요. 출판본 42쪽의 이 사진은 권리 때문에 싣지 않았어요.
:::

그렇다면 컴퓨터는 손가락 사이의 거리를 어떻게 계산하고 반응하는 것일까? 손가락 끝의 위치는 화면 위의 2차원 좌표로 표현할 수 있으며, MediaPipe Hands와 같은 라이브러리를 활용하면 손가락 관절들의 위치를 절대 좌표로 정밀하게 추출할 수 있다.

::쪽[43]

엄지 끝의 좌표가 (x₁, y₁), 검지 끝의 좌표가 (x₂, y₂)라고 할 때, 두 점 사이의 거리는 :용어[유클리드 거리] 공식을 통해 계산할 수 있다.

:::말풍선
유클리드 거리 공식은 수학에서 두 점 사이의 직선 거리를 구하는 데 사용하는 방법으로, 피타고라스 정리를 바탕으로 해.
:::

![유클리드 거리 그림. 점 p1(x1, y1)과 점 p2(x2, y2)를 잇는 파란 선분의 길이가 d이고, 유클리드 거리(d)는 루트 (x2-x1)의 제곱 더하기 (y2-y1)의 제곱이라는 식이 적혀 있다](/images/lessons/1-2-3/book-euclid-diagram.webp "교과서 43쪽")

:::말풍선
손가락 끝의 두 점이 가까워지면 거리 값이 작아지고, 멀어지면 값이 커지게 돼.
:::

MediaPipe Hands는 손가락 끝에 해당하는 랜드마크 좌표를 제공하는데, 엄지는 4번, 검지는 8번 랜드마크로 지정된다. 이를 활용하면 두 손가락 사이의 거리 변화를 실시간으로 계산할 수 있다.

예를 들어 웹캠에서 추출한 관절 정보 중 엄지 끝 좌표가 (300, 400), 검지 끝 좌표가 (600, 800)이라면 두 좌표 간 유클리드 거리는 다음과 같이 계산한다.

√(600−300)² + (800−400)² = √(90000 + 160000) = √250000 = 500(픽셀)

이처럼 손가락 사이 거리 값을 수학적으로 구하면 손가락을 오므리거나 벌리는 동작에 따라 사진을 확대하거나 축소하는 등의 기능을 손쉽게 프로그램으로 구현할 수 있다.

:::해보기[손 좌표 이동과 선 연결 원리 살펴보기]
그림의 웹캠 화면 위에 표시된 점과 선을 관찰하고, 컴퓨터가 손의 움직임을 어떻게 인식하는지 생각해 보자.

❷ MediaPipe를 이용해 두 손가락 사이의 거리를 실시간으로 계산했다면 이 값이 어느 정도일 때 어떤 동작을 실행할지 구체적인 예시 조건(숫자 포함)을 하나 정해 보자.

## 2 손가락 거리 인식하기 프로그램 개요

이번 실습에서는 OpenCV로 웹캠 영상을 실시간 출력하고, MediaPipe Hands를 활용해 엄지와 검지 끝의 위치를 인식하여 두 손가락 사이의 거리를 계산해 본다. 또 계산된 거리 값에 따라 화면 속 원의 크기를 실시간으로 조절하면서 유클리드 거리 개념을 디지털 환경에서 직접 적용해 본다.

MediaPipe Hands에서 엄지 끝(4번)과 검지 끝(8번) 좌표를 활용하면 두 손가락 사이의 거리를 계산할 수 있다. 이 거리는 사용자의 손가락 움직임에 따라 계속 바뀌며, 이를 이용해 원의 크기를 자동 조절함으로써 손동작을 기반으로 한 간단한 제스처 인터페이스를 구현할 수 있다.

그리고 이 과정을 통해 영상 속 좌표계와 컴퓨터 비전의 기본 원리를 이해하고, 손의 움직임을 활용한 디지털 상호 작용 방식을 직접 체험해 볼 수 있다.

## 4 손가락 거리 인식하기 프로그램 기능과 사용자 인터페이스

웹캠으로 촬영한 영상 위에 손가락의 관절 위치를 나타내는 랜드마크가 표시되고, 엄지와 검지 끝 사이의 거리를 계산한 수치가 화면 왼쪽 상단에 숫자로 나타난다.

계산된 거리를 반지름으로 하는 원이 화면 중앙에 그려지며, 사용자가 손가락을 벌리거나 오므릴 때마다 거리 값이 변하면서 원의 크기도 실시간으로 커지거나 작아진다.

## 기본 실습 | 손가락 거리로 선 그리기

손가락 사이 거리로 원 크기를 제어하는 프로그램을 구현해 보자. OpenCV와 MediaPipe를 활용하여 웹캠 영상에서 엄지와 검지 끝의 위치를 실시간으로 추적하고, 두 점 사이의 거리를 계산한다.

계산된 거리를 반영하여 화면 중앙에 표시되는 원의 크기를 자동으로 조절함으로써, 손가락 움직임을 통해 화면 요소를 제어하는 기본적인 제스처 인터페이스를 체험할 수 있다.

### 단계 1 | 라이브러리 불러오기 및 인식 모델 준비하기
```python {start=1}
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import math

# 손 인식 모델 및 그리기 유틸리티 설정하기
mp_hands = mp.solutions.hands
mp_drawing = mp.solutions.drawing_utils

# 손 인식 객체 생성하기
hands = mp_hands.Hands()
```
:::코드설명
- **줄 2** OpenCV 라이브러리 불러오기
- **줄 3** MediaPipe 손 인식 라이브러리 불러오기
- **줄 4** 유클리드 거리 계산용 라이브러리 불러오기
- **줄 7** 모듈 변수 할당
- **줄 8** 손 랜드마크 시각화 도구
- **줄 11** 손 인식 처리 객체 생성
:::

### 단계 2 | 웹캠 연결 및 실시간 영상 처리하기
```python {start=12}
# 웹캠 연결하기
cap = cv2.VideoCapture(0)

# 영상 처리 루프 시작하기
while True:
    ret, frame = cap.read()
    if not ret:
        break

# 화면 변환 처리하기
    frame = cv2.flip(frame, 1)
    h, w, _ = frame.shape

# 색상 공간 변환하기
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
```
:::코드설명
- **줄 13** 웹캠(0번 장치) 연결
- **줄 17** 프레임 읽기
- **줄 18** 읽기 실패 시 종료
- **줄 22** 좌우 반전
- **줄 23** 프레임 크기 저장
- **줄 26** RGB 변환
:::

::쪽[46]

### 단계 3 | 손 좌표 추출 및 거리 계산하기
```python {start=27}
# 손 인식 처리하기
    result = hands.process(rgb)

# 손이 감지된 경우 처리하기
    if result.multi_hand_landmarks:
        for hand in result.multi_hand_landmarks:

# 손 랜드마크 시각화하기
            mp_drawing.draw_landmarks(frame, hand, mp_hands.HAND_CONNECTIONS)

# 엄지와 검지 끝 좌표 가져오기
            thumb = hand.landmark[4]
            index = hand.landmark[8]

# 상대 좌표를 픽셀 좌표로 변환하기
            x1, y1 = int(thumb.x * w), int(thumb.y * h)
            x2, y2 = int(index.x * w), int(index.y * h)

# 두 점 사이 거리 계산하기
            distance = math.hypot(x2 - x1, y2 - y1)

# 거리 시각화 출력하기
            cv2.line(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv2.putText(frame, f'Distance: {int(distance)}', (10, 50),
                cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 0, 0), 2)
```
:::코드설명
- **줄 38** 엄지 끝
- **줄 39** 검지 끝
- **줄 46** 유클리드 거리 계산
- **줄 49** 선 그리기
- **줄 51** 거리 텍스트 출력
:::

:::말풍선
엄지(thumb)와 검지(index)의 끝 좌표를 픽셀 좌표로 변환한 후, 두 점 사이의 거리를 계산하여 거리 정보를 시각화해.
:::

:::말풍선
'math.hypot()' 함수를 사용해서 두 점 사이의 직선 거리(유클리드 거리)를 구하고, 'cv2.line()'은 엄지와 검지 끝 좌표를 선으로 연결해. 'cv2.putText()'는 거리 값을 화면에 텍스트로 출력해줘.
:::

- 엄지와 검지 끝에 녹색 선이 표시되고, 거리 값이 숫자로 출력되었다.
- 손 움직임과 거리 변화에 따라 선의 길이와 숫자가 실시간으로 반응하였다.
- 'q' 키 입력 시 프로그램이 정상적으로 종료되고 자원이 해제되었다.
:::

## 심화 실습 | 엄지와 검지 사이 거리로 원 그리기

손가락 사이 거리 값을 활용하여 화면 중앙에 원을 그리고 그 크기를 실시간으로 조절하는 프로그램을 만들어 보자.

OpenCV와 MediaPipe를 사용하면 웹캠 영상에서 엄지와 검지의 위치를 추적할 수 있고, 두 점 사이의 거리를 계산해 원의 반지름으로 활용할 수 있다. 이렇게 하면 손의 움직임만으로 시각 요소를 제어하는 인터페이스를 구현할 수 있다.

이때 계산된 거리 값은 손가락의 움직임에 따라 실시간으로 변한다. 두 손가락을 가까이 하면 원이 작아지고, 멀리하면 원이 커진다. 원의 크기는 다음과 같이 설정한다.

::쪽[48]

**거리 값을 이용한 원 크기 제어 코드**

```python
# 엄지(x1, y1)와 검지(x2, y2) 사이 거리 계산하기
distance = math.hypot(x2 - x1, y2 - y1)    # 유클리드 거리 공식으로 손가락 사이 거리 계산

# 계산된 거리(distance)를 반지름으로 하여 원 그리기
cv2.circle(frame,          # 원을 그릴 대상 프레임(웹캠 영상)
           (cx, cy),       # 원의 중심 좌표(예 화면 중앙)
           int(distance),  # 반지름: 손가락 사이 거리
           (0, 255, 255),  # 색상: 노란색(B, G, R 순서)
           3)              # 선의 두께: 3픽셀
```

### 단계 3 | 엄지–검지 좌표 추출 및 거리 계산하기
```python {start=23}
# 손 인식 처리하기
    result = hands.process(rgb)

# 손이 인식된 경우
    if result.multi_hand_landmarks:
        for hand in result.multi_hand_landmarks:

# 손 랜드마크 표시하기
            mp_drawing.draw_landmarks(frame, hand, mp_hands.HAND_CONNECTIONS)

# 엄지(4번)와 검지(8번) 좌표 추출하기
            thumb = hand.landmark[4]
            index = hand.landmark[8]

# 상대 좌표를 픽셀 좌표로 변환하기
            x1, y1 = int(thumb.x * w), int(thumb.y * h)
            x2, y2 = int(index.x * w), int(index.y * h)
```

### 단계 4 | 손가락 거리 계산 및 시각화하기
```python {start=40}
# 유클리드 거리 계산하기
            distance = math.hypot(x2 - x1, y2 - y1)

# 원 그리기: 거리 값을 반지름으로 사용
            cx, cy = w // 2, h // 2
            cv2.circle(frame, (cx, cy), int(distance),
            (0, 255, 255), 3)

# 거리 값 텍스트로 표시하기
            cv2.putText(frame, f'Distance: {int(distance)}', (10, 50),
                cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 0, 0), 2)
```
