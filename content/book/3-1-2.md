## 학습 목표

- 실시간 얼굴 인식 모델의 작동 원리를 이해하고, 이를 시리얼 통신을 통해 외부 장치와 연동할 수 있다.
- MediaPipe에서 인식된 얼굴 정보를 문자열로 전송하고, 마이크로 파이썬 보드에서 해당 문자열을 수신할 수 있다.
- 외부 컴퓨터 비전 시스템과 마이크로 컨트롤러를 연동하여 프로젝트를 구현할 수 있다.

## 1 시리얼 통신

:용어[시리얼 통신]은 데이터를 한 비트씩 순서대로 전송하는 방식으로, 마이크로 컨트롤러와 컴퓨터, 또는 센서 같은 장치 간에 정보를 주고받을 때 사용된다.
이때, 송신기(TX)와 수신기(RX)를 연결하여 데이터를 주고받는다. 구조가 간단하고 처리 방식이 직관적이어서, 센서값 수집, 명령 전달, 외부 장치 제어 등 다양한 프로젝트에서 널리 활용된다.

![파란 기판에 USB-C 단자와 GND, VCC, TX, RX 네 개의 핀이 달린 USB to UART 변환기 사진. 기판에 USB to UART Converter와 Power Logic 글자가 인쇄되어 있다](/images/lessons/3-1-2/third-party/kit-vendor/book-uart-converter-photo.webp "교과서 189쪽")

이 장치는 컴퓨터(USB)와 마이크로 컨트롤러 사이에 데이터를 주고받을 수 있게 도와주는 통신 장치이다.

## 2 프로그램 개요

이 프로젝트는 시리얼 통신의 작동 원리를 이해하고, 이를 직접 실습하여 문자 기반의 제어 시스템을 설계하는 능력을 기르는 것을 목표로 한다.

기초 실습 단계에서는, 마이크로 컨트롤러 보드와 컴퓨터를 시리얼로 연결한 후, 특정 문자(예: ‘a’, ‘b’)를 입력해 레이저를 켜고 끄는 프로그램을 작성해 본다.

다음 단계에서는 인공지능 얼굴 인식 모델(Face Model)을 활용하여 얼굴이 인식되었을 때는 ‘Face Detection’, 인식되지 않았을 때는 ‘None’과 같은 메시지를 시리얼로 받아 상황에 따라 레이저를 제어해 본다.

심화 과제에서는 MediaPipe와 연동하여 실제 얼굴 인식 여부에 따라 서로 다른 명령어를 시리얼로 전송하고, 이에 따라 출력 장치를 자동으로 제어하는 지능형 출력 시스템을 구현해 본다.

이 과정을 통해 학습자는 센서 - 인공지능 - 통신 - 제어가 연결된 시스템을 직접 설계하며 컴퓨팅 사고력과 문제 해결 능력을 확장할 수 있다.

## 4 UART 시리얼 통신 코드 작성 및 저장

### 단계 1 | 라이브러리 불러오기

```python
from machine import Pin, UART
from time import sleep
laser = Pin(18, Pin.OUT)
uart = UART(2, baudrate=115200, tx=16, rx=17)
```

:::코드설명
- **줄 1** Pin, UART 모듈 불러오기
- **줄 2** time 모듈 불러오기
- **줄 3** 레이저를 출력 장치로 설정하고, 18번 핀으로 설정
- **줄 4** UART2를 사용해 통신 속도 115200bps 설정. TX는 16번, RX는 17번 핀 설정
:::

:::용어풀이[UART(번호, baudrate=속도, tx=핀 번호, rx=핀 번호)]

### 단계 2 | 화면 초기화 및 문자 출력하기

```python {start=5}
while True:
```

## 5 마이크로 파이썬 device boot.py 파일로 저장

```python
from machine import Pin, UART
import time

laser = Pin(18, Pin.OUT)
uart = UART(2, baudrate=115200, tx=16, rx=17)

while True:
    if uart.any():
        data = uart.readline().decode().strip()
        if data == 'a':
            laser.on()
            sleep(1)
        elif data == 'b':
            laser.off()
            sleep(1)
```

:::웹정정[boot.py 코드의 sleep]
출판본 191쪽의 boot.py 코드는 `import time`만 하고 `sleep(1)`을 불러 써요. 이대로는 처음 a나 b를 받는 순간 NameError로 멈춰요. 190쪽 코드처럼 `from time import sleep`을 쓰거나 `time.sleep(1)`로 적어야 해요. 원문은 그대로 두었어요. 아래 실습실 예제는 원문 그대로라서 같은 오류가 나와요.
:::

::실습실[esp32/u3/3-1-2-uart-laser.py]

![Save to MicroPython device 창에서 MicroPython device 목록에 boot.py가 파란색으로 골라져 있고, 아래 파일 이름 칸에 boot.py가 적혀 있다](/images/lessons/3-1-2/book-boot-save-dialog.webp "교과서 191쪽")

1. file에서 save as를 눌러 Thonny 작성 코드 Micropython device를 클릭한다.
2. boot.py로 저장하고 실행 버튼을 클릭한다.

마이크로파이썬 보드에서 작성한 코드를 자동으로 실행하려면 boot.py 파일로 저장해야 한다. boot.py는 보드가 전원을 켜거나 리셋될 때 가장 먼저 실행되는 파일이기 때문이다.

즉, 보드에 전원이 공급되면 boot.py가 자동으로 실행되어 통신 준비가 완료된다. 따라서 Thonny에서 인공지능 코드를 실행할 때 Local Python을 사용하더라도, 마이크로 컨트롤러는 이미 통신을 받을 준비가 되어 있다.

:::읽기자료[왜 UART2를 사용하는가?]
ESP32 보드에는 UART0, UART1, UART2 총 3개의 UART 통신 채널이 있다. UART1은 주로 내부 기능(플래시 메모리와의 통신 등)에 사용되는 경우가 많아 일반적인 사용자 프로그램에서는 잘 활용되지 않는다.

UART0는 우리가 코드를 작성하고 실행 결과를 확인하는 도구인 Thonny 프로그램과 이미 연결되어 있어 이를 사용해 ESP32와 컴퓨터가 데이터를 주고받는 통로 역할을 하고 있다. 하지만 여기에 다른 장치를 같이 연결하면 통신이 섞이거나 충돌이 발생할 수 있어 UART2를 사용한다.

UART2는 UART(2, tx = 16, rx = 17)처럼 핀 번호를 자유롭게 설정할 수 있다. 기본 UART0와는 완전히 독립된 통신 라인이기 때문에, Thonny의 코드 실행이나 출력에 영향을 주지 않고 별도로 데이터를 주고받을 수 있다.
:::

### 단계 2 | 시리얼 통신으로 데이터 전송하기

```python {start=7}
while True:
    key = input('입력 (a, b, q): ').strip().lower()

    if key == 'a' or key == 'b':
        uart.write(key.encode('utf-8'))
        print(f'{key} 문자를 시리얼로 전송했습니다.')

    elif key == 'q':
        print('프로그램을 종료합니다.')
        break

    else:
        print('올바른 문자(a, b, q)를 입력해주세요.')

uart.close()
```

:::코드설명
- **줄 8** 사용자가 입력한 값을 공백 없이, 모두 소문자로 만들어 key 변수에 저장
- **줄 11** 사용자가 입력한 문자를 바이트로 바꿔서 마이크로 컨트롤러로 전송
:::

:::용어풀이[uart.write()]
특정 문자를 시리얼 포트를 통해 외부 장치로 전송하는 함수

## 심화 실습 | Face Detection 사용하기

MediaPipe의 얼굴 인식(Face Detection) 모델을 활용하여, 얼굴이 검출될 때 레이저 알림을 주는 시스템을 구현해 보자.

### 단계 1 | 클래스, 시리얼 통신 설정 및 face 모듈 불러오기

```python
import cv2
import mediapipe as mp
import serial
import time

uart = serial.Serial('COM5', 115200)
time.sleep(2)

mp_face_detection = mp.solutions.face_detection
face_detection = mp_face_detection.FaceDetection(min_detection_confidence=0.5)

cap = cv2.VideoCapture(0)
face_present = False
```

:::코드설명
- **줄 7** 연결 안정화 대기
- **줄 13** 얼굴 인식 상태를 저장
:::

### 단계 2 | 얼굴이 인식될 때 단일 문자 전송

```python {start=15}
while True:
    ret, frame = cap.read()
    if not ret:
        continue

    frame = cv2.flip(frame, 1)
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    results = face_detection.process(rgb)

    detected = results.detections is not None

    if detected != face_present:
        face_present = detected
        if detected:
            uart.write(b'a')
            print('Face detected → a 전송')
        else:
            uart.write(b'b')
            print('Face lost → b 전송')
```

:::코드설명
- **줄 27** 상태 갱신
- **줄 29** 얼굴이 새로 인식 되었을 때만 ‘a’ 전송, “단일 문자 전송”
- **줄 32** 얼굴이 사라졌을 때만 ‘b’ 전송
:::

::쪽[194]

### 단계 3 | 얼굴 인식 사각형 시각화 및 코드 종료하기

```python {start=35}
    if results.detections:
        for detection in results.detections:
            bbox = detection.location_data.relative_bounding_box
            ih, iw, _ = frame.shape
            x, y, w, h = int(bbox.xmin * iw), int(bbox.ymin * ih), int(bbox.width * iw), int(bbox.height * ih)
            cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)

    cv2.imshow('Face Detection', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
ser.close()
```

:::코드설명
- **줄 39** 시작점, 끝점 좌표로 사각형 그리기
- **줄 40** (b, g, r) 사각형 색상
:::

:::웹정정[ser.close()]
출판본 194쪽의 마지막 줄은 `ser.close()`인데, 이 프로그램에서 시리얼 통신을 연 변수는 `uart`예요(193쪽 6번째 줄). 그대로 실행하면 NameError가 나요. 원문은 그대로 두었어요. 실습실 예제도 원문 그대로라서 같은 오류가 나와요.
:::
