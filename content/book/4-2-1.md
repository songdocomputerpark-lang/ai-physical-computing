## 학습 목표

- 영상 처리 기반 마우스 제어 프로그램에 BLE 데이터 전송 기능을 추가하여 확장할 수 있다.
- BLE를 통해 전송된 문자열을 ESP32에서 수신하고, x와 y 좌푯값을 정확하게 :용어[파싱]하여 변수에 저장할 수 있다.
- 파싱한 좌푯값을 기반으로 두 개의 :용어[서보모터]를 제어하여, 얼굴 움직임에 따라 하드웨어가 반응하도록 만들 수 있다.

## 1 수신 데이터로 하드웨어 제어하기

이번 단원에서는 영상 처리 프로그램에서 전송된 얼굴 좌표와 클릭 정보를 하드웨어(ESP32)에서 받아들이고, 그 값을 활용해 서보모터를 제어하는 과정을 실습한다. ESP32는 블루투스를 통해 “DATA, X, Y, d_c, r_c”형식의 문자열을 실시간으로 수신하며, 이를 파싱하여 각 데이터를 개별 변수로 나눈다. 예를 들어, x와 y 좌표는 수평·수직 방향의 회전값으로 변환되어 서보모터를 움직이게 한다.

이처럼 ‘영상 인식 → 데이터 전송 → 수신 및 해석 → 하드웨어 제어’의 흐름을 직접 구성해 봄으로써, 컴퓨터에서 처리된 정보가 실제 장치를 어떻게 제어하는지 구체적으로 이해할 수 있다. 또한, 무선을 활용하면 케이블이 없어도 동작하므로 설치가 간편하고, 장치 배치에도 제약이 줄어든다는 장점이 있다.

## 2 수신 데이터로 하드웨어 제어하기 프로그램 개요

이 활동에서는 영상 처리 프로그램에서 추출한 얼굴 좌표와 클릭 신호를 하나의 데이터 형식으로 구성한 뒤 블루투스를 통해 하드웨어(ESP32)로 전송하는 과정을 실습한다.

먼저 웹캠으로 얼굴을 인식하고, 얼굴의 x, y 좌표와 눈 깜빡임을 통해 감지된 클릭 정보를 “DATA, X, Y, 더블 클릭_플래그, 우 클릭_플래그” 형식으로 정리한다. 이렇게 구성된 데이터는 파이썬 프로그램을 통해 BLE 방식으로 ESP32에 전송된다.

ESP32는 이 문자열을 수신한 뒤 쉼표(,)를 기준으로 각 값을 나누어 변수에 저장하고, LCD 화면에 출력한다. 이를 통해 수신된 데이터가 올바르게 처리되고 있는지를 직관적으로 확인할 수 있다.

이번 실습은 얼굴 기반 마우스 제어 데이터를 무선으로 안정적으로 주고받는 통신 구조의 원리를 이해하고, 이후 서보모터 등 다양한 하드웨어 제어로 확장하기 위한 기초를 다지는 데 목적이 있다.

### 단계 5 | EAR 계산 함수 정의하기
```python {start=49}
    def calculate_ear(eye_points, landmarks, w, h):
    points = []
    for point_id in eye_points:
        x = int(landmarks.landmark[point_id].x * w)
        y = int(landmarks.landmark[point_id].y * h)
        points.append([x, y])
    points = np.array(points)
    A = np.linalg.norm(points[1] - points[5])
    B = np.linalg.norm(points[2] - points[4])
    C = np.linalg.norm(points[0] - points[3])
    return (A + B) / (2.0 * C)
```

### 단계 6 | 눈 깜빡임 감지 및 클릭 처리 함수 정의하기
```python {start=60}
def process_eye_blinks(left_ear, right_ear):
    global left_eye_was_closed, right_eye_was_closed, both_eyes_were_closed
    global left_eye_close_start, right_eye_close_start, both_eyes_close_start,
    last_click_time
    current_time = time.time()

    # EAR 임곗값을 기준으로 눈을 감았는지 판별
    left_closed = left_ear <= EAR_THRESHOLD
    right_closed = right_ear <= EAR_THRESHOLD
    both_closed = left_closed and right_closed
    double_click_triggered = False
    right_click_triggered = False

    # 왼쪽 눈을 새롭게 감은 경우
    if left_closed and not left_eye_was_closed:
        left_eye_close_start = current_time
        left_eye_was_closed = True

    # 왼쪽 눈을 다시 뜬 경우
    elif not left_closed and left_eye_was_closed:
        duration = current_time - left_eye_close_start
        left_eye_was_closed = False
        if duration >= LONG_BLINK_THRESHOLD
        and not both_eyes_were_closed and current_time - last_click_time > click_delay:
            pyautogui.doubleClick()
            print(f"더블 클릭! ({duration:.2f}초)")
            last_click_time = current_time
            double_click_triggered = True
```

### 단계 7 | 마우스 이동 제어 함수 정의하기
```python {start=113}
def control_mouse(nose_x, nose_y):
    global previous_mouse_x, previous_mouse_y
    move_x = nose_x - reference_center[0]
    move_y = nose_y - reference_center[1]
    new_x = move_x / face_move_range_x * screen_width + screen_width // 2
    new_y = move_y / face_move_range_y * screen_height + screen_height // 2
    new_x = max(0, min(screen_width - 1, new_x))
    new_y = max(0, min(screen_height - 1, new_y))
    if previous_mouse_x is None:
```

- 이 데이터는 PC에서 전송된 내용을 기반으로 10 ms 간격으로 업데이트된다.

예 X: 1358 Y: 624, d_c: 0 r_c: 0
:::

### 단계 3 | 좌표를 서보모터 각도로 변환하기

이 단계에서는 BLE를 통해 수신된 얼굴 중심 좌표(x, y)를 map() 함수를 사용해 서보모터 제어에 필요한 각도(0~180°)로 변환한 뒤, 두 개의 서보모터를 회전시킨다. x 좌표는 좌우 얼굴 움직임에 따라 서보모터 X를 회전시키고, y 좌표는 상하 얼굴 위치에 따라 서보모터 Y를 회전시킨다. LCD에는 수신된 좌표 및 클릭 정보가 실시간으로 출력되어 모니터링이 가능하다.

**❶ 프로그래밍하기**

이 코드는 수신된 x, y 좌푯값을 서보모터 제어에 적합한 회전 각도로 변환하고, 이를 실제 서보모터 움직임으로 연결한다. 얼굴 위치의 변화가 물리적인 움직임으로 어떻게 바뀌는지를 직접 확인할 수 있다.

```python {start=1}
# 모듈 및 라이브러리 불러오기
import ESP32BLE_LIB
from machine import Pin, SoftI2C
from time import sleep
from i2c_lcd import I2cLcd
from mg90s_servo import MG90S_SERVO, map

# BLE 및 LCD 초기화
ble = ESP32BLE_LIB.init("ESP32")

i2c = SoftI2C(scl=Pin(22), sda=Pin(21), freq=400000)
lcd = I2cLcd(i2c, 0x20, 2, 16)
lcd.clear()
lcd.putstr("BLE Waiting...")

# 서보모터 초기화
servo_x = MG90S_SERVO(signal_pin=25)
servo_y = MG90S_SERVO(signal_pin=26)

# 초기 변수 선언
mouse_x, mouse_y = 0, 0
d_c, r_c = 0, 0
```

```python {start=23}
#  메인 루프 시작
while True:
    data = ble.read()

    if data:
        try:
            # 문자열 형식
            parts = data.split(',')

            if len(parts) == 5 and parts[0] == "DATA":

                # 좌표 및 클릭 상태 파싱
                mouse_x = int(parts[1])
                mouse_y = int(parts[2])
                d_c = int(parts[3])
                r_c = int(parts[4])

                # LCD에 정보 출력
                lcd.clear()
                lcd.setcursor(0, 0)
                lcd.putstr(f"X:{mouse_x:<5} Y:{mouse_y:<5}")
                lcd.setcursor(0, 1)
                lcd.putstr(f"d_c:{d_c:<5} r_c:{r_c:<5}")

                # 좌표 → 각도 변환
                angle_x = map(mouse_x, 0, 3840, 0, 180)
                angle_y = map(mouse_y, 0, 2160, 0, 180)

                # 서보모터 회전 실행
                servo_x.rotate(angle_x)
                servo_y.rotate(angle_y)

        except:
            pass

    sleep(0.01)
```
