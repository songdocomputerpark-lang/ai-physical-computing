- 팬 모터의 구조와 원리를 이해할 수 있다.
- 팬 모터를 회로에 연결하여 회전 방향과 속도를 제어할 수 있다.
- 입력값이나 조건에 따라 팬 모터의 작동 여부와 회전 세기를 제어할 수 있다.

## 1 팬 모터

요즘 노트북이나 데스크탑을 사용하다 보면, 갑자기 팬 소음이 커지는 순간을 경험한 적이 있을 것이다. 이는 팬 모터가 작동 속도를 높여, 내부의 열을 빠르게 식히기 위해 회전수를 증가시킨 결과이다.

팬 모터는 컴퓨터뿐 아니라 냉장고, 공기 청정기, 자동차 등 다양한 전자 제품에서 내부 온도를 조절하는 데 사용된다.

특히 요즘 출시되는 스마트 가전에서는 센서값에 따라 팬 속도를 자동으로 조절하며, 필요한 순간에만 고속으로 회전해 에너지를 절약하는 스마트한 시스템으로 진화하고 있다.

## 2 프로그램 개요

팬 모터의 작동 원리를 이해하고, 이를 직접 제어해 보는 경험을 통해 상황에 맞는 출력 장치로서 팬 모터를 활용하는 능력을 기르는 것을 목표로 한다. 먼저 동작 테스트 단계에서는 팬 모터를 제어하기 위한 INA/INB 신호 제어 코드를 통해 방향을 조절하고, :용어[PWM] 신호를 통해 속도를 제어하는 프로그램을 작성해 본다.

기본 과제에서는 time.sleep()을 활용하여 팬 모터를 1초 간격으로 켜고 끄는 코드를 구현한다. 또한 INA와 INB 핀에 서로 다른 신호를 주어 팬 모터의 회전 방향을 정방향과 역방향으로 제어해 본다.

:::용어풀이[INA / INB 핀]
두 개의 제어 신호로 팬 모터의 회전 방향(정회전/역회전) 또는 정지를 설정하는 제어 방식
:::

심화 과제에서는 PWM과 input() 함수를 활용하여 사용자가 입력한 값에 따라 팬 모터의 속도를 약하게, 중간으로, 강하게 조절하는 프로그램을 작성해 보고, 버튼이나 터치센서 등 다양한 입력 장치와 연계한 물리적 컴퓨팅 시스템 설계 능력을 키운다.

## 3 회로 구성

:::연결레시피[팬 모터 연결 레시피]
- GND
- VCC
- INA (GPIO 25번 핀): LOW(0), HIGH(1) 신호 조합에 따라 모터의 회전 방향을 결정함.
- INB (GPIO 26번 핀): INA와 함께 사용하여 정회전, 역회전, 정지를 설정할 수 있음.

### 단계 2 | 팬 모터 제어 핀 설정하기

```python {start=3}
ina = Pin(25, Pin.OUT)
inb = Pin(26, Pin.OUT)
```

:::코드설명
- **줄 3** 팬 모터 제어를 25번 핀으로 설정(ina 핀)
- **줄 4** 팬 모터 제어를 26번 핀으로 설정(inb 핀)
:::

### 단계 3 | 회전 제어하기

```python {start=5}
while True:
    ina.value(1)
    inb.value(0)
    time.sleep(2)

    ina.value(0)
    inb.value(1)
    time.sleep(2)

    ina.value(0)
    inb.value(0)
    time.sleep(2)
```

:::코드설명
- **줄 6** ina 핀 1로 설정
- **줄 7** inb 핀 0으로 설정
- **줄 8** 2초 동안 회전 유지
- **줄 10** ina 핀 0으로 설정
- **줄 11** inb 핀 1로 설정
- **줄 12** 2초 동안 회전 유지
- **줄 14** ina 핀 0으로 설정
- **줄 15** inb 핀 0으로 설정
- **줄 16** 2초 동안 회전 유지
:::

:::용어풀이[ina.value(1), inb.value(0)]
팬 모터를 정방향(시계 방향)으로 회전 시키는 신호
:::

:::용어풀이[ina.value(0), inb.value(1)]
팬 모터를 역방향(반시계 방향)으로 회전 시키는 신호
:::

:::용어풀이[ina.value(0), inb.value(0)]
팬 모터를 정지시키는 신호
:::

:::용어풀이[팬 모터의 회전 방향]

| INA | INB | 동작 |
| --- | --- | --- |
| 1 | 0 | 시계 방향(정방향) 회전 |
| 0 | 1 | 반시계 방향(역반향) 회전 |
| 0 | 0 | 정지 |

:::

:::에러체크[팬 모터 에러 체크 포인트]

| 오류 사항 | 조치 사항 |
| --- | --- |
| 전원 연결 오류 | 팬 모터의 핀 색상에 따라 VCC 및 GND 핀이 올바르게 연결되었는지 확인한다. |
| 신호 핀 설정 오류 | INA, INB 제어 핀 번호가 코드 내 Pin() 함수의 설정과 일치하는지 확인한다. |
| 회전 방향 설정 오류 | INA = 1, INB = 0 또는 INA = 0, INB = 1 조합이 정방향/역방향 동작 설정에 맞게 입력되었는지 확인한다. |
| 정지 신호 오류 | INA = 0, INB = 0으로 설정하여 정지 명령이 정상적으로 입력되었는지 확인한다. |

:::

## 심화 실습 | 키보드 활용하기

키보드 '1'을 입력 시 팬 모터가 작동하고 '0'을 입력 시 정지하는 프로그램을 구현해 보자.

### 단계 1 | 라이브러리 불러오기

```python
from machine import Pin
import time
from gorillacell_dcmotors import GORILLACELL_DCMOTORS

```

:::코드설명
- **줄 1** Pin 모듈 불러오기
- **줄 2** time 모듈 불러오기
:::

### 단계 2 | 장치 설정하기

```python {start=5}
# 팬 모터 제어용 라이브러리 객체 생성(GPIO 25, 26 핀 사용)
fan = GORILLACELL_DCMOTORS(25, 26)

```

### 단계 3 | 팬 모터 제어하기

:::웹정정[elif 뒤의 콜론과 intput()]
출판본 171쪽 코드의 15번째 줄은 `elif: cmd == '0':`로 적혀 있어요. elif 바로 뒤에 콜론이 있어 따라 쓰면 문법 오류(SyntaxError)가 나요. 말풍선의 `intput()`은 `input()`의 오타예요. 원문은 그대로 두었어요. 실습실 예제는 `elif cmd == '0':`으로 고친 코드예요.
:::

```python {start=8}
while True:
    cmd = input('입력(1/0/q):')

    if cmd == '1':
        fan.rotate('cw', speed = 100)
        print('[Fan] on (CW, speed =)')

    elif: cmd == '0':
        fan.stop()
        print('[Fan] OFF (STOP)')

    elif cmd.lower() == 'q':
        fan.stop()
        print('프로그램을 종료합니다.')
        break
    else:
        print('잘못된 입력입니다. 1/0/q 중에서 입력하세요.')
```

:::코드설명
- **줄 9** intput()함수는 항상 문자열을 반환
- **줄 12** 팬모터 정방향 회전 (속도 100%)
- **줄 16** 팬모터 정지
:::
