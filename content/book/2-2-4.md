## 1 서보모터

서보모터는 전기 신호에 따라 원하는 각도로 정확하게 회전하는 정밀 제어용 모터이다. 내부에는 기어 박스, 위치 센서, 제어 회로가 함께 내장되어 있어 :용어[PWM] 신호의 펄스 폭에 따라 0도부터 180도까지 정해진 각도로 움직일 수 있다. 이러한 특성 덕분에 서보모터는 로봇 관절, 자동문, RC카, 카메라 짐벌, 스마트홈 기기 등 다양한 장치의 위치 제어에 널리 활용되고 있다.

▲ 서보모터의 활용

## 2 프로그램 개요

서보모터의 작동 원리를 이해하고 이를 직접 제어해 보는 경험을 통해, 특정 위치에 정밀하게 작동하는 서보모터의 제어 능력을 기르는 것을 목표로 한다.

먼저 동작 테스트 단계에서는 서보모터를 제어하기 위한 PWM 신호를 설정하고, 정해진 각도(예: 0도, 90도, 180도)로 회전하는 코드를 작성해 본다.

:::용어풀이[servo.duty(값)]
서보모터 각도를 지정함.

servo.duty(40) = 0도

servo.duty(77) = 90도

servo.duty(115) = 180도

| 각도 | duty 값 |
| --- | --- |
| 0도 | 40 |
| 90도 | 77\~78 |
| 180도 | 115 |
:::

기본 과제에서는 먼저 time.sleep()을 활용하여 서보모터를 1초 간격으로 순차적으로 회전시키는 프로그램을 작성한다. 다음으로 반복문을 이용해 서보모터가 특정 위치를 반복적으로 오가는 동작을 구현해 본다.

심화 과제에서는 터치 센서나 조건문을 활용하여 사용자의 입력에 따라 서보모터가 원하는 각도로 회전하거나 정지하는 프로그램을 작성하고, 다양한 센서와의 연계를 통해 서보모터를 지능형 피지컬 컴퓨팅 시스템에 적용하는 능력을 키운다.

## 기본 실습 | 서보모터 제어하기

1도 단위로 각도를 조절하여 서보모터가 자연스럽게 움직이도록 구현한다.

### 단계 1 | 라이브러리 불러오기

```python
from machine import Pin
import time
from servo_library import ServoMotor

servo_1 = ServoMotor(signal_pin=25)

```

:::코드설명
- **줄 3** 서보모터 모듈 불러오기
- **줄 5** 서보모터 GPIO핀 25번 설정
:::

### 단계 2 | 서보모터 반복문 제어하기

:::웹정정[time.sleep() 값]
출판본 176쪽의 설명은 "0.1초 간격으로 1 도씩" 움직인다고 적었지만, 코드의 `time.sleep(0.01)`은 0.01초(10밀리초)예요. 말풍선도 `time.sleep(0.1)`이라고 적었어요. 원문은 그대로 두었어요. 실습실 예제는 코드와 같은 0.01초예요.
:::

```python {start=7}
for angle in range(0, 181, 1):
    servo_1.rotate(angle)
    time.sleep(0.01)

for angle in range(180, -1, -1):
    servo_1.rotate(angle)
    time.sleep(0.01)
```

:::코드설명
- **줄 7** 0도 → 180도까지 0.1초 간격으로 1 도씩 증가
- **줄 11** 180도 → 0도까지 0.1초 간격으로 1 도씩 감소
:::

## 심화 실습 | 키보드로 서보모터 제어하기

input() 함수를 통해 키보드로 숫자를 입력받고, 숫자에 따라 서보모터의 각도를 조절하는 프로그램을 구현해 보자.

### 단계 1 | 라이브러리 불러오기

```python
from machine import Pin
import time
from servo_library import ServoMotor

```

:::코드설명
- **줄 1** Pin 모듈 불러오기
- **줄 2** time 모듈 불러오기
:::

### 단계 2 | 장치 설정하기

```python {start=5}
servo_1 = ServoMotor(signal_pin=25)
servo_1.rotate(90)

```

:::코드설명
- **줄 5** 서보모터 GPIO핀 25번 설정
- **줄 6** 서보모터 초기 위치를 90도로 지정
:::

### 단계 3 | 서보모터 제어하기

```python {start=8}
while True:
    cmd = input('서보 제어 (1: 180도, 2: 0도): ')

    if cmd == '1':
        servo_1.rotate(180)
        print('서보모터가 180도로 이동했습니다.')

    elif cmd == '2':
        servo_1.rotate(0)
        print('서보모터가 0도로 이동했습니다.')

    else:
        print('잘못된 입력입니다. 1 또는 2를 입력하세요.')
```

:::코드설명
- **줄 11** 1이 입력되면 서보모터를 180도로 이동
- **줄 15** 2가 입력되면 서보모터를 0도로 이동
- **줄 19** 1과 2 이외의 값이 입력되면 '잘못된 입력입니다.' 출력
:::

::실습실[esp32/u2/2-2-4-servo-keyboard.py]
