## 학습 목표

- 수신된 클릭 신호를 기반으로 RGB LED의 색을 변경하고, 상황에 따라 적절한 버저음을 출력할 수 있다.
- 사용자의 클릭 상태에 따라 작동하는 다양한 출력 장치(RGB LED, 버저, 레이저 등)를 함께 연동하여 구성할 수 있다.
- BLE를 통해 전송된 데이터를 ESP32에서 :용어[파싱]하고, 해당 값에 따라 하드웨어의 동작을 제어하는 흐름을 설명할 수 있다.

## 1 클릭 신호에 따라 LED와 버저로 반응하기

사용자가 눈 깜빡임으로 클릭 명령을 내릴 경우, 화면 변화만으로는 그 명령이 정확히 전달되었는지 확인하기 어려울 수 있다. 이를 해결하기 위해 클릭 이벤트가 발생했을 때 LED가 점등되거나 버저음이 출력되도록 설정하면 사용자는 명령이 정상적으로 인식되었음을 실시간으로 확인할 수 있다.

이러한 시각적·청각적 피드백 장치는 사용자의 동작에 즉각 반응함으로써, 시스템과 사용자 간 상호작용을 더욱 명확하게 하고 보조기기의 직관성과 완성도를 높여 준다.

## 2 클릭 신호에 따라 LED와 버저로 반응하기 프로그램 개요

이번 실습에서는 얼굴 움직임 기반의 BLE 마우스 제어 프로그램을 확장하여, 클릭 신호에 따라 LED와 버저를 제어하는 기능을 추가한다. 영상 처리 프로그램은 얼굴 좌표와 클릭 여부를 포함한 “DATA, X, Y, d_c, r_c” 형식의 문자열을 BLE로 전송하고, ESP32는 이를 실시간으로 수신해 각각의 값을 변수에 저장한다.

‘d_c’는 ‘더블 클릭’, ‘r_c’는 ‘우 클릭’ 여부를 나타내며, 이 값에 따라 출력 장치를 제어한다. 예를 들어 ‘d_c’값이 ‘1’이면 초록색 LED가 켜지고, ‘r_c’값이 ‘1’이면 파란색 LED가 점등된다. 두 경우 모두 짧은 버저음이 함께 올려 사용자 명령이 인식되었음을 즉시 확인할 수 있도록 한다.

이처럼 시각적·청각적 피드백 장치를 연동함으로써, 사용자의 입력 상태를 명확하게 전달하고 인터페이스의 직관성을 높여 구현해 볼 수 있다.

### 단계 2 | 입·출력 함수 초기화하기
```python {start=6}

# I2C 설정 및 LCD 객체 생성
i2c = SoftI2C(scl=Pin(22), sda=Pin(21), freq=400000)

lcd.clear()

# 서보모터 객체 생성(x 축: GPIO25, y 축: GPIO26)
servo_x = MG90S_SERVO(signal_pin=25)
servo_y = MG90S_SERVO(signal_pin=26)

# RGB LED 핀 설정
led_r = Pin(27, Pin.OUT)
led_g = Pin(32, Pin.OUT)
led_b = Pin(33, Pin.OUT)

# 클릭 상태 및 마우스 좌표 초깃값 설정
mouse_x, mouse_y = 0, 0
d_c, r_c = 0, 0

# 레이저 모듈 제어 핀 설정 (GPIO18)
laser = Pin(18, Pin.OUT)

# 버저 제어 핀 설정 (GPIO2, PWM 사용)

buzzer.duty(0)
```

- **줄 20** 빨간색
- **줄 21** 초록색
- **줄 22** 파란색
- **줄 33** 버저 OFF로 시작

:::학습활동[LED와 버저 출력을 응용하여 사용자 피드백 확장하기]
완성한 얼굴 좌표 기반 무선 제어 시스템을 바탕으로, LED와 버저의 피드백을 다양화하고, 클릭 동작에 따른 표현 방법을 탐구해 보자.

1. 더블 클릭과 우 클릭을 했을 경우 각각 다른 음이 재생되도록 지정해 보자.

   예 더블 클릭 시 도-미-솔 음, 우 클릭 시 솔-미-도 음

2. 클릭이 감지되면 LED가 1초 동안 켜졌다가 자동으로 꺼지도록 프로그램을 구성해 보자.

3. LED가 오래 켜져 있을 경우 어떤 문제가 발생할 수 있을지 생각해 보고, 프로그램의 다른 동작에 영향을 주지 않도록 하려면 어떻게 구현해야 할지 써 보자.

   sleep(1)을 사용하면 LED는 켜지지만, 그동안 프로그램의 다른 기능도 함께 멈춘다.
:::
