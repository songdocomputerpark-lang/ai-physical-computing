## 학습 목표

- 음성을 실시간으로 텍스트로 변환하는 프로그램을 작성할 수 있다.
- 음성 인식 결과를 출력하고 내용을 확인할 수 있다.
- 키워드 감지를 통해 프로그램을 제어하는 방법을 이해할 수 있다.

## 1 음성 인식하기

최근 사람의 음성을 실시간으로 인식하고, 이를 글자로 바꾸는 기술인 :용어[STT](Speech-to-Text)가 빠르게 발전하고 있다. 사용자가 마이크에 대고 “오늘의 날씨를 알려 줘.”라고 말하면, 프로그램은 이 음성을 디지털 신호로 바꾸고, 해당 내용을 텍스트로 변환한다. 변환된 텍스트는 화면에 표시되거나, 사용자가 말한 문장에 특정 단어가 있는지 확인하고, 그에 따라 프로그램이 어떻게 작동할지 결정한다. 예를 들어, 사용자가 “시작”이라고 말하면 프로그램이 실행을 시작하고, “정지”라고 말하면 프로그램이 멈추도록 만드는 것이다. 이러한 기술은 인공지능 음성 비서, 키오스크 안내 시스템, 자막 생성, 번역 시스템 등 다양한 분야에서 폭넓게 사용되고 있다.

## 2 음석 인식하기 프로그램 개요

이 프로그램은 음성 인식 기술의 핵심 과정을 이해하고, 키워드 감지를 통해 프로그램을 제어하는 원리를 체험하는 데 목적이 있다. 사용자의 음성을 마이크로 입력하면, 프로그램은 이를 디지털 신호로 변환하고 STT 기술을 활용해 텍스트로 바꾼다. 이후 텍스트에 포함된 키워드를 감지하여, 그에 따라 프로그램이 동작하게 된다.

기본 과제에서는 음성을 텍스트로 변환하고 그 결과를 화면에 출력하는 과정을 실습한다. 심화 과제에서는 “시작”, “정지”, “종료”, “위험”과 같은 명령어를 인식하여, 해당 키워드에 따라 프로그램의 흐름을 제어하는 기능을 구현해 본다.

## 4 음성 인식하기 프로그램 기능 및 사용자 인터랙션

이 프로그램은 사용자가 마이크에 음성 명령을 말하면, 이를 인식해 텍스트로 변환하고 화면에 출력한다. 변환된 텍스트에서 키워드가 감지되면, 그에 맞는 반응을 프로그램이 수행한다.

사용자가 명령어를 말하고, 프로그램이 이를 인식하여 반응하는 과정이 반복되며, 키워드가 없을 경우에는 다음 음성 입력을 기다리는 상태가 유지된다. 이처럼 사용자의 음성 입력과 프로그램의 반응이 순차적으로 연결되면서, 음성 명령을 중심으로 한 프로그램 흐름과 상호작용 방식의 구조를 이해할 수 있다.


### 단계 2 | 마이크 입력 준비하기

```python {start=3}
# 음성을 입력받고 처리하는 함수 정의
def recognize_voice():
    r = sr.Recognizer()

    # 마이크로부터 음성 입력받기
    with sr.Microphone() as source:
        print("말씀하세요. (5초 이내)")
        audio = r.listen(source, phrase_time_limit=5)
```

:::코드설명

:::

:::말풍선

## 심화 실습 | 음성 키워드를 감지해 반응하는 프로그램 구현하기

사람은 말로 컴퓨터에 명령을 내릴 수 있고, 이 과정을 통해 프로그램과 상호작용할 수 있다. speech_recognition 라이브러리와 구글 STT(Speech-to-Text) API를 활용하여 사용자의 음성 명령을 실시간으로 텍스트로 변환하고, 그 내용을 바탕으로 프로그램의 동작을 제어하는 기능을 구현해 보자.

변환된 텍스트에 “시작”, “정지”, “종료”, “위험” 등 미리 설정된 키워드가 포함되어 있으면, 프로그램은 해당 명령에 맞게 반응한다. 예를 들어, “종료”라는 키워드가 감지되면 프로그램이 자동으로 종료된다.

이러한 흐름은 음성을 이해하고 실행 결과로 이어지는 기본적인 음성 인식 알고리즘의 작동 방식을 보여 준다.

**음성 인식 알고리즘**

**❶ 음성 입력 및 변환**

사용자가 마이크에 대고 말을 하면, 프로그램은 해당 음성을 녹음한 후 구글의 음성 인식 기능을 활용해 실시간으로 텍스트로 변환한다.

**❷ 키워드 감지 및 반응**

변환된 텍스트에서 “시작”, “정지”, “종료” 등 미리 설정된 키워드를 찾아내고, 키워드에 따라 프로그램이 동작하거나 종료된다.

**❸ 입력·출력 흐름 시각화**

화면에는 “말씀하세요.”와 같은 안내 메시지가 표시되고, 인식된 텍스트와 감지된 키워드가 함께 출력되어 사용자가 프로그램의 반응을 실시간으로 확인할 수 있다.

::쪽[108]

### 단계 1 | 라이브러리 불러오기 및 초기 설정하기

```python
# 라이브러리 불러오기
import speech_recognition as sr

# 인식할 키워드 목록 정의
KEYWORDS = ["시작", "정지", "종료"]

# 현재 프로그램 실행 상태를 저장하는 변수
is_running = False
```

### 단계 2 | 음성 인식 및 프로그램 제어 함수 정의하기

```python {start=9}
# 음성을 인식하고 키워드에 따라 프로그램을 제어
def recognize_and_control():
    global is_running
    r = sr.Recognizer()

    # 마이크로부터 음성 입력받기
    with sr.Microphone() as source:
        if not is_running:
            print("프로그램을 시작하려면 '시작'이라고 말하세요.")
        else:
            print("명령어를 말하세요. ('정지' 또는 '종료')")

        audio = r.listen(source, phrase_time_limit=5)

    try:
        text = r.recognize_google(audio, language='ko-KR')
        print("인식된 내용:", text)
```

:::코드설명
- **줄 11** 함수 안에서 전역 변수 'is_running'값을 변경하기 위해 global 선언
- **줄 12** 음성 인식 도구 객체 생성
- **줄 15** 마이크 장치 사용 준비
- **줄 17** 실행 전 안내 메시지 출력
- **줄 19** 실행 중일 때 안내 메시지 출력
- **줄 21** 최대 5초간 음성 입력받기
- **줄 24** 입력된 음성을 한글 텍스트로 변환
- **줄 25** 인식 결과 출력
:::

::쪽[109]

### 단계 3 | 키워드 감지 및 프로그램 상태 제어하기

```python {start=26}
        # 인식된 텍스트에서 키워드 탐지
        for word in KEYWORDS:
            if word in text:
                print(f"감지된 키워드: {word}")

                if word == "시작":
                    if not is_running:
                        print("프로그램이 실행됩니다.")
                        is_running = True
                    else:
                        print("이미 실행 중입니다.")

                elif word == "정지":
                    if is_running:
                        print("프로그램이 일시 정지되었습니다.")
                        is_running = False
                    else:
                        print("이미 정지 상태입니다.")

                elif word == "종료":
                    print("프로그램을 종료합니다.")
                    return False

                break
            else:
            print("유효한 명령어가 없습니다.")
```

:::코드설명
- **줄 27** 미리 정의된 키워드 목록을 하나씩 확인
- **줄 28** 텍스트에 해당 키워드가 포함되어 있는지 확인
- **줄 29** 감지된 키워드 출력
- **줄 33\~34** 프로그램을 실행 상태로 전환
- **줄 36** 이미 실행 중일 경우 메시지 출력
- **줄 40\~41** 프로그램을 정지 상태로 전환
- **줄 43** 이미 정지 중일 경우 메시지 출력
- **줄 46** 프로그램 종료 안내
- **줄 47** 반복 루프 종료 신호
- **줄 49** 키워드가 하나 감지되면 추가 검사는 생략
- **줄 51** 어떤 키워드도 감지되지 않았을 경우 안내 출력
:::

:::웹정정[들여쓰기]
출판본 109쪽 코드의 50~51줄은 들여쓰기가 맞지 않게 인쇄되어 있어요. 그대로 따라 쓰면 `else:` 아래가 비어 `IndentationError`가 나요. `else:`는 27줄 `for word in KEYWORDS:`와 같은 깊이로, 51줄 `print(...)`는 그보다 한 단계 안쪽으로 써야 해요. 원문은 그대로 두었어요. 실습실 예제는 맞는 들여쓰기예요.
:::

### 단계 4 | 오류 발생 시 처리 및 프로그램 실행하기

```python {start=52}
    except sr.UnknownValueError:
        print("음성을 인식할 수 없습니다.")
    except sr.RequestError:
        print("서버 요청 실패.")
    return True

# 프로그램 실행 루프
if __name__ == "__main__":
```

:::학습활동[실시간 음성 인식 시스템에 생성형 인공지능 기능 더하기]
완성한 음성 인식 프로그램을 바탕으로, 생성형 인공지능을 활용해 실생활에서 더욱 유용하게 쓰일 수 있도록 기능을 발전시켜 보자.

1. 음성 명령어에 따라 생성형 인공지능으로 다양한 응원 문장을 생성하여 화면에 출력되도록 구성해 보자.

   예 “시작” → “좋아요! 오늘도 열심히 해 봐요!”, “정지” → “잠깐 쉬어가는 것도 좋아요!”

2. “오늘 날씨 어때?”, “배고파” 등 일반 대화 문장을 인식했을 때, 상황에 맞는 응답을 출력하도록 구성해 보자.

3. 음성으로 연속된 명령어를 인식하고, 그 순서대로 동작이 실행되도록 구성해 보자.

   예 “시작 → 왼쪽 → 점프” → 캐릭터가 시작되고 왼쪽으로 이동한 뒤 점프 동작 수행

4. 이 프로그램이 실생활에서 사용될 수 있는 장면을 상상하여, 구체적인 활용 사례를 정리해 보자.

   예 스마트 학습 도구에서 “도움이 필요해요.”라고 말하면 인공지능이 설명해 주는 기능
:::
