## 1 피지컬 컴퓨팅

:용어[피지컬 컴퓨팅](Physical Computing)은 센서, 마이크로컨트롤러, 액추에이터 등을 활용하여 현실인 아날로그 세계와 디지털 세계를 연결하는 기술로, 임베디드 시스템을 이용한다. 쉽게 말해, 사람의 동작, 소리, 빛, 온도와 같은 물리적인 데이터를 컴퓨터가 이해하고, 다시 물리적인 동작으로 반응하게 만드는 과정이다.

피지컬 컴퓨팅은 입력 장치, 처리 장치, 출력 장치로 구성된다. 입력 장치는 센서, 버튼, 스위치 등으로 외부 환경의 변화나 사용자의 동작을 감지하여 데이터를 수집한다. 처리 장치는 입력된 데이터를 마이크로컨트롤러로 처리하고 다른 장치를 제어한다. 출력 장치는 처리된 결과를 LED, 모터, 스피커, 디스플레이 등으로 출력한다.

:::용어풀이[센서의 종류]
빛 센서, 온도 센서, 소리 센서, 습도 센서, 압력 센서, 거리 센서, 가속도 센서 등 용도에 따라 다양한 센서가 있다.
:::

![손가락으로 누르는 그림의 입력 장치에서 반도체 칩 그림의 처리 장치로, 다시 컴퓨터 모니터 그림의 출력 장치로 화살표가 이어지는 피지컬 컴퓨팅의 구성](/images/lessons/2-1-1/flow-input-process-output.webp "교과서 117쪽")

## 2 임베디드 시스템

:용어[임베디드 시스템](Embedded System)은 피지컬 컴퓨팅을 구현하는 핵심 플랫폼으로, 특정한 하나의 기능 또는 소수의 기능만을 수행하도록 설계된 소형 컴퓨팅 시스템이다. 주요 구성 요소와 역할은 다음과 같다.

:::용어풀이[임베디드 소프트웨어 개발 도구]
센서, LED, 모터 등을 제어하고, 특정한 하드웨어 안에서 직접 실행되는 임베디드 소프트웨어를 개발하기 위한 도구로, 파이썬을 가볍고 빠르게 만든 마이크로파이썬을 활용한다.
:::

| 구성 요소 | 역할 |
| --- | --- |
| 마이크로컨트롤러 | 입력된 데이터 연산과 시스템 제어를 하며, 프로그램이 저장되어 실행된다. |
| 센서(Sensor) | 주변 환경의 정보를 감지하여 마이크로컨트롤러에 전달하는 장치이다. |
| 액추에이터(Actuator) | 마이크로컨트롤러의 제어 신호를 받아 실제 물리적인 동작을 수행하는 장치이다. |
| 펌웨어(Firmware) | 마이크로컨트롤러 내부에서 하드웨어를 제어하는 프로그램이다. 특정한 기능을 수행하도록 작성된 코드로, 임베디드 시스템의 동작 방식을 결정한다. |

::쪽[118]

**ESP32 동작 테스트**

**LED 출력 테스트하기**

```python
from machine import Pin
from time import sleep

led = Pin(2, Pin.OUT)

while True:
    led.on()
    sleep(0.5)
    led.off()
    sleep(0.5)
```

:::코드설명
- **줄 1** ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
- **줄 2** 초 단위로 지연을 주기 위한 함수 불러오기
- **줄 4** D2는 ESP32의 기본 내장 LED
- **줄 6\~10** ESP32가 작동 가능한 정상 상태인지 확인하기 위하여 led.on()과 led.off() 함수를 교대로 사용하여 ESP32 내장 LED의 깜박거림 확인
:::
