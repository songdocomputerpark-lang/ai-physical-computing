## 학습 목표

- MediaPipe와 PyAutoGUI를 활용하여 손가락 동작을 인식할 수 있다.
- MediaPipe와 PyAutoGUI를 활용하여 마우스 커서를 제어할 수 있다.
- 손가락 좌표를 실제 화면 해상도에 맞춰 변환하여 마우스 커서를 제어할 수 있다.

## 1 손 인식과 화면 제어의 원리

우리는 보통 마우스와 키보드를 통해 컴퓨터를 조작하지만, 손가락 끝의 정교한 움직임만으로 이를 제어할 수 있다면 어떨까? 이번 단원에서는 손 인식 기술과 좌표 매핑을 통해 그런 상상을 직접 구현해 본다.

MediaPipe는 웹캠 영상에서 손을 인식하고, 손가락 끝과 관절을 포함한 21개의 특징점(:용어[랜드마크]) 좌표를 실시간으로 제공한다. 이를 활용하면, 엄지와 검지의 상대 위치로 동작을 인식하거나, 검지의 위치로 마우스 커서를 제어할 수 있다.

단, MediaPipe의 좌표는 정규화된 상대 좌표이다. 따라서 이를 모니터 해상도 기준의 실제 좌표로 변환해야 한다. 이 과정에서 PyAutoGUI 라이브러리를 사용하면 화면 크기를 기준으로 손 좌표를 변환하고, 마우스 커서를 이동시킬 수 있다.

:::용어풀이[정규화]
데이터를 일정한 범위로 맞추는 과정으로, 보통 0과 1 사이의 값으로 변환하는 것
:::

이처럼 손 인식과 좌표 매핑 기술을 활용하면 손가락만으로도 컴퓨터를 제어하는 새로운 방식을 실현할 수 있다.

## 2 프로그램 개요

이 프로그램은 웹캠을 통해 손의 움직임을 인식하고, 이를 기반으로 컴퓨터를 제어하는 것이 목표이다. 주요 기능은 두 가지다.

첫째, 엄지와 검지의 동작을 인식하여 스크린숏을 촬영하는 기능이다. MediaPipe를 통해 손의 특징점을 감지하고, 엄지가 검지보다 위에 있을 때 PyAutoGUI를 사용해 화면을 이미지로 저장한다.

둘째, 검지의 움직임으로 마우스 커서를 제어하는 기능이다. 손가락의 위치는 영상 내 상대 좌표이므로, 모니터 해상도에 맞게 실제 픽셀 좌표로 변환하여 커서를 이동시킨다.

이처럼 손 동작만으로도 스크린숏 촬영과 마우스 조작이 가능해지며, 비접촉식 컴퓨터 제어라는 새로운 상호작용 방식을 체험해 볼 수 있다.

## 기본 실습 | 손 동작으로 스크린숏 촬영하기

MediaPipe와 pyautogui를 활용하여 사용자의 손의 특징점을 추출하여 손 동작으로 스크린숏을 찍는 프로그램을 구현한다.

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import pyautogui

# MediaPipe 손 인식 모델 초기화하기
mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7)
mp_draw = mp.solutions.drawing_utils

# 웹캠 연결하기
cap = cv2.VideoCapture(0)
```

:::코드설명
- **줄 2** OpenCV 모듈 불러오기
- **줄 3** Mediapipe 모듈 불러오기
- **줄 4** pyautogui 모듈 불러오기
- **줄 7** MediaPipe hands 모듈 가져오기
- **줄 9** 손 특징점을 그리기 위한 유틸리티 가져오기
- **줄 12** 0번 카메라(내장 웹캠)와 연결
:::

:::용어풀이[max_num_hands=1]
여러 손이 감지될 때 한 손만 처리하도록 함.
:::

:::용어풀이[min_detection_confidence=0.7]
손 감지 정확도가 70% 이상일 때만 유효하다고 판단하게 하여 오인식을 줄임.

## 심화 실습 | 손가락으로 마우스 커서 조종하는 프로그램 구현하기

웹캠으로 검지의 움직임을 실시간 감지해 마우스 커서를 제어하는 프로그램을 만들어 보자.

PC마다 모니터 크기와 해상도가 다르므로 특정 해상도를 고정하지 않고, 실행 환경에서 해상도를 자동으로 불러오는 방식을 사용해야 한다. 프로그램은 웹캠 화면 전체에서 손을 인식하지만, 실제 커서 제어에는 검지 끝 좌표만을 사용하는 것이 좋다.

이러한 매핑 방식을 통해 사용자 환경이 달라도 손가락 움직임만으로 자연스럽게 컴퓨터를 조작할 수 있도록 만들어 보자.

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import pyautogui

# MediaPipe 손 인식 모델 초기화
mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7)
mp_draw = mp.solutions.drawing_utils

# 화면 해상도 가져오기
screen_width, screen_height = pyautogui.size()

# 웹캠 연결
cap = cv2.VideoCapture(0)
```

:::코드설명
- **줄 2** OpenCV 모듈 불러오기
- **줄 3** Mediapipe 모듈 불러오기
- **줄 4** pyautogui 모듈 불러오기
- **줄 7** MediaPipe hands 모듈 가져오기
- **줄 9** 손 특징점을 그리기 위한 유틸리티 가져오기
- **줄 12** 현재 모니터의 가로 및 세로 해상도 픽셀 값 가져오기
- **줄 15** 0번 카메라(내장 웹캠)와 연결
:::

### 단계 3 | 손 인식 및 마우스 조종하기

```python {start=26}
    # MediaPipe 손 인식 실행
    result = hands.process(image_rgb)
    # 손이 인식된 경우 → 검지 좌표 추출 및 마우스 커서 이동
    if result.multi_hand_landmarks:
        for hand_landmarks in result.multi_hand_landmarks:
            # 손 특징점과 연결선 그리기
            mp_draw.draw_landmarks(image, hand_landmarks, mp_hands.HAND_CONNECTIONS)
            # 검지 끝(INDEX_FINGER_TIP) 특징점의 좌표 가져오기
            index_tip = hand_landmarks.landmark[mp_hands.HandLandmark.INDEX_FINGER_TIP]
            # 검지의 정규화된 좌표(0.0~1.0)를 실제 화면 픽셀 좌표로 변환
            # 웹캠 영상의 크기가 아닌, 실제 모니터 해상도에 맞춰 변환하여 마우스 커서 이동
            finger_x = int(index_tip.x * screen_width)
            finger_y = int(index_tip.y * screen_height)
            # 마우스 커서 이동
            pyautogui.moveTo(finger_x, finger_y)
```

- **줄 37** 검지 x 좌표를 화면 너비에 맞춰 변환
- **줄 38** 검지 y 좌표를 화면 높이에 맞춰 변환

:::학습활동[인공지능을 이용한 스크린 제어 프로그램 만들기]
완성한 손 동작 인식 프로그램을 기반으로, 생성형 인공지능을 활용해 실생활에 활용할 수 있도록 기능을 발전시켜 보자.

1. 손가락 동작 인식 후 자동으로 화면을 캡처하는 기능을 구성해 보자.

   예 엄지와 검지가 특정 위치에 오면 → pyautogui.screenshot() 실행 → “스크린숏이 저장되었습니다” 출력

2. 캡처가 완료되었을 때 화면에 문장을 출력하도록 구성해 보자.

   예 “지금 촬영이 완료되었습니다!” 또는 “화면 캡처가 완료되었습니다!” 등 문구 출력

3. 검지 끝 좌표를 이용하여 마우스 커서를 실제 화면 위치에 맞춰 움직여 보자.

   힌트) screen_width, screen_height를 활용하여 정규화 좌표 → 실제 좌표로 변환
