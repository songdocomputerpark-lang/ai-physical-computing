## 학습 목표

- 페이스 메시를 활용해 얼굴 랜드마크 추출 과정을 설명할 수 있다.
- 얼굴 중심 좌표를 기준으로 Left/Right 방향 감지 로직을 구현할 수 있다.
- 방향 인식으로 실시간 카운터를 구현할 수 있다.

## 1 얼굴 방향 감지하기

사람은 일상생활에서 고개를 움직여 다양한 의사 표현을 한다. 예를 들어, 고개를 끄덕여 동의의 뜻을 나타내거나, 고개를 돌려 특정 방향을 가리키기도 한다. 이러한 고개 움직임을 컴퓨터가 인식한다면, 여러 분야에서 사용자에게 편리함을 제공할 것이다. 최근 MediaPipe와 같은 :용어[오픈 소스] 영상 처리 기술이 개발되면서, 웹캠만으로도 사람의 얼굴에서 3차원(3D) 형태의 데이터를 실시간으로 추출할 수 있게 되었다. 이를 통해 별도의 장비 없이도 고개 움직임이나 시선 방향을 인식하는 것이 가능해졌다.

이 기술을 활용한 프로그램은 웹캠을 통해 사용자의 얼굴을 인식하고, 고개가 움직이는 방향을 감지하고 실시간으로 분석하여 그 횟수를 기록한다. 이러한 방식은 별도의 특수 장비 없이도 구현이 가능하며, 현재 교육, 헬스케어, 접근성 보조 기술 등 다양한 분야에 활용되고 있다. 이와 같은 프로그램을 만들어 봄으로써 학습자는 :용어[컴퓨터 비전]의 개념을 이해하고, 영상 인식, 좌표 추출, 조건 분기, 사용자 :용어[인터페이스](UI) 구성 등 소프트웨어 개발의 전 과정을 종합적으로 체험할 수 있다.

:::용어풀이[컴퓨터 비전]
사람의 시각 능력을 컴퓨터가 모방하거나 구현하려는 기술 분야로, 이미지나 영상을 처리하여 의미 있는 정보를 추출하는 것을 말한다.
:::

## 2 얼굴 방향 감지하기 프로그램 개요

이 프로그램은 MediaPipe의 :용어[페이스 메시] 기술을 활용하여 얼굴의 주요 특징점(:용어[랜드마크])을 시각적으로 표현하고, 얼굴 인식의 원리를 이해하는 것을 목적으로 한다. 특히 얼굴 중심에 위치한 코의 x 좌표 변화를 기준으로 하여, 사용자의 고개가 왼쪽, 정면, 또는 오른쪽 중 어느 방향을 향하고 있는지를 실시간으로 판별하고 그 횟수를 기록할 수 있다.

이 프로그램은 비대면 환경에서의 집중도 분석, 사용자 경험(UX) 개선, 장애인 보조 기술 등 다양한 분야에 적용된다.

## 기본 실습 | 얼굴 랜드마크 인식 및 시각화 프로그램 구현하기

MediaPipe의 페이스 메시를 활용하여 사용자의 얼굴을 인식하고, 얼굴의 특징점(랜드마크)을 추출하여 실시간으로 화면에 표시하는 프로그램을 구현해 보자.

### 단계 1 | 라이브러리 불러오기 및 초기 설정하기

```python
# 라이브러리 불러오기
import cv2
import mediapipe as mp

# 웹캠 연결 및 FaceMesh 초기화
cap = cv2.VideoCapture(0)
mp_face_mesh = mp.solutions.face_mesh
face_mesh = mp_face_mesh.FaceMesh(max_num_faces=1)
```

- **줄 3** MediaPipe 모듈 불러오기
- **줄 6** 웹캠 연결
- **줄 7** FaceMesh 솔루션 불러오기
- **줄 8** 1명의 얼굴만 인식하도록 모델 초기화
:::

:::말풍선
'cv2.VideoCapture(0)'은 웹캠에서 실시간 영상을 입력받기 위한 객체야.
:::

### 단계 2 | 영상 전처리 및 얼굴 랜드마크 시각화하기

```python {start=9}
# 영상 처리 루프 시작
while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        print("프레임을 가져올 수 없습니다.")
        continue

        # 좌우 반전 및 색상 변환
        frame = cv2.flip(frame, 1)
        rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        results = face_mesh.process(rgb_frame)

        # 얼굴이 인식된 경우 랜드마크 출력
        if results.multi_face_landmarks:
            for landmark in results.multi_face_landmarks[0].landmark:
                h, w = frame.shape[:2]
                x = int(landmark.x * w)
                y = int(landmark.y * h)
                cv2.circle(frame, (x, y), 1,(0, 255, 0), -1)
```

:::코드설명
- **줄 10** 웹캠이 열려 있는 동안 반복
- **줄 11** 프레임 읽기
- **줄 13** 프레임을 읽지 못했을 경우 메시지 출력
- **줄 14** 다음 반복으로 넘어가기
- **줄 17** 좌우 반전
- **줄 18** BGR → RGB 색상 변환
- **줄 19** FaceMesh 모델로 얼굴 랜드마크 추출
- **줄 22** 얼굴이 감지되었을 때
- **줄 23** 첫 번째 얼굴의 랜드마크 순회
- **줄 24** 프레임의 높이와 너비 가져오기
- **줄 25** 랜드마크 x 좌표 → 픽셀 좌표 변환
- **줄 26** 랜드마크 y 좌표 → 픽셀 좌표 변환
- **줄 27** 랜드마크 위치에 초록색 점 그리기
:::

:::말풍선

## 심화 실습 | 얼굴 방향 인식 및 카운트 기능 구현하기

눈과 코 랜드마크 번호

:::그림생략[교과서 57쪽 사진]
눈과 코 둘레의 랜드마크 번호(33번, 263번, 1번)가 표시된 사람 얼굴 일부 사진이에요. 사람의 얼굴이 나와 싣지 않았어요.
:::

MediaPipe의 FaceMesh 모듈은 실시간 얼굴 인식을 위한 :용어[라이브러리]로, 이미지나 영상에서 얼굴을 감지하고, 눈·코·입·윤곽 등 얼굴의 주요 위치(랜드마크)를 3차원 좌표로 추출하는 기능을 제공한다. 하나의 얼굴에 대해 총 478개의 랜드마크를 제공하며, 이 정보를 이용해 얼굴의 방향이나 표정 등을 분석할 수 있다.

이 프로그램은 페이스 메시를 활용하여 사용자의 고개가 어느 방향(왼쪽, 오른쪽, 정면)을 향하고 있는지를 실시간으로 판별하는 기능을 제공한다. 고개 방향을 판단하기 위해 눈과 코의 위치 정보를 활용하며, 특히 왼쪽 눈(33번), 오른쪽 눈(263번), 그리고 코(1번) 랜드마크를 기준으로 한다.

**고개 방향 판정 알고리즘**

**❶ 눈 중심 계산**

먼저, 고개가 어느 방향을 향하고 있는지를 알아보기 위해 눈의 중심 위치를 계산한다. 이는 왼쪽 눈의 x 좌표와 오른쪽 눈의 x 좌표의 평균값으로 구할 수 있다.

x<sub>eye_center</sub> = (x<sub>left_eye</sub> + x<sub>right_eye</sub>) ÷ 2

**❷ 눈 중심과 코 위치 차이 계산**

눈 중심과 코의 상대적인 위치를 계산한다. 즉, 코의 x 좌표에서 눈 중심의 x 좌표를 뺀 값(Δx)을 구한다.

Δx = x<sub>nose</sub> − x<sub>eye_center</sub>

**❸ 고개 방향 판정 기준**

Δx값을 통해 고개의 방향을 다음과 같이 판단할 수 있다.

- Δx가 음수이고 일정 기준(:용어[임곗값])보다 작다면 → Left(왼쪽)
- Δx가 양수이고 일정 기준보다 크다면 → Right(오른쪽)
- Δx의 절댓값이 기준값 이내라면 → Center(정면)

이와 같은 간단한 수학적 계산을 통해 프로그램은 사람의 고개 방향을 정밀하게 예측할 수 있다.

::쪽[58]

### 단계 1 | 모듈 불러오기 및 변수 초기화하기

```

def detect_head_direction(nose_x, eye_center_x, threshold=10):
    diff = nose_x - eye_center_x
    if diff < -threshold:
        return "Left"
    elif diff > threshold:
        return "Right"
    else:
        return "Center"
```
