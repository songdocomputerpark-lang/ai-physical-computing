**10** 다음 프로그램은 OpenCV와 MediaPipe Pose를 이용하여 웹캠 영상에서 사람의 포즈(관절 위치)를 추정한다. 빈칸에 들어갈 코드를 쓰시오.

```python
import cv2
import mediapipe as mp

cap = cv2.VideoCapture(0)
pose = mp.solutions.pose.Pose()

while True:
    ret, frame = cap.read()
    results = pose.process( ____________ )
```

[Tip] OpenCV는 영상을 BGR 형식으로 읽어오지만, MediaPipe Pose는 RGB 영상을 사용한다. 따라서 BGR → RGB 변환이 필요하다.

**11** 다음 프로그램은 SpeechRecognition 라이브러리를 사용하여 마이크 음성을 텍스트로 변환하고 출력한다. 빈칸에 들어갈 코드를 쓰시오.

```python
import speech_recognition as sr

r = sr.Recognizer()
with sr.Microphone() as source:
    audio = r.listen(source)
    command = r.__(audio, language='ko-KR')
    print(command)
```

[Tip] Google Web Speech API를 이용하며, 한국어 인식을 위해 language=’ko-KR’를 지정한다.

**1** 기존 응용 프로그램은 개발자가 작성한 규칙에 따라 작동하며, 새로운 상황에는 규칙을 추가로 프로그래밍해야 한다. 반면 인공지능 응용 프로그램은 데이터로부터 규칙을 스스로 학습해 패턴을 찾아내고, 학습된 모델을 활용해 추론과 예측을 수행한다.

**2** 인공지능 에이전트(Agent)는 환경과 상호 작용하며 목표를 달성하는 시스템으로 기본적으로 환경, 센서, 지능적 처리, 액추에이터 네 가지 구성 요소를 가진다. 개발자는 에이전트의 구성 요소에 포함되지 않는다.

**3** 얼굴 478개 지점을 분석하는 것은 얼굴 랜드마크 감지에 해당한다.

**4** MediaPipe Pose 모델은 인체의 33개 관절 위치(x, y, z 좌표)를 제공한다. y 좌푯값은 작을수록 화면의 위쪽을 의미한다. 따라서 왼손 손목의 y 좌표가 어깨보다 작으면, 즉 화면에서 어깨보다 위에 있으면 손을 든 것으로 판단한다.

**5** ④는 음성 신호 처리에 해당하며, 영상 인식 기술의 사례가 아니다.

**6** 포즈 트래킹은 카메라 프레임을, 음성 인식은 마이크 신호를 입력받아 즉시 처리한다. 두 기술 모두 실시간 분석이 가능하다는 공통점을 가진다. 반면 카메라 입력만이나 마이크 입력만 사용하는 것은 각 기술에만 해당되며, 두 기술 모두 오프라인 전용이 아니고, 학습 데이터 없이 항상 정확히 동작하지는 않는다.

**7** 카메라 영상에서 사람의 주요 관절 위치를 추출하고, 이를 분석해 동작을 인식하는 기술을 포즈 트래킹이라 한다. MediaPipe Pose 모델 등을 활용하면 2D 또는 3D 좌표를 얻을 수 있으며, 이를 통해 운동 분석, 피트니스 코칭, 제스처 기반 제어 등 다양한 응용이 가능하다.

**8** [예시 답안] cv2.flip()

- flipCode = 0 → 상하 반전
- flipCode = 1 → 좌우 반전(거울 모드)
- flipCode = -1 → 상하·좌우 동시 반전

**9** [예시 답안]

눈 주변 랜드마크 좌표를 이용해 Eye Aspect Ratio(EAR)를 계산한다.

MediaPipe FaceMesh는 눈 주변 좌표를 이용해 EAR(눈 종횡비)을 구한다. EAR은 눈의 세로 거리 평균을 가로 거리로 나눈 값이다. 눈을 감으면 세로 길이가 줄어 EAR이 급격히 감소한다. 일정 임곗값 이하로 내려가면 눈을 감은 것으로 판단하며, 연속 프레임 확인과 임곗값 보정을 통해 정확도를 높일 수 있다.

**10** OpenCV의 VideoCapture는 BGR 형식으로 이미지를 제공하지만, MediaPipe Pose의 pose.process()는 RGB 이미지를 사용한다. 따라서 처리 전에 반드시 BGR을 RGB로 변환해야 정확한 랜드마크 검출이 가능하다.

**11** SpeechRecognition 라이브러리는 마이크 입력을 listen()으로 받아 audio 객체에 저장한다. recognize_google() 메서드는 이 음성 데이터를 Google Web Speech API로 전송해 텍스트로 변환한다. language=’ko-KR’ 옵션을 지정하면 한국어 음성을 인식한다. 변환된 결과는 print()를 통해 출력되며, Google API를 사용하므로 인터넷 연결이 필요하다.
