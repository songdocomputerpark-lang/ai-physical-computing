## 학습 목표

- ESP32와 :용어[네오픽셀]의 연결 및 제어 원리를 이해할 수 있다.

- 센서 입력에 따라 네오픽셀 LED의 상태를 동적으로 제어할 수 있다.

## 1 네오픽셀의 이해

:용어[네오픽셀](NeoPixel)은 스마트 RGB LED로, 하나의 LED 안에 빨강(R), 초록(G), 파랑(B) 3가지 색을 조합할 수 있는 소자가 들어 있으며, 디지털 신호로 제어 가능한 칩이 내장된 LED이다.

:::용어풀이[소자]
전자 제품 안에서 특정 역할을 하는 부품 하나를 가리킨다.
:::

각 RGB LED는 0\~255의 밝기 값을 가지고 있다. 네오픽셀의 LED에는 번호(Index)가 있어, 코드에서 np[0], np[1],……,np[15]로 독립적으로 제어할 수 있다.

:::용어풀이[색상 코드 표현 방식]
숫자와 코드를 이용해 색을 표현한다. 컴퓨터 모니터, LED 조명, 휴대폰 화면 등에서 색을 표현할 때 사용된다.

- 숫자 3개로 표시: (예) RGB(255, 0, 0)=빨간색
- 16진수로 표시: (예) #FF0000
:::

:::말풍선
6번째 LED는 np[5]야!
:::

## 2 프로그램 개요

네오픽셀의 기본적인 작동 원리를 이해하고, 네오픽셀과 관련된 기술을 직접 활용하고 경험해 보며, 궁극적으로 다양한 센서와 연동하여 응용하는 능력을 기르는 것을 목표로 한다.

동작 테스트에서는 LED를 순차적으로 점등 및 소등해 보며 네오픽셀의 상태를 확인한다. 기본 과제에서는 네오픽셀의 원리를 이해하기 위한 목적으로 RGB 값을 조합하여 다양한 색상을 특정한 순서대로 출력해 보고, 이를 바탕으로 심화 과제에서는 터치 센서의 4개 버튼을 활용하여 네오픽셀의 색상을 제어하는 스마트 무드 등을 제작해 보는 실습을 한다. 이러한 활동을 통해 최종적으로 센서와 다양한 색상 제어를 이용하여 생활 속 문제를 해결하는 응용 장치를 구현할 수 있는 능력을 키운다.

## 4 동작 테스트

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
from machine import Pin
from neopixel import NeoPixel
from time import sleep
# 핀 연결하기
NUM_OF_LED = 16
np = NeoPixel(Pin(23), NUM_OF_LED)
```

:::코드설명
- **줄 2** ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
- **줄 3** 네오픽셀을 제어하기 위한 모듈 불러오기
- **줄 4** 초 단위로 지연을 주기 위한 함수 불러오기
- **줄 6** 사용할 네오픽셀 LED 개수 16개로 설정
- **줄 7** GPIO 23번 핀에 네오픽셀 연결
:::

### 단계 2 | 장치 설정 및 네오픽셀 제어하기

:::웹정정[np.write()가 없는 첫 반복문]
출판본 149쪽 코드의 첫 반복문(10\~12줄)에는 `np.write()`가 없어요. 색을 정해도 LED로 보내지지 않아 불이 차례로 켜지지 않고, 뒤쪽 반복문에서 `np.write()`를 부를 때 한꺼번에 바뀌어요. 원문은 그대로 두었어요. 실습실 예제(사이트판)는 11번째 줄 아래에 `np.write()`를 더했어요.
:::

```python {start=8}
# 네오픽셀 점등 및 소등 제어하기
while True:
    for i in range(16):
        np[i] = (100, 0, 0)
        sleep(0.1)
    for i in range(15, -1, -1):
        np[i] = (0, 0, 0)
        np.write()
        sleep(0.1)
```

:::코드설명
- **줄 10\~11** LED 16개를 순차적으로 점등(빨간색)하고, 역순으로 소등하는 과정을 반복
- **줄 15** 'np[i]=(R,G,B)'로 설정한 색상 정보를 LED에 전송하는 역할
:::

::실습실[esp32/u2/2-1-5-neopixel-check-site.py]

:::에러체크[네오픽셀 에러 체크 포인트]

| 주요 에러 메시지 | 에러 의미 | 에러 원인 |
| --- | --- | --- |
| ValueError: tuple length must be 3 | RGB 색상 개수 오류 | (R,G,B) 색상 설정 불일치 |
| IndexError: index out of range | 인덱스 범위 초과 | 네오픽셀 인덱스 불일치 |
| ImportError: no module named 'neopixel' | 내장된 모듈이 없음. | 보드에 모듈이 내장되어 있지 않음. |

### 단계 2 | 네오픽셀 설정 및 무지개색 점등 제어하기

| 색상 | RGB 값 |
| --- | --- |
| 빨간색 | (255, 0, 0) |
| 주황색 | (255, 94, 0) |
| 노란색 | (255, 228, 0) |
| 초록색 | (0, 255, 0) |
| 파란색 | (0, 0, 255) |

```python {start=5}

# 네오픽셀 점등 제어하기
while True:
    for i in range(16):
        np[i]=(255, 0, 0)
        np.write()
        sleep(0.1)
    for i in range(15, -1, -1):
        np[i]=(255, 94, 0)
        np.write()
        sleep(0.1)
    for i in range(16):
        np[i]=(255, 228, 0)
        np.write()
        sleep(0.1)
    for i in range(15, -1, -1):
        np[i]=(0, 255, 0)
        np.write()
        sleep(0.1)
    for i in range(16):
        np[i]=(0, 0, 255)
        np.write()
        sleep(0.1)
    for i in range(15, -1, -1):
        np[i]=(0, 0, 75)
        np.write()
        sleep(0.1)
    for i in range(16):
        np[i]=(95, 0, 255)
        np.write()
        sleep(0.1)
```

# 라이브러리 불러오기

- **줄 3** ADC(아날로그 입력)를 제어하기 위한 모듈 불러오기
- **줄 4** 네오픽셀을 제어하기 위한 모듈 불러오기

### 단계 2 | 장치 설정하기

```python {start=6}
# 네오픽셀 설정하기
NUM_OF_LED = 16
np = NeoPixel(Pin(23), NUM_OF_LED)

# 아날로그 터치 입력 설정하기
touch = ADC(Pin(32))
touch.atten(ADC.ATTN_11DB)
touch.width(ADC.WIDTH_12BIT)
```

:::코드설명
- **줄 8** GPIO 23번 핀에 네오픽셀 연결
- **줄 12** 0\~3.3 V, 전압 범위 최대 3.3 V까지 확장
- **줄 13** 0\~4095, 해상도 12비트로 설정
:::

### 단계 3 | 무드 등 색상 설정하기

```python {start=14}
# 무드 등 색상 정의하기
colors = {
    "Button 1": (255, 0, 0),
    "Button 2": (0, 255, 0),
    "Button 3": (0, 0, 255),
    "Button 4": (0, 0, 0)
}

# 네오픽셀 색상 적용 함수
def set_color(rgb):
    for i in range(NUM_OF_LED):
        np[i] = rgb
    np.write()
```

:::코드설명
- **줄 16** 빨강
- **줄 17** 초록
- **줄 18** 파랑
- **줄 19** 꺼짐
- **줄 23** 네오픽셀의 16개 LED가 모두 순차적으로 rgb(변수) 색상으로 점등되게 함.
:::

### 단계 4 | 터치 센서 설정하기

```python
# 버튼 감지 함수
def get_button(value):
    if 500 < value < 800:
        return "Button 1"
    elif 1000 < value < 1700:
        return "Button 2"
    elif 2000 < value < 2500:
        return "Button 3"
    elif 3000 < value < 3500:
        return "Button 4"
    else:
        return "None"
```

:::코드설명
- **줄 2** 'get_button(value)' 함수에서의 특정 범위는 터치 센서 또는 아날로그 버튼에서 읽어들인 전압(또는 저항값)이 ADC를 통해 변환된 숫자값의 범위를 의미하며, 특정 범위에 따라 터치 센서 각 4개의 버튼 작동 유무가 구분됨.
:::

### 단계 5 | 터치 센서로 네오픽셀 제어하기

```python {start=13}
# 이전 상태 저장하기
prev_button = "None"

# 메인 루프
while True:
    val = touch.read()
    button = get_button(val)

    if button != prev_button and button in colors:
        print(f"ADC: {val} → {button}")
        set_color(colors[button])
        prev_button = button
        sleep(0.2)

    sleep(0.05)
```

:::코드설명
- **줄 18** 현재 아날로그 값 읽기
- **줄 19** 현재 값에 해당하는 버튼 확인
- **줄 22** 현재 아날로그 값과 버튼 이름 출력
- **줄 23** 해당 색상으로 네오픽셀 점등
- **줄 25** 0.2초 동안 멈춤.
:::
