## 1 인공지능과 하드웨어 사이의 연결

우리가 스마트폰으로 문자를 보내거나, 컴퓨터에서 센서 정보를 확인할 수 있는 이유는 기기 간에 정해진 규칙에 따라 데이터를 주고받기 때문이다. 데이터는 단순한 숫자나 글자 그 자체가 아니라, 컴퓨터와 전자기기 내부에서는 0과 1로 이루어진 전기 신호로 바뀌어 전달된다.

컴퓨터가 주고받는 데이터는 모두 0과 1로 이루어진 :용어[비트](bit)이다. 비트를 8개로 묶어서 1:용어[바이트](byte)로 주고 받는다. 우리가 문자 ‘1’을 보낼 때와 숫자 1을 보낼 때 컴퓨터 내부에서는 서로 다른 바이트 값으로 표현된다.

:::용어풀이[비트(Bit)]
데이터를 이루는 가장 작은 단위이며, 0 또는 1 중 하나의 값을 가짐.
:::

:::용어풀이[바이트(Byte)]
8개의 비트로 이루어진 단위이며, 하나의 문자, 색상, 숫자 등을 저장할 수 있음.
:::

| 구분 | 예시 | 내부 저장 값 |
| --- | --- | --- |
| 문자 ‘1’ | 화면에 보이는 글자 | 0x31 (10진수 49) |
| 숫자 1 | 실제 정숫값 | 0x01 (10진수 1) |

:::말풍선
문자 ‘1’은 10진수 49, 숫자 1은 10진수 1로 서로 다르게 저장돼. 16진수는 ‘0x’를 붙여 “이 값은 16진수”임을 표시해. 예를 들어 0x31은 문자 ‘1’의 ASCII 코드값(십진수 49)이고, 0x01은 숫자 1의 실제 정숫값이야.
:::

## 3 영상 처리 프로그램에서 데이터 송신 방법

인공지능 프로그램은 특징점 좌표(x, y)를 이용해 하드웨어를 제어할 수 있다. 이때 인공지능에서 판단 후 결과만 보내는 방식과 좌표 변수를 보내 하드웨어가 직접 처리하는 방식 두 가지가 있다.

**결괏값만 보내기** 손가락 위치에 따라 ‘a’, ‘b’, ‘c’와 같은 결과 문자를 보낼 수 있다. 이처럼 단순 문자로 전송하면, 수신 측은 조건문으로 하드웨어를 단순 동작으로 손쉽게 제어할 수 있다.

```python
if finger_x < 100:
    b.send('a')
elif finger_x > 500:
    b.send('b')
else:
    b.send('c')
```

**변수로 보내기** 하드웨어 측에서 데이터를 변수로 받으면 더 정밀하게 제어가 가능하다. 변수를 여러 개 전송할 때는 영상 처리 프로그램과 하드웨어 프로그램 사이에 데이터 전송 :용어[프로토콜]을 미리 약속해 두어야 한다. 일반적으로 변수와 변수 사이에 쉼표(,)로 구분한 문자열로 보낸다.

:::용어풀이[프로토콜]
컴퓨터, 기기, 시스템 등에서 데이터를 교환하기 위한 규칙 체계로, 서로 다른 장치들이 원활하게 소통할 수 있도록 정의된 약속 또는 규약
:::

```python
b.send('f{finger_x}, {finger_y}\n')
```

:::웹정정[f 문자열의 f 위치]
출판본 186쪽의 이 코드는 `'f{finger_x}, {finger_y}\n'`처럼 f가 따옴표 안쪽에 들어 있어요. 좌푯값이 글자로 들어가려면 f가 따옴표 앞에 있어야 해요(`f'{finger_x}, {finger_y}\n'`). 원문은 그대로 두었어요.
:::

:::용어풀이[\n (줄바꿈 문자)]
“메시지의 끝”을 나타내는 기호
:::

영상 처리 프로그램은 조건에 맞으면 x, y 좌푯값을 지속적으로 전송한다. 이때 메시지의 끝을 알리기 위해 마지막에 종료 문자(\n)를 붙인다. 이렇게 하면 하드웨어는 데이터를 한 줄 단위로 구분해 읽을 수 있고, 쉼표를 기준으로 손쉽게 값을 나눌 수 있다.

예를 들어 ‘120,250\n124,278\n...’와 같은 메시지를 받으면, 하드웨어는 \n 전까지의 ‘120,250’을 하나의 문자열로 해석한 뒤, 쉼표를 기준으로 120과 250 두 숫자로 나누어 활용할 수 있다.

::쪽[187]

## 4 하드웨어에서 데이터 수신 방법

Python에서 전송된 데이터는 ESP32에 도착할 때 바이트(bytes) 형태 그대로 입력된다. 따라서 처음 수신한 값은 원시값(raw data)이며, x와 y 값이 문자열로 묶여 있는 상태로는 바로 사용할 수 없다. 미리 약속된 프로토콜에 따라 쉼표를 기준으로 분리하고, 정수로 바꿔 변수에 저장한 다음 조건에 따라 활용한다.

| 순 | 처리 단계 | 코드 예시 | 설명 |
| --- | --- | --- | --- |
| 1 | 문자열 분리 | values = data.split(‘,’) | 쉼표 기준으로 값 나누기 |
| 2 | 변수 저장 | x = int(values[0])<br>y = int(values[1]) | 문자열 → 정수 |
| 3 | 값 활용 | print(x, y) | 좌표를 하드웨어 제어에 활용 |

**데이터 수신과 :용어[파싱]**

```python
data = ble.read()
if data:
    values = data.split(',')
    x = int(values[0])
    y = int(values[1])
    print(x, y)
```

:::코드설명
- **줄 1** 데이터 읽기
- **줄 3** 쉼표로 나누기
- **줄 4** 첫 번째 값 정수 변환
- **줄 5** 두 번째 값 정수 변환
- **줄 6** 변환된 값 확인
:::

:::용어풀이[파싱]
문자열이나 복잡한 데이터를 일정한 규칙(예 쉼표)을 기준으로 나누어, 각 정보를 프로그램이 사용할 수 있도록 분리하고 해석하는 과정이다.
:::

영상 처리 프로그램은 보통 무한 반복으로 값을 계속 전송한다. 이때 ESP32 입력 버퍼에 데이터가 과도하게 쌓이면, 실제 동작이 1초 이상 늦게 나타나는 지연(delay) 현상이 발생할 수 있다. 이를 방지하기 위해 두 가지 방법을 사용할 수 있다.

- 이전에 보낸 값과 현재 값을 비교하고 값이 달라질 때만 전송한다.
- ‘1초에 10번만 전송’과 같이 전송 횟수를 제한한다.

| 전송 방식 | 특징 | 장단점 |
| --- | --- | --- |
| 무한 반복 전송 | 계속 모든 프레임 전송 | 데이터 쌓임 → 지연 발생 |
| 변화 시 전송 | 값이 달라질 때만 전송 | 불필요한 데이터 줄고 반응 속도 ↑ |

파이썬에서 데이터를 전송할 때는 반드시 메시지 끝에 줄바꿈 문자(\n)를 붙여야 한다. 이렇게 해야 ESP32가 한 줄 단위로 메시지를 구분해 읽을 수 있고, 통신 오류도 줄어든다. 이 방식은 수신 오류를 줄이고, LED·LCD·서보모터와 같은 출력 장치를 안정적으로 제어하는 데 도움이 된다.

::쪽[188]

## 5 시리얼과 블루투스 통신의 공통 원리

데이터 전송 경로가 USB 시리얼 통신이나 블루투스일 때 모두 보낼 때는 문자열을 bytes로 변환하고 받을 때는 이를 분리·변환하는 공통 원리를 따른다. 파이썬과 ESP32의 원리는 다음과 같다.

:::용어풀이[USB 시리얼 통신(USB Serial Communication)]
데이터를 한 비트씩 순서대로 주고받는 유선 통신 방식이다. 두 장치 간 직접 연결 방식으로 단순하고 안정적이라는 특징이 있다.
:::

:::용어풀이[블루투스(Bluetooth)]
짧은 거리에서 데이터를 무선으로 주고받는 근거리 통신 방식이다.
:::

**파이썬** 문자열을 bytes로 변환해 전송한다.

**ESP32** 수신한 bytes를 문자열로 해석하고, 쉼표로 나눈 뒤 정수(int)로 변환해 변수에 저장한다.

영상 처리는 파이썬으로 이루어지므로, 통신을 위해 별도의 라이브러리가 필요하다. 시리얼과 블루투스의 경우 다음과 같은 라이브러리를 설치하여 사용한다.

**시리얼 통신** bleak 라이브러리 사용

**블루투스 통신** bleak 라이브러리 사용

:::용어풀이[bleak]
파이썬에서 블루투스 기능을 사용할 수 있게 해 주는 라이브러리이다.
:::

:::웹정정[시리얼 통신의 라이브러리]
출판본 188쪽은 시리얼 통신과 블루투스 통신 둘 다 bleak 라이브러리를 쓴다고 적었어요. bleak는 블루투스(BLE)용이라서, 이 책의 시리얼 실습(189~194쪽)은 `import serial`(pyserial)을 써요. 원문은 그대로 두었어요.
:::

반면, 하드웨어 측은 마이크로 파이썬으로 처리된다. ESP32는 시리얼(UART)과 블루투스(Bluetooth) 기능을 이미 내장하고 있어, 별도 설치 없이 바로 호출해 사용할 수 있다.

:::해보기[데이터 변환과 전송 과정 이해하기]

2. 영상 처리 결과를 전송할 때 단일 문자, 단일 변수, 복수 변수 등 어떤 형태로 데이터를 보내야 하는지 상황별로 정리해 보자.
