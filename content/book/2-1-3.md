:::용어풀이[I2C]

:::

## 1 OLED의 이해

:용어[OLED](Organic Light-Emitting Diode)는 유기 화합물 층이 전류가 흐를 때 빛을 내는 디스플레이다. OLED 각 :용어[픽셀]이 자체적으로 빛을 내므로 백라이트가 필요하지 않으며 LCD에 비해 높은 명암비와 빠른 응답 속도, 넓은 시야각 등의 장점을 가지고 있다.

ESP32에 연결하는 LCD는 주로 문자와 숫자를 표시하는 데 적합하여 텍스트 중심의 간단한 정보를 출력하는 장치로 많이 사용된다. 반면, OLED는 픽셀 단위로 제어할 수 있어 글자뿐만 아니라 점, 선, 도형, 이미지 등 다양한 그래픽과 시각적 표현이 가능한 출력 장치이다.

## 2 프로그램 개요

다양한 실습형 과제를 통해 OLED의 기본적인 작동 원리를 이해하고, OLED를 직접 활용해 본 경험을 바탕으로 응용 시스템을 구현하는 것을 목표로 한다.

동작 테스트 단계에서는 OLED에 문자를 출력하여 화면의 정상 작동 여부를 점검한다. 기본 과제에서는 선, 사각형 등 그래픽 요소를 제어하는 방법을 익히고, 화면에 간단한 이미지를 직접 그려봄으로써, OLED 제어 방법을 학습한다. 심화 과제에서는 터치 센서를 활용하여 이미지 출력 제어 방법을 실습함으로써, OLED를 다양한 상황과 목적에 맞게 활용하는 능력을 기른다.

### 단계 5 | OLED에 다양한 방식으로 출력하기

```python
# 라이브러리 불러오기
from machine import Pin
from machine import SoftI2C
from sh1106 import SH1106_I2C
from time import sleep_ms

# 화면 초기화하기
i2c = SoftI2C(scl=Pin(22), sda=Pin(21))

# OLED 초기화 (128x64 기준)
oled = SH1106_I2C(128, 64, i2c)
# 화면 지우기
oled.fill(0)
```

- **줄 2** ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
- **줄 3** I2C 통신을 사용하기 위한 모듈 불러오기
- **줄 4** OLED 제어 함수가 포함된 외부 라이브러리 불러오기
- **줄 5** 밀리초 단위로 지연을 주기 위한 함수 불러오기
- **줄 7** I2C의 클럭 신호를 보내는 SCL 핀을 GPIO 22번에 설정, I2C의 데이터 신호를 주고받는 SDA 핀을 GPIO 21번에 설정
- **줄 10** 기본 I2C 주소 0x3C를 사용, 해상도 128×64 픽셀의 OLED 디스플레이 객체 생성

### 단계 1 | 터치 센서를 통해 출력값 변화시키기

:::말풍선
ADC(Analog to Digital Converter)는 아날로그 신호(연속적인 값)를 디지털 신호(이진수)로 바꿔 주는 장치야.
:::

```python
from machine import ADC, Pin
from time import sleep

# SIG 핀을 아날로그 입력으로 설정하기
touch = ADC(Pin(32))
touch.atten(ADC.ATTN_11DB)
touch.width(ADC.WIDTH_12BIT)

# 버튼별 전압 범위 설정하기
def get_button(value):
    if 300 < value < 800:
        return "Button 1"
    elif 1000 < value < 1600:
        return "Button 2"
    elif 1800 < value < 2400:
        return "Button 3"
    elif 3000 < value < 4200:
        return "Button 4"
    else:
        return "No touch"
while True:
    val = touch.read()
    button = get_button(val)
    print(f"ADC: {val} → {button}")
    sleep(0.2)
```

:::코드설명
- **줄 5** GPIO 32번 핀을 아날로그 입력으로 설정
- **줄 6** 전압 범위를 최대 3.3 V까지 측정 가능하도록 설정
- **줄 7** 0\~4095 범위
- **줄 11\~12** 전압 범위가 300\~800 사이일 때, 버튼 1이 터치되었다고 판별
- **줄 13\~14** 전압 범위가 1000\~1600 사이일 때, 버튼 2가 터치되었다고 판별
- **줄 15\~16** 전압 범위가 1800\~2400 사이일 때, 버튼 3이 터치되었다고 판별
- **줄 17\~18** 전압 범위가 3000\~4200 사이일 때, 버튼 4가 터치되었다고 판별
- **줄 23\~24** 'get_button()' 함수는 측정된 아날로그 값을 기반으로 어떤 버튼이 눌렸는지 판별
:::

:::말풍선
코드 본문에서 ADC는 장치를 의미하는 것이 아니라(물론 장치도 있지만) GPIO 32에 연결된 터치 센서나 신호를 0 V\~3.3 V 같은 아날로그 전압으로 읽어서 0\~4095 범위의 디지털 값으로 변환해 주는 마이크로파이썬 라이브러리에서 제공하는 클래스명이야.
:::

### 단계 4 | 함수 설정하기

```python {start=20}
# RGB LED 색상 설정 함수
def set_color(r_val, g_val, b_val):
    r.duty(r_val * 4)
    g.duty(g_val * 4)
    b.duty(b_val * 4)
# 버튼 판별 함수
def get_button(value):
    if 1000 < value < 1200:
        return "Button 1"
    elif 2000 < value < 2500:
        return "Button 2"
    elif 3500 < value < 4000:
        return "Button 3"
    elif 4000 < value < 4200:
        return "Button 4"
    else:
        return "No touch"
```

- **줄 26** 'get_button(value)' 함수에서의 특정 범위는 터치 센서 또는 아날로그 버튼에서 읽어들인 전압(또는 저항값)이 ADC(아날로그-디지털 변환기)를 통해 변환된 숫자값의 범위를 의미하며, 특정 범위에 따라 터치 센서 각 4개의 버튼 작동 유무가 구분됨.

::::읽기자료[인공지능을 세상에 비춰줄 미래의 큰 주역, OLED 디스플레이]
**AI로 읽는 세상**

우리는 이미 인공지능을 스마트폰의 음성 비서, 자율주행 자동차, 스마트 홈 기기 등을 통해 다양한 방법으로 이용하고 있다. 우리가 인공지능을 사용하거나 인공지능과 정보를 주고받기 위해서는 소통 도구가 필요한데, 이 중요한 역할을 하는 것이 바로 디스플레이이며 그 중심에 떠오르고 있는 기술이 OLED이다.

OLED(유기 발광 다이오드)는 스스로 빛을 내기 때문에 백라이트가 필요 없어 얇고 가벼운 화면을 구현할 수 있는데, 유연한 기판과 초박막 기술을 적용하면 화면을 구부리거나 접을 수도 있다. 즉, 단순히 얇은 화면이 아니라, 휘어지고 접히는 ‘플렉시블 디스플레이’가 가능하게 된 것이다.

인공지능에 플렉시블 디스플레이를 결합하면 더 큰 가치를 만들 수 있다. 자동차의 곡면 디스플레이는 인공지능이 수집하고 분석한 교통 정보를 운전자에게 직관적으로 전달하고, 웨어러블 기기와 스마트 헬스케어 장비를 몸에 밀착해 연결하면 스마트폰의 인공지능 서비스를 눈으로 보고 귀로 듣고 몸으로 느끼며 체험할 수 있다.
