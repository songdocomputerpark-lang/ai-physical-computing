## 학습 목표

- EAR 공식을 활용하여 눈 깜빡임을 정확하게 감지하는 시스템을 구현할 수 있다.
- 왼쪽 눈과 양쪽 눈의 깜빡임을 구분하여 각각 다른 명령으로 매핑할 수 있다.
- 오감지를 방지하고 사용자의 의도를 정확히 파악하는 알고리즘을 설계할 수 있다.

## 1 눈 깜빡임으로 마우스 제어하기

눈을 이용한 제어 방식은 깜빡임을 신호로 활용한다. 왼쪽, 오른쪽, 양쪽 눈을 각각 깜빡이는 방식으로 세 가지의 제어 신호를 구분할 수 있다. 단순히 눈꺼풀 사이의 거리로 판단할 수도 있지만, 보다 정확한 제어를 위해 눈의 종횡비(:용어[EAR], Eye Aspect Ratio)를 활용한다.

EAR는 눈의 수직 길이와 수평 길이의 비율을 계산하여 눈이 열려 있는지 감겨 있는지를 판단하는 방식이다. 예를 들어, 왼쪽 눈은 [33, 160, 158, 133, 153, 144]의 6개 :용어[랜드마크]를 통해 EAR를 계산할 수 있다. 이를 통해 사용자의 눈 깜빡임을 정밀하게 감지하고, 마우스 클릭 신호로 변환할 수 있다.

:::그림생략[교과서 232쪽 사진: 눈 그림(점 P1~P6 표시)]
출판본 232쪽의 눈 그림은 저작권 때문에 이 사이트에는 싣지 못했어요. 책 232쪽에서 보세요.
:::

**EAR 계산 공식**

`EAR = (|P2-P6| + |P3-P5|) / (2 * |P1-P4|)`

P1, P4: 눈의 양쪽 끝 / P2, P3, P5, P6: 눈의 위아래 점들

## 2 눈 깜빡임으로 마우스 제어하기 프로그램 개요

이 활동에서는 눈 깜빡임으로 마우스 커서를 제어할 수 있는 프로그램을 완성해 본다. 먼저 사용자의 얼굴에서 콧등의 위치를 기준으로 얼굴 중심 좌표를 추출하고, 기준점으로부터의 이동량을 계산한다. 그 이동량을 사용 중인 모니터의 해상도와 매핑하여, 얼굴의 움직임이 커서 위치에 반영되도록 한다.

클릭을 수행하기 위해 EAR값을 계산하여 눈을 떴을 때는 0, 감았을 때는 1로 상태를 구분한다. 이 값을 활용해 PyAutoGUI로 마우스 클릭을 실행함으로써 마우스를 제어할 수 있다.

### 단계 3 | EAR 계산 함수 정의하기

```python {start=32}
# EAR 계산 함수 정의
def calculate_ear(eye_points, landmarks, frame_width, frame_height):
    points = []
    for point_id in eye_points:
        x = int(landmarks.landmark[point_id].x * frame_width)
        y = int(landmarks.landmark[point_id].y * frame_height)
        points.append((x, y))

    def distance(p1, p2):
        return ((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)**0.5

    A = distance(points[1], points[5])
    B = distance(points[2], points[4])
    C = distance(points[0], points[3])
    ear = (A + B) / (2.0 * C)
    return ear
```

### 단계 3 | EAR 계산 함수 정의하기
```python {start=37}
# EAR 계산 함수 정의
def calculate_ear(eye_points, landmarks, frame_width, frame_height):
    points = []
    for point_id in eye_points:
        x = int(landmarks.landmark[point_id].x * frame_width)
        y = int(landmarks.landmark[point_id].y * frame_height)
        points.append((x, y))

    def distance(p1, p2):
        return ((p1[0] - p2[0]) ** 2 + (p1[1] - p2[1]) ** 2) ** 0.5

    A = distance(points[1], points[5])
    B = distance(points[2], points[4])
    C = distance(points[0], points[3])
    ear = (A + B) / (2.0 * C)
    return ear
```

- EAR값이 특정 임곗값 이하로 떨어졌을 때, 눈을 깜빡인 것으로 정확하게 인식되었다.
- 왼쪽 눈만 감을 경우 PyAutoGUl를 이용해 더블 클릭 이벤트가 정상적으로 실행되었다.
- 양쪽 눈을 동시에 감을 경우 PyAutoGUI를 이용해 우 클릭 이벤트가 정상적으로 실행되었다.
- 눈 깜빡임에 따른 클릭 이벤트는 과잉 반응 없이 딜레이 또는 조건 처리로 안정적으로 제어되었다.

:::학습활동[실생활에서 활용할 수 있는 눈 깜빡임으로 제어하는 프로그램 만들기]
완성한 눈 깜빡임으로 클릭하기 프로그램을 기반으로, 생성형 인공지능을 활용해 실생활에 활용할 수 있도록 기능을 발전시켜 보자.

1. 평상시 눈 깜빡임이 마우스 더블 클릭이나 우 클릭으로 오작동하지 않도록, 0.3초 이상 지속되는 눈 감김만 클릭으로 인식하도록 개선해 보자.

   눈 깜빡임의 임곗값을 조정하면 제어를 위한 깜빡임인지, 반사 신경에 의한 깜빡임인지 구분할 수 있다.

2. 코드의 주요 기능을 함수로 나누어 구조화하여 가독성을 높여 보자.

   `detect_blink()` 함수는 EAR 계산 및 깜빡임 판단을 담당하고, `click_mouse()` 함수는 실제 클릭 동작을 담당하도록 구성하면 코드를 더 명확하게 이해할 수 있다.

3. 눈 감김 외에도 사용자의 피로 상태를 종합적으로 분석하여 다양한 동작을 실행하는 프로그램으로 발전시켜 보자.

   예 생성형 인공지능을 이용하여 사용자의 얼굴 표정(하품, 눈 처짐, 고개 떨굼 등)을 인식하면 “피곤해 보이네요, 잠시 쉬는 건 어때요?”라는 메시지를 띄우는 기능 추가

4. 이 프로그램이 실생활에서 어떻게 활용될 수 있을지 조사하고, 그 가능성을 정리해 보자.

   예 손을 쓰기 어려운 장애인을 위한 눈 깜빡임 기반의 클릭 보조 시스템
