## 학습 목표

- ESP32와 MP3 플레이어의 연결 및 제어 원리를 이해할 수 있다.
- 마이크로파이썬을 활용하여 MP3 파일을 재생, 정지, 볼륨 조절 등의 기능을 명령으로 제어할 수 있다.
- 센서나 입력 장치와 연동하여 MP3 플레이어의 동작을 동적으로 제어할 수 있다.

## 1 MP3의 이해

MP3 플레이어는 MP3 파일을 재생할 수 있는 소형 모듈로, 스피커나 이어폰을 바로 연결하여 음악이나 소리를 출력할 수 있다.

:::용어풀이[MP3 모듈]
MP3 모듈은 MP3 파일을 재생할 수 있는 소형 오디오 재생 모듈로, MP3 디코더, microSD 카드 리더기, 오디오 앰프 회로를 모두 내장하고 있어서, 마이크로컨트롤러와 간단한 직렬 통신(UART)만으로 소리를 출력할 수 있다.
:::

MP3 플레이어는 마이크로 SD 카드에 저장된 MP3 파일을 제어 신호로 선택 및 재생할 수 있으며, 별도의 복잡한 MP3 :용어[디코딩] 장치 없이도 소리를 출력할 수 있어 ESP32 등과 같은 마이크로컨트롤러와 쉽게 연동할 수 있다.

:::용어풀이[디코딩]
압축 또는 암호화되거나 어떤 규칙에 따라 변환된 데이터를 원래의 형태로 되돌리는 과정이다.
:::

## 2 프로그램 개요

MP3 플레이어 회로를 구성하여 음악을 재생해 보면서 MP3 플레이어의 기본적인 작동 원리에 대해 이해하고, 다양한 방법으로 MP3 플레이어를 제어하는 활동을 해 보고 궁극적으로 응용 시스템을 구현하는 것을 목표로 한다.

동작 테스트 단계에서는 음악을 재생하면서 출력 상태를 점검하고 장치가 정상적으로 작동하는지 확인한다.

기본 과제에서는 음성 파일을 이용해 재생, 정지, 반복, 볼륨 조절 등을 제어하여 자동 음성 안내 시스템을 만들어 본다. 심화 과제에서는 터치 센서를 활용해 음악 트랙 및 재생을 제어하는 활동을 한다. 이러한 활동을 통해 다양한 상황에 맞게 MP3 플레이어를 활용하는 능력을 키운다.


:::코드설명
- **줄 2\~3** 직렬 통신(UART)을 하기 위한 모듈, ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
:::

### 단계 2 | 장치 설정 및 MP3 제어하기

```python {start=4}
# DFPlayer 연결용 UART 설정하기
uart = UART(2, baudrate=9600, tx=Pin(17), rx=Pin(16))

# MP3 제어하기
def send_cmd(cmd, p1=0, p2=0):
    command = bytearray(10)
    command[0] = 0x7E
    command[1] = 0xFF
    command[2] = 0x06
    command[3] = cmd
    command[4] = 0x00
    command[5] = p1
    command[6] = p2
    command[7] = 0xEF
    uart.write(command)

# MP3 재생(001.mp3)하기
send_cmd(0x03, 0x00, 0x01)
sleep(5)
send_cmd(0x16)
```

:::코드설명
- **줄 5** UART 2포트 사용, 9600bps 속도로 통신 설정, GPIO 17번 핀을 송신, 16번 핀을 수신으로 설정
- **줄 8** 'def send_cmd(cmd, p1=0, p2=0)' 함수는 DFPlayer에 명령을 전송, cmd는 실행할 명령 코드(재생, 정지, 볼륨 등), p1, p2는 명령어 매개 변수
- **줄 10** 시작 바이트
- **줄 11** 버전 정보
- **줄 12** 명령어 길이(6바이트)
- **줄 13** 실행할 명령 코드
- **줄 14** 피드백 설정
- **줄 15** 첫 번째 매개 변수
- **줄 16** 두 번째 매개 변수
- **줄 17** 종료 바이트
- **줄 21\~23** '0x03'는 'Play track' 명령어, 'p1=0x00'는 피드백 받지 않음(0x01: 피드백 받음.), 'p2=0x01'는 트랙 1번 재생(001.mp3). 'Stop, send_cmd(0x16)'은 음악 정지 명령
:::

## 기본 실습 | 자동 음성 안내 시스템 만들기

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
from machine import UART, Pin
from time import sleep
```

:::코드설명
- **줄 2\~3** 직렬 통신(UART)을 하기 위한 모듈, ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기

### 단계 2 | 장치 설정 및 MP3 파일 제어하기

```python {start=4}
# DFPlayer 연결용 UART 설정하기
uart = UART(2, baudrate=9600,\
            tx=Pin(17), rx=Pin(16))

def send_cmd(cmd, p1=0, p2=0):
    uart.write(bytearray(\
        [0x7E, 0xFF, 0x06,\
        cmd, 0x00, p1, p2, 0xEF]))

# 음성 파일 제어하기
while True:
    # 볼륨 설정
    send_cmd(0x06, 0x00, 10)
    sleep(1)
    # 001.mp3 재생
    send_cmd(0x03, 0x00, 0x01)
    print("안내 방송 출력")
    sleep(10)
```

:::코드설명
- **줄 5** UART 2포트 사용, 9600bps 속도로 통신 설정
- **줄 6** GPIO 17번 핀을 송신, 16번 핀을 수신으로 설정
- **줄 8** DFPlayer에 명령을 전송, cmd는 실행할 명령 코드(재생, 정지, 볼륨 등), p1, p2는 명령어 매개 변수
- **줄 16** '0x06'은 볼륨 설정 명령어, '0x00'은 DFPlayer로부터 피드백 메시지 받지 않음, 10: 볼륨 10으로 설정
- **줄 19** '0x03'은 MP3 파일 재생 명령어, '0x00'은 피드백 받지 않음, '0x01'은 001.mp3(첫 번째 파일)을 재생
- **줄 21** 10초마다 반복

## 심화 실습 | 터치 센서로 작동하는 MP3 플레이어 만들기

터치 센서로 작동하는 MP3 플레이어를 만들어 보자.

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
from machine import ADC, Pin, UART
from time import sleep
```

:::코드설명
- **줄 2** ADC(아날로그 입력), UART(직렬 통신), Pin(핀) 모듈 불러오기
:::

### 단계 2 | 장치 설정 및 제어하기

:::연결레시피[터치 센서 연결하기]

| 터치 센서 | 실드 |
| --- | --- |
| GND | GND |
| VCC | VCC |
| S | 21번 핀 |

:::

:::말풍선
0x01은 001.mp3(첫 번째 파일)을 재생, 0x16은 재생을 중지하라는 명령어야.
:::

:::웹정정[터치 센서 연결 핀과 코드의 핀 번호]
출판본 164쪽의 연결 표는 터치 센서의 S를 실드의 21번 핀에 꽂도록 적었지만, 같은 쪽의 코드는 `ADC(Pin(32))`로 32번 핀을 읽어요. 앞 절의 4채널 터치 센서 실습(2-1-3·2-1-5)도 32번 핀이에요. 원문은 그대로 두었어요. 실습실 예제는 32번 핀에 4채널 터치 센서를 이어요.
:::

```python {start=4}
# UART 설정하기 (DFPlayer Mini)
uart = UART(2, baudrate=9600,\
            tx=Pin(17), rx=Pin(16))

# ADC 입력 설정하기
adc = ADC(Pin(32))
adc.atten(ADC.ATTN_11DB)
adc.width(ADC.WIDTH_12BIT)

# 트랙 번호 및 상태
track_num = 1
prev_button = 0

# DFPlayer 명령 전송 함수
def send_cmd(cmd, p1=0, p2=0):
    uart.write(bytearray(\
        [0x7E, 0xFF, 0x06, cmd, 0x00,\
        p1, p2, 0xEF]))

# n번 트랙 재생하기
def play_track(n):
    send_cmd(0x03, 0x00, n)

# 재생 중지하기
def stop_track():
    send_cmd(0x16)

# 버튼 판별 함수
def get_button(adc_val):
    if 500 < adc_val < 800:
        return 1
    elif 1200 < adc_val < 1700:
        return 2
    else:
        return 0
```

:::코드설명
- **줄 5** UART 2포트 사용, 9600bps 속도로 통신 설정
- **줄 6** GPIO 17번 핀을 송신, 16번 핀을 수신으로 설정
- **줄 9** ESP32의 GPIO 32번 핀에 연결하여 아날로그 입력을 디지털로 변환 설정
- **줄 10** 전압 범위 최대 3.3 V까지 확장
- **줄 11** 해상도 12비트로 설정
- **줄 15** 이전 버튼 상태
- **줄 25\~26** '0x03'은 MP3 파일 재생 명령어, '0x00'은 DFPlayer로부터 피드백 메시지 받지 않음.
- **줄 34** 다음 곡 버튼
- **줄 36** 정지 버튼
:::

::쪽[165]

### 단계 3 | 터치 센서로 파일 제어 설정하기

```python
# 터치 센서 및 파일 제어하기
while True:
    val = adc.read()

    # 현재 아날로그 전압값 읽기
    print("ADC 값:", val)
    btn = get_button(val)

    # 다음 곡 버튼 눌림 감지하기
    if btn == 1 and prev_button == 0:
        track_num += 1
        if track_num > 3:
            track_num = 1
        print("▶ 다음 곡:", track_num)
        play_track(track_num)
        sleep(0.5)

    # 정지 버튼 눌림 감지하기
    if btn == 2 and prev_button == 0:
        print("▣ 정지")
        stop_track()
        sleep(0.5)

    prev_button = btn
    sleep(0.1)
```

:::코드설명
- **줄 3** 현재 아날로그 센서값 읽기
- **줄 6\~7** 값 확인용 출력, 어떤 버튼인지 판별
:::
