## 1 RGB LED와 레이저

하나의 LED 소자에 빨간색(R), 초록색(G), 파란색(B) 세 가지 LED가 함께 들어 있는 것을 RGB LED라고 한다. 빛의 삼원색 원리를 활용하여 이 세 가지 색의 밝기를 조절함으로써, 다양한 색상을 표현할 수 있다.

:::용어풀이[LED의 발광 원리]
LED는 N형 반도체와 P형 반도체가 맞닿은 구조로 되어 있다. 전압을 가하면 P형의 정공과 N형의 전자가 만나 빛을 방출한다. 이때 두 반도체의 에너지 차이에 따라 빛의 색이 달라지는데, 차이가 크면 파란색 계열, 차이가 작으면 붉은색 계열의 빛이 나온다.

![위쪽 파란 P형 층의 정공과 아래쪽 분홍 N형 층의 전자가 만나는 모습을 그린 그림. 위로는 빛 화살표가, 아래로는 열 화살표가 나가고 양극(+)과 음극(-) 표시가 있다](/images/lessons/2-1-4/led-emission-diagram.webp "교과서 142쪽")
:::

레이저 내부에는 레이저 매질이 있으며, 양쪽 끝에는 완전 반사 거울과 부분 반사 거울로 구성된 공진기가 있다. 외부에서 에너지를 공급하면 매질이 빛을 방출하고, 이 빛이 공진기 안에서 반복 반사되며 증폭되어 강한 레이저 광선이 된다.

:::용어풀이[레이저 매질]
- 레이저 장치 안에서 빛(광자)을 만들어내고, 증폭시키는 역할을 하는 물질이다.
- 매질 상태로는 고체, 액체, 기체, 반도체가 있다.
:::

:::용어풀이[공진기]
레이저 안에서 빛이 계속해서 반사되며 증폭되도록 만들어진 구조를 말한다.
:::

## 2 프로그램 개요

RGB LED와 레이저의 기본적인 작동 원리를 이해하고 제어하는 활동을 하고, 응용 시스템을 구현하는 것을 목표로 한다.

동작 테스트에서는 RGB LED를 연결하여 다양한 색상을 출력하고, 레이저 장치를 연결하여 출력 제어를 해 본다. 기본 활동에서 PWM 제어 기술을 활용하여 RGB LED의 밝기가 연속적으로 변화하는 장치와 레이저 모듈을 연동하여 RGB LED가 순서대로 색이 변화하는 장치를 구현해 본다.

이러한 활동을 통해 최종적으로 창의적인 색상 표현 및 센서 연동 등을 응용하여 구현할 수 있는 능력을 키운다.

## 4 RGB LED 동작 테스트하기

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
from machine import Pin
from time import sleep
```

### 단계 2 | 장치 설정 및 RGB LED 색상 출력 제어하기하기

:::웹정정[제어하기하기]
출판본 143쪽 단계 2의 제목은 "제어하기하기"로 적혀 있어요. "제어하기"의 '하기'가 한 번 더 들어간 오타로 보여요. 원문은 그대로 두었어요.
:::

```python {start=4}
# 핀 연결하기
r=Pin(27,Pin.OUT)
g=Pin(32,Pin.OUT)
b=Pin(33,Pin.OUT)

# 색상 출력하기
led=[r,g,b]
while True:
    for x in range(3):
        print(x)
        led[x].on()
        sleep(0.2)
        led[x].off()
        sleep(0.2)
```

:::코드설명
- **줄 5** 빨간색(R) LED 핀: GPIO 27
- **줄 6** 초록색(G) LED 핀: GPIO 32
- **줄 7** 파란색(B) LED 핀: GPIO 33
- **줄 10** 리스트 led에 각 색상의 핀 객체 저장
:::

## 기본 실습 | RGB LED로 사이렌 표현하기

RGB LED가 사이렌처럼 밝기가 연속적으로 변하는 프로그램을 만들어 보자.

### 단계 1 | 프로그램 준비하기

```python
# 라이브러리 불러오기
from machine import Pin
from machine import PWM
from time import sleep
```

### 단계 2 | 장치 설정하기

```python {start=5}
# 핀 연결하기
r = PWM(Pin(27))
g = PWM(Pin(32))
b = PWM(Pin(33))
```

:::코드설명
- **줄 6** GPIO 27번 핀을 PWM 출력을 사용하는 빨간색(R) 핀으로 설정
- **줄 7** GPIO 32번 핀을 PWM 출력을 사용하는 초록색(G) 핀으로 설정
- **줄 8** GPIO 33번 핀을 PWM 출력을 사용하는 파란색(B) 핀으로 설정
:::

### 단계 3 | RGB LED 밝기 제어하기

```python {start=9}
# RGB LED 제어하기
r.duty(0)
g.duty(0)
b.duty(0)

while True:
    for i in range(1024):
        r.duty(i)
        g.duty(0)
        b.duty(0)
        sleep(0.001)
    for i in range(1023, -1, -1):
        r.duty(i)
        g.duty(0)
        b.duty(0)
        sleep(0.001)
```

:::코드설명
- **줄 10\~12** duty는 PWM에서 신호가 'ON'되어 있는 시간의 비율(%)을 의미함. 예를 들면, duty(0)은 0%로 완전히 꺼짐을 의미하고, duty(1023)은 100%로 항상 켜짐을 의미함.
:::

### 단계 3 | RGB LED와 레이저 연동하기

:::웹정정[set_color 함수의 값 개수]
출판본 146쪽의 코드는 `set_color(r_on, b_on)`처럼 값을 두 개만 받는 함수를 만들어 놓고 `set_color(1, 0, 0)`·`set_color(0, 0, 1)`처럼 세 개를 넘겨요. 그대로 실행하면 TypeError로 멈춰요. 원문은 그대로 두었어요. 실습실 예제(사이트판)는 초록(G) 핀 줄을 더하고 값을 세 개 받게 고친 코드예요.
:::

```python {start=7}
# 레이저 출력 핀
laser = Pin(21, Pin.OUT)

# 색상 설정 함수
def set_color(r_on, b_on):
    r.value(r_on)
    b.value(b_on)

# 메인 루프
while True:
    laser.on()
    set_color(1, 0, 0)
    sleep(1)

    laser.off()
    set_color(0, 0, 1)
    sleep(1)
```

:::코드설명
- **줄 17** 레이저 ON
- **줄 18** 빨간색 LED
- **줄 21** 레이저 OFF
- **줄 22** 파란색 LED
:::
