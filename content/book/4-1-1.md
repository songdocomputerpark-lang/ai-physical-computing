## 학습 목표

- 얼굴 인식에서 레이저 출력에 이르는 과정을 시스템 구성도로 나타내고, 전체 동작 원리를 설명할 수 있다.
- 보조공학 기술이 생활의 불편을 해소하는 데 기여할 수 있음을 이해하고, 이를 긍정적으로 활용할 수 있다.

## 1 문제 발견하기

오늘날 컴퓨터는 일상생활 속에서 다양한 일을 처리하는 데 활용되어 우리에게 편리함을 주고 있다. 문서를 작성하거나 정보를 검색할 때, 또 다른 사람과 소통할 때에 컴퓨터를 활용하곤 한다.

하지만 모든 경우에 컴퓨터를 손쉽게 사용할 수 있는 것은 아니다. 예를 들어, 손을 자유롭게 움직일 수 없는 상황에 처한 경우에는 마우스나 키보드 조작에 어려움이 있을 것이다. 이처럼 신체의 움직임이 제한된 상황에서도 컴퓨터를 쉽게 사용할 수 있는 방법에는 무엇이 있을까?

## 2 문제 정의하기

영상 처리 및 인공지능 기술의 발전으로, 신체 움직임에 제약이 있는 사람들도 컴퓨터를 보다 쉽게 사용할 수 있게 되었다. 특히 얼굴의 :용어[특징점]을 인식하는 기술을 활용하면, 눈 깜빡임, 고개 움직임, 입 벌림과 같은 미세한 표정 변화만으로도 마우스 커서를 제어하고 다양한 작업을 수행할 수 있다. 얼굴 인식 기술과 :용어[피지컬 컴퓨팅] 도구를 활용하여, 컴퓨터를 제어할 수 있는 시스템을 설계 및 구현하고, 실생활에서 어떻게 도움이 될 수 있을지 탐구해 보자.

그리고 시스템을 구현하는 과정에서는 여러 단계의 작업이 필요하므로, 한 사람이 모든 과정을 처리하기보다는 역할을 나누어 함께 프로젝트로 진행하는 편이 더 효과적일 때가 많다. 실제 프로젝트에서는 각 과정이 유기적으로 연결되기 때문에 모둠원 간의 협력과 의견 조율이 중요한 요소로 작용한다. 이렇게 협력하여 진행하는 프로젝트 활동을 통해 더 완성도 높은 해결 방안을 모색할 수 있다.

## 3 프로젝트 개요

이 프로젝트에서는 손을 자유롭게 사용하기 어려운 사용자를 위해, 얼굴의 움직임만으로 컴퓨터를 제어할 수 있는 보조공학 시스템을 만들어 본다. MediaPipe를 활용해 사용자의 얼굴 :용어[특징점]을 실시간으로 추적하고, 이를 기반으로 마우스 이동, 클릭, 더블 클릭, 우 클릭 등의 동작을 수행한다. 예를 들어, 왼쪽 눈을 깜빡이면 더블 클릭, 양쪽 눈을 동시에 깜빡이면 우 클릭, 머리를 좌우로 움직이면 마우스 커서가 함께 이동하도록 설정할 수 있다.

동작 신호는 PyAutoGUI로 컴퓨터의 마우스를 제어하는 데 활용되고, 동시에 :용어[BLE](Bluetooth Low Energy) 통신을 통해 :용어[ESP32] :용어[마이크로컨트롤러]로 전송된다. ESP32는 받은 데이터를 분석하여, :용어[서보모터]를 움직이는 레이저 포인터를 제어한다. 이 장치는 화면 속 마우스 커서의 위치를 실제 공간에서 레이저로 가리켜, 사용자가 현재 조작 중인 위치를 시각적으로 확인할 수 있도록 돕는다. 이외에도 진동 모터, MP3 모듈, RGB LED, :용어[OLED] 디스플레이 등의 출력 장치를 추가하여, 다양한 방식으로 피드백을 제공하거나 기능을 확장할 수 있다.

:::용어풀이[PyAutoGUI]
컴퓨터의 마우스 움직임이나 클릭, 키보드 입력 등을 프로그램으로 자동 실행할 수 있도록 해 주는 도구이다.
:::

:::용어풀이[BLE(Bluetooth Low Energy)]
작은 전력으로 데이터를 주고받을 수 있는 블루투스 기술로, 센서나 장치와의 무선 통신에 자주 사용된다.
:::

:::용어풀이[ESP32]
와이파이와 블루투스 기능이 내장된 작은 컴퓨터로, 다양한 센서나 장치를 연결해 동작을 제어할 수 있다.
:::

## 5 시스템 구조 파악하기

이 프로젝트는 손을 사용하지 않고도 컴퓨터를 제어할 수 있도록, 얼굴 인식과 인공지능 기술을 활용한 보조공학 시스템을 구현하는 것을 목표로 한다. 전체 시스템은 입력, 처리, 전송, 수신, 출력의 5단계로 구성된다. 모든 프로젝트에서 이 다섯 단계가 반드시 포함되어야 하는 것은 아니며, 활동 목적에 따라 일부 단계는 생략하거나 단순화할 수 있다.

![시스템 구조 그림. 다섯 칸이 화살표로 이어진다. ❶ 입력 웹캠(얼굴 영상), ❷ 처리 얼굴 인식 및 좌표 클릭 정보 생성, ❸ 전송 데이터 무선 전송(Bluethooth 사용), ❹ 수신 제어 신호 해석(ESP32가 분석), ❺ 출력 하드웨어 동작(서보모터, OLED 등)](/images/lessons/4-1-1/system-flow-5steps.webp "교과서 215쪽")

**❶ 입력(Input)**

- 도구: 웹캠
- 기능: 사용자의 얼굴을 실시간으로 촬영하여 컴퓨터로 전송한다.

**❷ 처리(Processing)**

- 도구: 파이썬, OpenCV, MediaPipe, PyAutoGUI
- 기능: 얼굴의 특징점을 실시간으로 인식하며, 얼굴의 좌우 및 상하 움직임을 각각 x, y 좌표로 변환한다. 또, 눈 깜빡임이나 입 벌림 등 특정 표정을 통해 클릭 신호를 판별한다.

**❸ 전송(Transmission)**

- 도구: Bluetooth(BLE)
- 기능: 생성된 좌표 및 클릭 정보를 블루투스 무선 통신으로 ESP32 장치에 전송한다.

**❹ 수신(Receive)**

- 도구: ESP32, 마이크로파이썬
- 기능: 수신된 데이터를 좌푯값과 클릭 신호로 구분하여 해석하고, 어떤 하드웨어를 작동시킬지 판단한다.

**❺ 출력(Output)**

- 도구: 서보모터, 레이저 포인터, RGB LED, 버저, OLED, LCD
- 기능: 서보모터가 x 축 또는 y 축 방향으로 움직이며, 레이저는 사용자의 시선을 따라 이동한다. RGB LED는 시각적 피드백을 주며, 버저는 청각적 피드백을 제공한다. OLED 또는 LCD 화면에는 현재 커서 위치나 클릭 상태 등 시스템의 작동 정보가 표시된다.

## 7 동작 테스트하기

컴퓨터의 웹캠을 켜고 화면에 영상이 나타나는지 확인하는 기본 코드를 작성한다.

**웹캠 영상 띄우기 코드**

```python
# 동작 테스트하기(웹캠 켜기)
import cv2
cap = cv2.VideoCapture(0)
while True:
    success, frame = cap.read()
    if not success:
        break
    # 결과 영상 출력
    cv2.imshow('Camera Feed', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
# 자원 정리
cap.release()
cv2.destroyAllWindows()
```
