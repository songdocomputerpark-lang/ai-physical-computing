## 학습 목표

- “접두어, x 좌표, y 좌표, 더블 클릭_플래그, 우 클릭_플래그” 형식의 데이터 스트림을 설계할 수 있다.
- 파이썬으로 :용어[BLE](Bluetooth Low Energy)를 활용하여 :용어[ESP32]로 데이터를 안정적으로 전송하는 시스템을 구현할 수 있다.
- 데이터 손실이나 지연을 최소화하기 위한 BLE 통신 구조와 예외 처리 방식을 적용할 수 있다.

## 1 얼굴 좌표 데이터 전송하기

웹캠으로 얼굴을 인식하고, 그 좌표 데이터를 블루투스(BLE)를 이용해 다른 장치로 무선 전송하면, 해당 장치에서 다양한 동작을 실행할 수 있다. 예를 들어, 얼굴 방향에 따라 서보모터가 회전하거나, 눈 깜빡임 신호에 따라 LED가 켜질 수 있다.

BLE는 선 없이 데이터를 주고받는 기술로, 설치가 간편하고 움직임에 제약이 적다. 전송할 데이터 형식을 “접두어, 변수1, 변수2, 변수3, …”처럼 정해 두면, 수신 장치에서 각 값을 정확히 받아 해석할 수 있다.

얼굴 인식 프로그램과 하드웨어 제어 프로그램이 주고받는 데이터를 잘 설계하면, 눈에 보이지 않는 무선 신호만으로도 정밀한 제어가 가능해진다. 이 과정을 통해 무선 이어폰, 스마트워치 같은 다양한 기기의 원리를 자연스럽게 이해할 수 있다.

## 2 얼굴 좌표 데이터 전송하기 프로그램 개요

이 활동에서는 얼굴 인식 마우스 제어 데이터를 블루투스로 안정적으로 전송하기 위한 준비 실습을 진행한다. 먼저 웹캠으로 얼굴을 인식하고, 얼굴의 x, y 좌표와 눈 깜빡임으로 감지한 클릭 신호를 하나의 문자열 형태의 데이터 묶음으로 만들어 “접두어, x 좌표, y 좌표, 더블 클릭, 우 클릭”과 같은 형식으로 구성한다.

이렇게 정리된 데이터는 파이썬 프로그램을 통해 BLE 방식으로 ESP32 :용어[마이크로컨트롤러]에 전송된다. ESP32는 수신된 문자열을 쉼표(,) 기준으로 나누고, 각 값을 변수에 저장하여 LCD에 출력한다. 이를 통해 데이터가 제대로 수신되고 처리되는지를 눈으로 직접 확인할 수 있다.

이번 실습은 영상 처리 프로그램과 하드웨어가 데이터를 주고받는 구조를 이해하고, 향후 서보모터나 레이저 포인터 같은 장치 제어로 확장하기 위한 기반을 다지는 데 목적이 있다.

## 기본 실습 | 얼굴 좌표 데이터를 BLE로 전송하고 LCD에 출력하기

### 단계 4 | BLE 데이터 수신 및 LCD 출력하기

ESP32는 “DATA, X, Y” 형식의 문자열을 수신한다. 수신된 문자열을 쉼표(,)를 기준으로 분할해 x 좌표, y 좌표를 추출하고, LCD에 실시간으로 출력한다.

```python
import ESP32BLE_LIB
from machine import Pin, SoftI2C
from time import sleep
from i2c_lcd import I2cLcd

# 블루투스 초기화
ble = ESP32BLE_LIB.init("ESP32")

# LCD 설정
i2c = SoftI2C(scl=Pin(22), sda=Pin(21), freq=400000)
lcd = I2cLcd(i2c, 0x20, 2, 16)
lcd.clear()
lcd.putstr("BLE Waiting...")

# 수신 및 출력
while True:
    data = ble.read()

    if data:
        try:
            parts = data.split(',')
            if len(parts) == 3 and parts[0] == "DATA":
                x = int(parts[1])
                y = int(parts[2])

                lcd.clear()
                lcd.putstr(f"X:{x:<5} Y:{y:<5}")
        except:
            pass

    sleep(0.01)
```

코드를 작성한 후에는 반드시 ‘main.py’ 또는 ‘boot.py’로 저장하고 ESP32에 업로드한다. 이렇게 저장하면 ESP32 전원이 켜질 때 자동으로 코드가 실행된다. 업로드가 완료되면 Thonny의 인터프리터를 다시 로컬 파이썬으로 전환하여 영상 처리 프로그램과의 BLE 통신을 테스트할 수 있다.

### 단계 5 | 결과 확인하기

영상 처리 프로그램에서는 얼굴 인식을 통해 얻은 좌표 데이터를 “DATA, X, Y” 형식의 문자열로 변환한 뒤 BLE를 통해 ESP32로 전송한다. ESP32는 이 데이터를 수신하여 x, y 좌표를 추출하고, LCD에 실시간으로 출력한다.

예를 들어 “DATA, 277, 202”와 같은 문자열이 전송되면, LCD에는 해당 좌표가 표시되며 전체 시스템의 동작 상태를 직관적으로 확인할 수 있다.

이 과정을 통해 ‘영상 처리 → BLE 전송 → 하드웨어 출력’으로 이어지는 전체 흐름이 완성된다.

:::결과

- x, y 좌표는 각각 현재 얼굴의 위치를 나타내며, 문자열로 전송된 데이터가 BLE 통신을 통해 정확히 전달되었음을 보여 준다.
- LCD를 통해 데이터 흐름의 최종 결과를 직접 확인할 수 있어, 통신과 출력이 정상적으로 작동하는지 직관적으로 파악할 수 있다.

## 심화 실습 | 콧등의 좌표를 BLE로 전송하고 LCD에 출력하기

MediaPipe를 이용해 얼굴 인식 후, 콧등(랜드마크 6번)의 x, y 좌표를 추출하여 “DATA, X, Y” 형식으로 0.5초 간격으로 BLE 전송하고, ESP32에서 이를 수신해 LCD에 출력한다. 이전 실습에서 구성한 ESP32 환경, BLE 연결, LCD 연결 설정은 동일하게 유지하며 그대로 사용한다.

### 단계 1 | 프로그램 전환하기

Thonny IDE에서 로컬 파이썬 인터프리터로 전환한다. OpenCV, MediaPipe, 사용자 정의 BLE 라이브러리(bluetooth_lib)를 사용할 수 있도록 설정한다.

### 단계 2 | 콧등 좌표 추출 및 전송 코드 작성하기

아래는 0.5초마다 콧등(랜드마크 6번)의 좌표를 추출해 BLE로 전송하는 코드이다. 전송 형식은 DATA, X, Y이며, 문자열 시작점을 “DATA”로 지정해 수신 장치가 인식하기 쉽게 만든다.

```python {start=1}
# 라이브러리 불러오기
import cv2
import mediapipe as mp
import time
from bluetooth_lib import init as bluetooth_init

# ESP32 BLE 주소를 입력하여 연결 시도(실제 ESP32의 MAC 주소로 변경)
bluetooth_client = bluetooth_init("XX:XX:XX:XX:XX:XX")

# 블루투스 연결 직후 잠시 대기(연결 안정화)
time.sleep(2)

# 얼굴 랜드마크를 추출할 객체 생성(최대 1명 인식)
face_mesh = mp.solutions.face_mesh.FaceMesh(max_num_faces=1)

# 두 번째 카메라 열기(카메라 번호는 환경에 따라 다를 수 있음)
cap = cv2.VideoCapture(2)

# 마지막 전송 시각 초기화
last_send = 0
```
:::코드설명
- **줄 2** OpenCV: 영상 처리용
- **줄 3** MediaPipe: 얼굴 랜드마크 인식용
- **줄 4** 시간 제어용(전송 간격 설정)
- **줄 5** 사용자 정의 BLE 초기화 함수
:::

::쪽[255]

```python {start=21}
# 메인 반복 루프
while True:
    ret, frame = cap.read()
    if not ret:
        break
    frame = cv2.flip(frame, 1)
    results = face_mesh.process(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))

    # 콧등(6번) 좌표 추출 및 전송
    if results.multi_face_landmarks:
        nose = results.multi_face_landmarks[0].landmark[6]
        x, y = int(nose.x * frame.shape[1]), int(nose.y * frame.shape[0])

        if time.time() - last_send > 0.5:
            bluetooth_client.send(f"DATA,{x},{y}")
            print(f"전송: {x},{y}")
            last_send = time.time()

        # 콧등 위치를 초록 원으로 표시
        cv2.circle(frame, (x, y), 5, (0, 255, 0), -1)

        # 좌표를 화면 좌측 상단에 텍스트로 표시
        cv2.putText(frame, f"X:{x} Y:{y}", (10, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)

    # BLE 연결 상태를 확인하여 표시
    status = "Connected" if bluetooth_client.connected else "Disconnected"
    cv2.putText(frame, f"BT: {status}", (10, 70),
                cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0))

    # 영상 창 띄우기
    cv2.imshow('BLE Test', frame)

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

# BLE 연결 종료
bluetooth_client.disconnect()
```

:::학습활동[다양한 형식으로 BLE 데이터 전송해 보기]
BLE를 이용해 영상 처리 프로그램에서 수집한 데이터를 전송할 때, 형식이나 내용이 바뀌면 수신 쪽에서는 어떻게 처리해야 할지 실습을 통해 이해한 뒤 개선해 보자.

1. 전송하는 데이터 개수를 바꿔 보며, 수신이 제대로 되는지 확인해 보자.

   예 “DATA,250,100” 대신 “DATA,250,100,1”처럼 더 많은 정보를 보낼 경우 수신 쪽에서는 어떻게 받아들이는지 확인

2. 숫자 외에 글자(문자열) 또는 ‘True/False’ 같은 값을 보낼 경우 그 결과를 확인해 보자.

   예 “DATA, left, click”, “DATA, True, False”

   어떤 값이 잘 전송되고, 어떤 값이 오류가 나는지 직접 확인한다.

3. 나만의 데이터 시작 문자를 정해 전송해 보자.

   예 “DATA” 대신 “NOSE”나 “EYE”처럼 구별되는 헤더를 붙여 수신 측에서 구분해 처리하는 방법
:::
