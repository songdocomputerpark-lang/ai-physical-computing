## 학습 목표

- ESP32와 버저의 연결 및 제어 원리를 이해할 수 있다.
- 마이크로파이썬을 이용하여 버저에서 다양한 소리를 출력할 수 있다.
- :용어[PWM] 신호를 활용하여 음의 높낮이(주파수)와 길이(시간)를 조절할 수 있다

## 1 버저의 이해

버저(Buzzer)는 전기 신호를 소리로 변환하는 전자 장치로, 주로 경고음이나 알림음을 발생시키는 데 사용된다. 버저는 전류가 흐를 때 만들어지는 전자기장을 이용해 내부 진동판을 진동시켜 소리를 만들고, 이 진동판의 떨림이 공기를 진동시켜 귀로 들을 수 있는 음파를 생성하게 된다.

:::용어풀이[전자기장]
전기가 흐르는 곳에 생기는 힘이 미치는 공간인 전기장과 전류나 자석 주위에 생기는 힘이 미치는 공간인 자기장을 합쳐서 부르는 말이다.
:::

버저는 사용 목적에 따라 간단한 비프음에서부터 다양한 :용어[주파수]의 음까지 낼 수 있어 전자 기기나 피지컬 컴퓨팅 프로젝트에서 상태 표시, 알림, 사용자 피드백 등 다양한 용도로 활용할 수 있다.

:::용어풀이[주파수]
- 어떤 현상이 일정한 주기를 가지고 반복될 때, 1초 동안 몇 번 반복되는지를 나타내는 물리량이다.
- 단위는 헤르츠(Hz)이며, 1 Hz는 1초에 1번 반복을 의미한다.
:::

## 2 프로그램 개요

다양한 과제를 통해 버저의 기본적인 작동 원리를 이해하고, 이를 바탕으로 버저를 직접 활용하고 경험해 보면서 궁극적으로 응용 시스템을 구현하는 것을 목표로 한다.

동작 테스트 단계에서는 버저를 이용해 소리를 출력함으로써, 버저가 정상으로 작동하는지 확인한다

기본 과제에서는 PWM 제어를 활용해 다양한 음계를 출력해 보고, 심화 과제에서는 터치 센서와 버저를 연동하여 터치 입력을 기반으로 버저를 제어해 보는 활동을 한다. 이러한 활동을 통해 실제 현실에서의 다양한 상황에 맞게 버저를 활용하는 능력을 키운다.

### 단계 2 | 버저 출력 상태 점검하기

`# 라이브러리 불러오기`

```python
from machine import Pin
from time import sleep

# 핀 연결하기
buzzer = Pin(15, Pin.OUT)

# 1초 간격으로 소리 울리기
while True:
    buzzer.on()
    sleep(1)
    buzzer.off()
    sleep(1)
```

:::코드설명
- **줄 1** ESP32의 핀(Pin)을 제어하기 위한 모듈 불러오기
- **줄 2** 초 단위로 지연을 주기 위한 함수 불러오기
- **줄 5** GPIO 15번 핀을 출력 모드로 설정하여 버저 연결
- **줄 9** 소리 ON, 버저에 전류가 공급되면, 소리 켜짐.
- **줄 11** 소리 OFF, 버저에 전류가 차단되면, 소리 꺼짐.
:::

::실습실[esp32/u2/2-2-1-buzzer-check.py]

### 단계 2 | 장치 설정 및 소리 출력하기

```python {start=5}
# 패시브 버저를 GPIO15에 연결하기
buzzer = PWM(Pin(15))

# 도레미파솔라시도 (C4~C5) 주파수 (Hz)
notes = {"도": 262,"레": 294,"미": 330,"파": 349,
         "솔": 392,"라": 440,"시": 494,"도(높은)": 523}

# 연주 순서
melody = ["도", "레", "미", "파",
          "솔", "라", "시", "도(높은)"]

# 연주하기
for note in melody:
    buzzer.freq(notes[note])
    buzzer.duty(512)
    print(note)
    sleep(0.5)

# 소리 끄기
buzzer.deinit()
```

:::코드설명
- **줄 6** GPIO 15번 핀을 출력 모드로 설정하여 버저 연결
- **줄 9** 'notes'는 각 음계와 주파수를 매핑한 딕셔너리
- **줄 13** 'melody'는 연주할 음의 순서를 정한 리스트
- **줄 19** 음 크기, 출력음 크기를 설정하는 함수(출력음 크기는 0\~1023까지 조절 가능)
- **줄 20\~21** 음계명 출력, 음계가 연주될 때마다 동시에 음계명이 컴퓨터 화면에 출력되도록 하여 코드 이상 유무 및 버저 작동 상태를 확인
:::

:::웹정정[print 괄호와 들여쓰기]
출판본 159쪽 단계 1의 7번째 줄은 `print("touch value:",touch.value()`로 끝의 닫는 괄호 `)`가 하나 모자라요. 또 8번째 줄 `sleep(0.2)`는 7번째 줄보다 한 단계 더 안쪽으로 인쇄돼 있어요. 따라 쓰면 문법 오류(SyntaxError, IndentationError)가 나요. 원문은 그대로 두었어요. 실습실 예제는 괄호를 닫고 `sleep(0.2)`를 `print`와 같은 깊이로 맞춘 코드예요.

```python
from machine import Pin
from time import sleep

touch = Pin(17, Pin.IN)

while True:
    print("touch value:",touch.value()
```

- **줄 7\~8** 'touch.value()' 함수는 터치 감지면 '1' 출력, 터치 미감지면 '0' 출력

### 단계 2 | 터치 센서를 누를 때마다 버저음 출력하기

```python
# 라이브러리 불러오기
from machine import Pin
from time import sleep

# 터치 센서 입력 핀 연결하기
touch = Pin(17, Pin.IN)

# 버저 출력 핀 연결하기
buzzer = Pin(15, Pin.OUT)
buzzer.off()

# 터치 센서로 버저음 제어하기
prev_touch = 0
while True:
    touch_state = touch.value()
    if touch_state == 1 and\
    prev_touch == 0:
        buzzer.on()
        print('buzzer on')
        sleep(0.5)
        buzzer.off()
        print('buzzer off')
    prev_touch = touch_state
    sleep(0.05)
```

:::코드설명
- **줄 6\~7** Pin(17, Pin.IN) 함수는 터치 센서가 연결된 핀(GPIO 17)을 입력으로 설정
- **줄 15** touch_state 0 → 1 바뀔 때, 버저음 출력
- **줄 18\~19** 버저음이 출력될 때마다, 동시에 터치 센서와 버저음 작동 이상 여부를 확인하기 위해 프로그램상에 'buzzer on' 문구가 출력
- **줄 20** 짧게 소리
- **줄 21** 버저음이 꺼지면 'buzzer off' 문구가 출력
:::

::실습실[esp32/u2/2-2-1-adv-touch-buzzer.py]
