## 학습목표

- 영상 인식 인공지능 라이브러리가 무엇이고 왜 쓰는지 설명할 수 있어요.
- OpenCV와 MediaPipe로 웹캠 영상을 화면에 보여 주고(출력), 거울처럼 뒤집고(변환), 손을 찾아 점과 선으로 표시(처리)할 수 있어요.

## 왜 배울까

사람은 말뿐 아니라 표정과 손동작으로도 뜻을 전해요. 요즘은 스마트폰과 컴퓨터도 카메라로 손동작을 알아보고 반응해서, 화면을 만지지 않고 기기를 다룰 수 있어요. 특별한 장비 없이 웹캠과 :용어[라이브러리] 몇 개만 있으면 이런 프로그램을 직접 만들 수 있어요.

## 핵심 개념

### 영상 인식 인공지능 라이브러리

라이브러리는 자주 쓰는 기능을 미리 만들어 모아 둔 코드 묶음이에요. 영상 인식 인공지능 라이브러리를 쓰면 카메라 영상을 읽고, 바꾸고, 그 안에서 손이나 얼굴을 찾는 어려운 일을 몇 줄의 코드로 할 수 있어요. 이 차시에서는 두 라이브러리를 함께 써요.

| 라이브러리 | 하는 일 |
| --- | --- |
| OpenCV(`cv2`) | 영상을 :용어[픽셀] 단위로 처리하는 :용어[컴퓨터 비전] 라이브러리예요. 영상을 불러오고 저장하고, 색을 바꾸고, 흐리게 하거나 윤곽선을 찾아요. 이 차시에서는 `VideoCapture()`, `read()`, `flip()`, `cvtColor()`, `imshow()`, `waitKey()`를 써요. |
| MediaPipe(`mp`) | 미리 학습된 인공지능 모델로 사진 속 손, 얼굴, 몸을 찾아요. 손 인식 기능을 모아 둔 Hands 모듈은 손가락 관절 21곳의 위치(:용어[랜드마크])를 알려 줘요. 이 차시에서는 `Hands()`, `process()`, `draw_landmarks()`를 써요. |

MediaPipe가 찾은 랜드마크를 선으로 이으면 손 모양을 화면에 그릴 수 있어요. 이 좌표를 쓰면 손동작으로 키보드를 치거나, 마우스를 움직이거나, 음량을 조절하는 프로그램도 만들 수 있어요.

### 영상은 프레임을 빠르게 넘긴 것

영상은 사진 한 장 한 장(:용어[프레임])을 빠르게 이어서 보여 주는 거예요. 그래서 웹캠 프로그램은 "프레임 한 장 읽기 → 처리하기 → 보여 주기"를 반복문으로 계속 되풀이해요. 오늘 만들 손 인식 프로그램은 아래 차례로 돌아요.

<figure>
<img src="/images/lessons/1-2-1/frame-pipeline.svg" alt="손 인식 프로그램이 프레임마다 되풀이하는 여섯 단계를 고리 모양으로 그린 그림: ① 프레임 읽기(read) → ② 좌우 반전(flip) → ③ 색 순서 바꾸기(cvtColor) → ④ 손 찾기(process) → ⑤ 점과 선 그리기(draw_landmarks) → ⑥ 화면에 보여 주고 키 확인(imshow, waitKey) → 다시 ①. ④와 ⑤는 MediaPipe, 나머지는 OpenCV가 맡는다" width="640" height="330">
<figcaption>반복문이 한 바퀴 돌 때마다 프레임 한 장이 이 여섯 단계를 거쳐요. ④와 ⑤는 MediaPipe, 나머지는 OpenCV가 해요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

| 단계 | 하는 일 |
| --- | --- |
| 입력 | 웹캠의 실시간 영상을 받아요(`cv2.VideoCapture(0)`). |
| 프레임 캡처 | 영상에서 프레임을 한 장씩 차례로 꺼내요(`read()`). |
| 손 인식 처리 | MediaPipe Hands가 손의 랜드마크를 찾아요(`process()`). |
| 시각화 | 찾은 랜드마크를 선으로 이어 손 모양을 그려요(`draw_landmarks()`). |
| 출력 | 그린 결과를 화면에 보여 줘요(`imshow()`). |

웹캠은 나를 마주 보고 찍어요. 그대로 보여 주면 내가 오른손을 들 때 화면 속 손은 왼쪽에서 올라가서 어색해요. 거울처럼 보이게 하려면 프레임을 좌우로 뒤집어요.

### 손을 찾는 세 함수

MediaPipe의 Hands 모듈은 손의 위치를 찾고 손가락 관절의 랜드마크를 뽑아 줘요. 세 함수가 차례로 일해요.

**`Hands()` — 손 인식 도구 만들기.** 손을 찾고 랜드마크를 뽑는 도구(객체)를 만들어요. 설정 값을 세 가지 정할 수 있어요.

| 설정 | 뜻 |
| --- | --- |
| `static_image_mode` | 사진을 한 장씩 따로 볼지(`True`), 이어지는 영상으로 볼지(`False`) 정해요. 웹캠은 `False`예요. |
| `max_num_hands` | 한 번에 찾을 손의 최대 개수예요. `1`이면 손 하나만 찾아요. |
| `min_detection_confidence` | 손이라고 인정하는 :용어[신뢰도]의 기준(0~1)이에요. 값이 클수록 확신이 높을 때만 손으로 인정해요. |

신뢰도는 인공지능이 "이것은 손이다"라고 얼마나 확신하는지를 0에서 1 사이 수로 나타낸 값이에요. 기준이 0.5면 확신이 50%를 넘을 때만 손으로 인정해요. 기준을 낮추면 손이 아닌 물체도 손으로 잘못 알아보고, 높이면 손을 찾기가 까다로워져요.

**`process()` — 사진에서 손 찾기.** 사진을 분석해 손이 있는지 확인하고, 손의 랜드마크 좌표를 돌려줘요. 컬러 사진은 픽셀마다 색 숫자 3개를 적는데, OpenCV는 파랑, 초록, 빨강 순서(BGR)로 다루고 MediaPipe는 빨강, 초록, 파랑 순서(RGB)의 사진을 받아요(:용어[BGR·RGB]). 그래서 `cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)`로 순서를 바꾼 뒤에 넘겨요.

`process()`가 돌려주는 랜드마크 하나는 이런 모양이에요.

```text
landmark {
  x: 0.52     ← 화면의 가로 위치(0: 왼쪽 끝, 1: 오른쪽 끝)
  y: 0.60     ← 화면의 세로 위치(0: 위쪽 끝, 1: 아래쪽 끝)
  z: -0.03    ← 깊이(값이 작을수록 카메라에 더 가까워요)
}
```

<figure>
<img src="/images/lessons/1-2-1/landmark-coords.svg" alt="화면 위 손 그림에서 검지 끝 점 하나를 표시한 그림: 화면 위쪽 가장자리에 가로 x가 왼쪽 0에서 오른쪽 1까지, 왼쪽 가장자리에 세로 y가 위 0에서 아래 1까지 눈금이 있고, 검지 끝에서 내린 점선이 가로 0.52, 세로 0.60을 가리킨다" width="640" height="360">
<figcaption>x와 y는 화면의 가로와 세로 길이를 1로 본 위치예요. 수학 시간의 좌표와 달리 y는 아래로 갈수록 커져요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

이렇게 0과 1 사이 수로 나타낸 위치를 :용어[정규화 좌표]라고 해요. 화면 크기가 달라도 같은 수로 위치를 말할 수 있어요. 화면의 픽셀 위치로 바꾸는 방법은 다음 차시(1-2-2)에서 배워요.

**`draw_landmarks()` — 점과 선 그리기.** 찾은 랜드마크 좌표에 점을 찍고, 관절끼리 연결선을 그려요. 넘겨준 사진 위에 바로 그리고, 따로 돌려주는 값은 없어요.

## 따라하기

예제 두 개를 차례로 실행해요. 기본 실습은 웹캠 영상을 화면에 보여 주고 거울처럼 뒤집어요. 심화 실습은 여기에 MediaPipe를 더해 손을 찾고 점과 선으로 표시해요.

카메라가 없어도 끝까지 할 수 있어요. 기본 실습은 실습실의 '샘플 입력(움직이는 도형)'으로, 심화 실습은 '재생 입력(합성 좌표)'으로 해요. 아래 줄 번호는 실습실에 보이는 예제 파일의 줄 번호예요.

### 기본 실습 코드 읽기

- 1행: OpenCV 라이브러리(`cv2`)를 불러와요.
- 3행: `cv2.VideoCapture(0)`으로 0번 카메라(웹캠)에 연결해요.
- 4~8행: `isOpened()`로 웹캠이 잘 열렸는지 확인해요. 열리지 않았으면 안내 문장을 보이고 `exit()`로 끝내요.
- 10~14행: `while True:` 반복문 안에서 `read()`가 프레임을 한 장씩 읽어요. `ret`은 읽기에 성공했는지(`True` 또는 `False`), `frame`은 읽은 사진이에요.
- 16행: `cv2.flip(frame, 1)`로 프레임을 좌우로 뒤집어요.
- 17행: `cv2.imshow('Webcam', frame)`으로 'Webcam' 창에 보여 줘요.
- 19~20행: `cv2.waitKey(30)`은 30밀리초(1000분의 30초) 동안 키 입력을 기다려요. 그사이 q 키를 누르면 반복을 끝내요.
- 22~23행: 웹캠을 놓아주고(`release()`) 창을 모두 닫아요.

### 심화 실습 코드 읽기

- 1~2행: OpenCV와 MediaPipe를 불러와요. MediaPipe는 `mp`라는 짧은 이름으로 불러요.
- 5행: MediaPipe의 손 인식 모듈을 `mp_hands`라는 이름으로 불러요.
- 6~8행: `Hands()`로 손 인식 도구를 만들어요. 영상 모드(`False`), 손은 최대 1개, 신뢰도 기준은 0.5예요.
- 10행: 랜드마크를 그려 주는 도구(`drawing_utils`)를 `mp_drawing`이라는 이름으로 불러요.
- 12~17행: 웹캠에 연결하고 프레임을 한 장씩 읽어요. 기본 실습과 같아요.
- 19~21행: 좌우로 뒤집고(19행), 색 순서를 BGR에서 RGB로 바꾼 뒤(20행), `hands.process()`로 손을 찾아 결과를 `result`에 담아요(21행).
- 23~26행: 손을 찾았으면(`result.multi_hand_landmarks`) 찾은 손마다 `draw_landmarks()`로 관절 점과 연결선(`HAND_CONNECTIONS`)을 그려요.
- 28행: 'Hand Tracking' 창에 보여 줘요.
- 30\~31행: q 키를 누르면 반복을 끝내요. 33\~34행: 웹캠을 놓아주고 창을 닫아요.

### 기본 실습 실행하고 결과 보기

첫 번째 예제에서 [이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 처음 한 번은 파이썬과 OpenCV를 받느라 조금 걸려요. 브라우저가 카메라 사용을 물으면 "허용"을 눌러요. 콘솔에 이렇게 나와요.

```text
웹캠이 연결되었습니다.
```

출력 칸의 'Webcam' 창에 내 모습이 거울처럼 보여요. 오른손을 들면 화면에서도 오른쪽에서 손이 올라가요. 카메라가 없으면 입력 소스가 '샘플 입력(움직이는 도형)'으로 바뀌고, 왼쪽 위에 있던 '샘플 입력' 글자가 오른쪽 위에 거울 글자로 보여요.

끝낼 때는 출력 화면을 한 번 누른 뒤 키보드의 q 키를 누르거나, 출력 칸 아래의 [q]를 눌러요.

:::확인
- 콘솔에 "웹캠이 연결되었습니다."가 나와요.
- 'Webcam' 창의 영상이 거울처럼 좌우가 뒤집혀 보여요.
- q 키(또는 [q])를 누르면 실행이 끝나요.
:::

:::왜그럴까
3행이 웹캠에 연결하고, 10행의 반복문이 도는 동안 11행이 프레임을 한 장씩 읽어요. 16행이 그 한 장을 좌우로 뒤집고 17행이 보여 줘요. 이 일을 1초에도 여러 번 되풀이하니, 뒤집힌 사진이 이어져 거울 같은 영상이 돼요.

19행의 `waitKey(30)`은 한 장을 보여 줄 때마다 30밀리초씩 기다리며 그사이 누른 키를 알려 줘요. 그래서 q 키를 누르면 반복을 끝낼 수 있어요.
:::

### 심화 실습 실행하고 결과 보기

두 번째 예제에서 [이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 'Hand Tracking' 창에 손을 보여 주면 손가락 관절 21곳에 빨간 점이 찍히고, 점들이 흰 선으로 이어져요. 손을 움직이면 점과 선이 따라 움직여요.

![프로그램 창 속 손바닥을 편 손 위에 손가락 관절마다 빨간 점이 찍히고 점들이 흰 선으로 이어진 손 인식 결과 화면](/images/lessons/1-2-1/hand-landmarks-result.webp)

위 화면은 교과서 027쪽에 실린, 웹캠으로 실행한 결과예요.

카메라가 없으면 입력 소스를 '재생 입력(합성 좌표)'으로 골라요. 실습실 오른쪽 아래 '인식(mediapipe)' 칸의 재생 동작(처음에는 '손가락 0~5개 펴기')에 따라 실습실이 그린 손(흰 뼈대와 하늘색 점)이 움직이고, 코드가 그린 빨간 점과 흰 선이 그 위에 겹쳐져요. 재생 동작을 '두 손'으로 바꾸면 손이 두 개 나오는데, 점은 한 손에만 찍혀요.

실행하면서 생각해 봐요(교과서 026쪽 해 보기).

1. 손을 움직이면 화면 속 점과 선은 어떻게 바뀌나요?
2. 사진 대신 점과 선만으로 손 모양을 나타내면 어떤 점이 좋을까요?

:::확인
- 'Hand Tracking' 창에 손(또는 재생 입력의 손)이 보이면 관절마다 빨간 점이 찍히고 흰 선으로 이어져요.
- 손이 움직이면 점과 선도 따라 움직여요.
- 손이 두 개여도(재생 동작 '두 손') 점은 한 손에만 찍혀요.
:::

:::왜그럴까
21행의 `process()`는 프레임마다 손을 새로 찾아요. 손이 움직이면 다음 프레임에서 찾은 랜드마크 좌표가 달라지고, 26행이 바뀐 자리에 점과 선을 다시 그려요. 그래서 점과 선이 손을 따라다녀요. 7행에서 손을 최대 1개만 찾게 했으니 손이 둘이어도 하나에만 그려요.

점과 선으로 나타내면 수십만 개의 픽셀 대신 점 21개의 좌표만 다루면 돼요. 숫자가 적으니 "검지 끝이 어디에 있나", "두 손가락이 얼마나 떨어졌나"를 쉽게 계산할 수 있어요. 다음 두 차시에서 이 좌표로 그림을 그리고 거리를 재요.
:::

## 바꿔보기

:::바꿔보기
1. 기본 실습 16행 `cv2.flip(frame, 1)`의 `1`을 `0`으로, 다시 `-1`로 바꿔 실행해 보세요. 화면이 어느 쪽으로 뒤집히나요? 핵심 개념의 표와 견주어 보세요.
2. 심화 실습 7행의 `max_num_hands=1`을 `max_num_hands=2`로 바꾸고, 두 손을 보여 주거나 재생 동작 '두 손'으로 실행해 보세요. 점이 찍히는 손은 몇 개인가요?
3. 심화 실습 30행의 `cv2.waitKey(30)`을 `cv2.waitKey(300)`으로 바꿔 보세요. 손을 움직일 때 점이 따라오는 모습이 어떻게 달라지나요?
:::

:::왜그럴까[왜 waitKey(300)이면 점이 느릿느릿 따라올까?]
`waitKey(300)`은 프레임 한 장을 보여 줄 때마다 0.3초씩 기다려요. 1초에 처리하는 프레임이 몇 장으로 줄어서(출력 칸 아래의 fps 숫자도 작아져요), 손이 움직여도 점은 0.3초가 넘게 지나야 한 번씩 자리를 옮겨요. 기다리는 시간이 짧을수록 반응은 빨라지지만 컴퓨터가 할 일도 늘어요.
:::

:::참고[재생 입력에서는 신뢰도를 바꿔도 결과가 같아요]
재생 입력의 손은 실습실이 계산한 좌표라서 언제나 "확실한 손"이에요. 그래서 `min_detection_confidence`를 바꿔도 결과가 달라지지 않아요. 신뢰도 실험은 웹캠으로 해요(도전 과제 1).
:::

:::오류
`AttributeError: module 'cv2' has no attribute 'COLOR_BGRRGB'`처럼 나오면 이름을 잘못 친 거예요. `COLOR_BGR2RGB`(가운데 숫자 2), `mp.solutions`(끝의 s)처럼 대문자, 소문자와 글자 하나까지 예제와 같은지 확인해요. 오류 메시지의 뜻은 [오류 사전](/help/errors/#attribute-error-module)에서 찾아볼 수 있어요.
:::

## 도전 과제

::::도전[도전 과제 1: 손 인식이 잘되는 조건 찾기]
웹캠으로 심화 실습을 실행한 채 조건을 하나씩 바꾸며, 손을 잘 찾는지 표로 정리해 보세요. 신뢰도는 코드를 고치지 않아도 오른쪽 아래 '인식(mediapipe)' 칸의 "실행 중에 바꿔 보기"에서 검출 신뢰도 막대로 바로 바꿀 수 있어요.

| 구분 | 바꾼 조건 | 손을 찾았나요? |
| --- | --- | --- |
| 예: 밝기 | 방을 어둡게 해요. | 예 / 아니요 |
| 신뢰도 | 검출 신뢰도를 0.9로 올려요. | 예 / 아니요 |
| 배경 | 손과 비슷한 색의 벽 앞에서 해요. | 예 / 아니요 |
| 손의 각도 | 손날이 카메라를 향하게 세워요. | 예 / 아니요 |

:::힌트
신뢰도를 높이면(예: 0.9) 확실할 때만 손으로 인정해서, 어둡거나 손을 옆으로 세우면 손을 놓치기 쉬워요. 낮추면(예: 0.1) 손은 잘 찾지만 손이 아닌 물체를 손으로 잘못 볼 수 있어요. 카메라가 없으면 표의 결과를 먼저 예상해 적고, 친구의 웹캠 결과와 견주어 봐요.
:::
::::

::::도전[도전 과제 2: 손 뼈대 꾸미기]
점과 선의 색, 굵기, 크기를 바꿔 나만의 손 뼈대를 그려 보세요. `mp_drawing.DrawingSpec(color=(파랑, 초록, 빨강), thickness=굵기, circle_radius=점 크기)`로 모양을 만들고, 26행 `draw_landmarks()`에 넷째 값(점 모양)과 다섯째 값(선 모양)으로 넘겨요.

:::힌트
색은 OpenCV 순서라 (파랑, 초록, 빨강)으로 적어요. 예를 들어 `point_style = mp_drawing.DrawingSpec(color=(0, 255, 255), thickness=2, circle_radius=5)`는 노란 점 모양이에요. `draw_landmarks(frame, hand_landmarks, mp_hands.HAND_CONNECTIONS, point_style, line_style)`처럼 점 모양을 넷째, 선 모양을 다섯째 자리에 넘겨요.

비슷한 코드는 [계단 4 예제(선과 점 꾸미기)](/labs/vision/?example=vision%2Fopmp%2F04-drawing-style.py)에 있어요. 이 예제는 선 모양(`line_style`)을 일부러 넷째 자리에 넘겨요. 실행해 보고 어느 쪽이 점 모양이 되는지 확인해 봐요.
:::
::::

### 자주 막히는 곳
