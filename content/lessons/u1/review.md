### 8번(서술형)

웹캠 영상을 좌우로 뒤집어(거울 모드) 보여 줄 때 쓰는 OpenCV 함수와 그 기능을 써 보세요.

:::정답
예시 답안: `cv2.flip()` 함수로 영상을 뒤집어요. 두 번째 값(flipCode)에 따라 뒤집는 방향이 달라요.

| flipCode | 뒤집는 방향 |
| --- | --- |
| `0` | 위아래로 뒤집어요(상하 반전). |
| `1` | 좌우로 뒤집어요(좌우 반전, 거울 모드). |
| `-1` | 위아래와 좌우를 한꺼번에 뒤집어요. |

그래서 거울 모드는 `frame = cv2.flip(frame, 1)`처럼 써요. 1-4-1 기본 실습 19행에서도 이렇게 영상을 뒤집어요.
:::

FaceMesh는 눈 둘레의 좌표를 알려 줘요. EAR은 눈의 세로 거리 평균을 가로 거리로 나눈 값이에요. 눈을 감으면 세로 길이가 줄어 EAR이 갑자기 작아져요. 정해 둔 임계값보다 작아지면 눈을 감은 것으로 판단하고, 여러 프레임 동안 이어지는지 확인하거나 임계값을 사람에 맞게 고치면 더 정확해져요. 입 모양으로 하품을 알아채는 1-3-2 차시의 입 모양 비율(MAR)도 같은 원리예요.

## 프로그래밍으로 점검

### 10번

다음 프로그램은 OpenCV와 MediaPipe Pose로 웹캠 영상에서 사람의 포즈(관절 위치)를 찾아요. 빈칸에 들어갈 코드를 써 보세요.

```python
import cv2
import mediapipe as mp

cap = cv2.VideoCapture(0)
pose = mp.solutions.pose.Pose()

while True:
    ret, frame = cap.read()
    results = pose.process( ____________ )
```

:::참고[도움말]
OpenCV는 영상을 BGR 순서로 읽어 오지만, MediaPipe Pose는 RGB 순서의 영상을 받아요. 그래서 BGR → RGB 변환이 필요해요.
:::

:::정답
`cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)`

OpenCV의 `VideoCapture`는 BGR 순서로 영상을 주지만, MediaPipe Pose의 `pose.process()`는 RGB 영상을 받아요. 그래서 넘기기 전에 BGR을 RGB로 바꿔야 랜드마크를 정확하게 찾아요. 1-4-1 기본 실습의 20~22행이 바로 이 모양이에요.
:::

### 11번

다음 프로그램은 SpeechRecognition 라이브러리로 마이크 음성을 글자로 바꿔 출력해요. 빈칸에 들어갈 코드를 써 보세요.

```python
import speech_recognition as sr

r = sr.Recognizer()
with sr.Microphone() as source:
    audio = r.listen(source)
    command = r.____(audio, language='ko-KR')
    print(command)
```

:::참고[도움말]
Google Web Speech API(구글의 웹 음성 인식 서비스)를 이용하고, 한국어로 알아듣게 하려고 `language='ko-KR'`를 적어요. API는 프로그램이 다른 프로그램이나 서비스의 기능을 가져다 쓰는 약속이에요.
:::

:::정답
`recognize_google`

SpeechRecognition 라이브러리는 마이크로 들은 말을 `listen()`으로 받아 `audio`에 담아요. `recognize_google()`은 이 음성 데이터를 Google 음성 인식 서비스로 보내 글자로 바꿔요. `language='ko-KR'`를 적으면 한국어로 알아듣고, 바뀐 글자는 `print()`로 출력해요. Google 서비스를 쓰므로 인터넷에 연결되어 있어야 하고, 목소리가 인터넷 너머 서버로 가요. 이 사이트의 실습실에서는 목소리 대신 글자를 보내 같은 코드를 돌려요([1-4-3 말을 글로 바꾸는 기술](/learn/u1/1-4-3/)).
:::

### 채점할 때 볼 곳(사이트 제안)

- 8번(서술형): 함수 이름 `cv2.flip()`과, 두 번째 값이 1일 때 좌우 반전(거울 모드)이라는 기능을 함께 쓰면 돼요. 0(상하 반전)과 -1(상하·좌우 반전)까지 쓰면 더 좋아요.
- 9번(논술형): ① 눈 둘레 랜드마크 좌표로 EAR을 계산한다 ② EAR은 세로 거리 평균을 가로 거리로 나눈 값이다 ③ 눈을 감으면 EAR이 작아져 임계값 아래로 내려가면 감은 것으로 판단한다, 세 가지가 들어가면 돼요. 연속 프레임 확인이나 임계값 보정처럼 정확도를 높이는 방법까지 쓰면 더 좋아요.
- 10번: `cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)`의 변수 이름(`frame`)과 변환 코드(`COLOR_BGR2RGB`)가 모두 맞아야 해요.

### 원고에서 바꾼 곳

- 문장 끝을 해요체로 바꾸고, 보기의 "엑추에이터"는 사이트 전체에서 쓰는 "액추에이터"로 맞췄어요.
- 2번 해설의 "기본적으로 환경, 센서, 지능적 처리, 엑추에이터 네 가지 구성 요소"는 1-1-1(원고 011쪽)이 목표까지 다섯 가지로 적은 것과 부딪혀서, "목표를 이루려고 … 움직이는 시스템"으로 다듬었어요.
- 8번 예시 답안의 `cv2.fiip()`는 `cv2.flip()`의 오타라 바로잡았어요.
- 11번 코드의 6행은 원고에서 5행보다 한 칸 더 들여 써 있어 그대로 옮기면 파이썬 들여쓰기 오류(IndentationError)가 나요. 5행과 같게 맞췄어요.
