## 학습목표

- 검지 끝의 좌표로 선을 그리는 프로그램을 만들 수 있어요.
- 키보드 입력이나 손가락 움직임에 따라 선 그리기 기능을 켜고 끄는 프로그램을 만들 수 있어요.

## 왜 배울까

스마트폰 화면을 넘기거나 게임을 할 때 손동작만으로 조종해 본 적이 있을 거예요. 화면을 건드리지 않고 허공에서 손동작으로 기기를 다루는 기술을 :용어[공중 제스처]라고 하고, 전화를 받거나 음악을 바꾸는 데 쓰여요. 컴퓨터가 손가락 끝의 위치를 좌표로 알면, 허공에서 움직인 손끝을 따라 화면에 선을 그릴 수도 있어요.

### 손 랜드마크 번호: 검지 끝은 8번

### 픽셀 좌표계: 원점은 왼쪽 위

화면에 선을 그리려면 점의 위치를 :용어[픽셀] 단위로 알아야 해요. 그런데 영상을 처리할 때 쓰는 :용어[픽셀 좌표계]는 수학 시간에 배우는 좌표 평면과 모양이 달라요. 수학에서는 원점이 왼쪽 아래에 있고 y가 위로 갈수록 커지지만, 픽셀 좌표계는 원점이 왼쪽 위에 있고 y가 아래로 갈수록 커져요.

<figure>
<img src="/images/lessons/1-2-2/coordinate-systems.svg" alt="두 좌표계를 나란히 비교한 그림: 왼쪽 수학 좌표계는 원점 (0, 0)이 왼쪽 아래에 있고 x는 오른쪽, y는 위쪽으로 커지며 점 (3, 1)이 찍혀 있다. 오른쪽 픽셀 좌표계는 가로 640, 세로 480인 화면의 원점 (0, 0)이 왼쪽 위에 있고 x는 오른쪽, y는 아래쪽으로 커지며 점 (320, 120)이 찍혀 있다" width="640" height="300">
<figcaption>x는 두 좌표계 모두 오른쪽으로 커지지만, y는 반대예요. 픽셀 좌표계에서는 아래로 내려갈수록 y가 커져요. 사이트가 직접 그린 그림이에요.</figcaption>

| --- | --- | --- |

| y축 방향 | 위쪽으로 갈수록 커져요. | 아래쪽으로 갈수록 커져요. |

### 상대 좌표를 픽셀 좌표로 바꾸기

MediaPipe가 알려 주는 손가락 위치는 화면의 가로와 세로 길이를 1로 본 0과 1 사이의 :용어[상대 좌표]{항목=normalized-coordinates}예요. 그래서 선을 그리기 전에 실제 화면 크기에 맞는 픽셀 좌표로 바꿔야 해요. x에는 화면 너비를, y에는 화면 높이를 곱하면 돼요.

```python
h, w, _ = frame.shape          # h: 높이, w: 너비(픽셀 수)
x_pixel = int(landmark.x * w)  # 가로 위치
y_pixel = int(landmark.y * h)  # 세로 위치
```

<figure>
<img src="/images/lessons/1-2-2/relative-to-pixel.svg" alt="가로 640, 세로 480 픽셀 화면에서 상대 좌표 (0.5, 0.25)인 점을 픽셀 좌표로 바꾸는 그림: x는 0.5 곱하기 640으로 320, y는 0.25 곱하기 480으로 120이 되어 픽셀 좌표 (320, 120)을 얻는다" width="640" height="290">
<figcaption>상대 좌표에 화면 크기를 곱하면 픽셀 좌표가 나와요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

`frame.shape`는 사진의 크기를 (높이, 너비, 색 :용어[채널] 수) 차례로 알려 줘요. 채널 수는 쓰지 않아서 이름 대신 `_`로 받아요. 픽셀은 한 칸씩 세는 자리라 소수점이 없어서, `int()`로 소수점 아래를 버려 정수로 만들어요.

교과서의 예처럼 상대 좌표가 (1, 1)이고 화면이 1280×800이면 픽셀 좌표는 (1280, 800)이 돼요. 상대 좌표는 화면 크기와 상관없이 같지만, 픽셀 좌표는 화면 크기에 따라 달라져요.

### 점을 이어 선 그리기

OpenCV에서는 두 점을 `cv2.line()`으로 이어요. 수학 시간에 두 점을 이어 선분을 긋는 것과 같아요. 괄호 안에는 그릴 사진, 시작점, 끝점, 색(파랑, 초록, 빨강 순서), 굵기를 차례로 적어요.

```python
cv2.line(img, (x1, y1), (x2, y2), color, thickness)
```

검지 끝으로 그림을 그리는 원리는 간단해요. 프레임마다 **바로 앞 프레임의 검지 끝**(이전 좌표)과 **지금 검지 끝**(현재 좌표)을 짧은 선으로 이어요. 짧은 선이 1초에 여러 번 이어지면 손끝이 지나간 길이 곡선으로 보여요.

<figure>
<img src="/images/lessons/1-2-2/line-trail.svg" alt="프레임 1, 2, 3, 4에서 검지 끝 위치가 점으로 찍히고, 이웃한 두 점이 짧은 초록 선으로 이어져 곡선이 되는 그림. 손이 사라진 프레임 5에서는 이전 좌표가 (0, 0)으로 돌아가 선이 끊기고, 프레임 6부터 새 선이 시작된다" width="640" height="250">
<figcaption>이전 좌표와 현재 좌표를 잇는 짧은 선이 모여 그림이 돼요. 손이 사라지면 이전 좌표를 (0, 0)으로 돌려 선을 끊어요. 사이트가 직접 그린 그림이에요.</figcaption>

### 선이 남는 까닭: 도화지와 합성

웹캠 프레임은 반복문이 돌 때마다 새 사진으로 바뀌어요. 프레임에 바로 그리면 다음 프레임에서 선이 사라져요. 그래서 프레임과 크기가 같은 검은 도화지(캔버스)를 따로 만들어 거기에 선을 그리고, 보여 줄 때만 두 사진을 겹쳐요.

<figure>
<img src="/images/lessons/1-2-2/canvas-blend.svg" alt="웹캠 프레임(매번 바뀜)과 검은 도화지에 그린 초록 선(계속 남음)을 반씩 섞어, 손 영상 위에 초록 선이 함께 보이는 출력 화면을 만드는 그림. 식은 addWeighted(frame, 0.5, canvas, 0.5, 0)이다" width="640" height="250">
<figcaption>도화지는 한 번만 만들고 계속 그 위에 그려서 선이 남아요. 보여 줄 때 프레임과 도화지를 반씩 섞어요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

| 코드 | 하는 일 |
| --- | --- |
| `np.zeros_like(frame)` | 프레임과 크기가 같고 모든 픽셀이 0(검은색)인 도화지를 만들어요. |
| `cv2.addWeighted(frame, 0.5, canvas, 0.5, 0)` | 두 사진을 0.5:0.5 비율로 섞어 반투명하게 겹쳐요. |

NumPy(`np`)는 숫자 표(배열)를 빠르게 다루는 라이브러리예요. 사진도 픽셀 숫자가 담긴 표라서 NumPy로 만들 수 있어요. 사진이 숫자 표라는 것은 보충 차시 [V1 사진은 숫자다](/learn/u1/v1/)에서 확인할 수 있어요.

### 기본 실습 코드 읽기

- 1~3행: OpenCV, MediaPipe, NumPy를 불러와요.
- 6~7행: 손 인식 모듈을 부르고 `Hands()`로 손 인식 도구를 만들어요.
- 10~11행: 도화지(`canvas`)는 아직 없다는 뜻으로 `None`, 이전 좌표는 (0, 0)으로 시작해요.
- 14~19행: 웹캠에 연결하고 반복문에서 프레임을 한 장씩 읽어요.
- 21~22행: 좌우로 뒤집고, `frame.shape`로 프레임의 높이(`h`)와 너비(`w`)를 구해요.
- 25~26행: 도화지가 아직 없으면 `np.zeros_like(frame)`로 프레임과 크기가 같은 검은 도화지를 만들어요. 처음 한 번만 만들어져요.
- 29~30행: 색 순서를 RGB로 바꾸고 `process()`로 손을 찾아요.
- 33~35행: 손을 찾았으면 첫 번째 손(`[0]`)의 랜드마크 목록을 `lm`에 담아요.
- 38~39행: 검지 끝(`lm[8]`)의 상대 좌표에 너비와 높이를 곱해 픽셀 좌표 `x`, `y`를 구해요.
- 42~43행: 이전 좌표가 (0, 0)이 아니면, 이전 좌표와 현재 좌표를 초록색(`(0, 255, 0)`) 굵기 3짜리 선으로 도화지에 이어 그려요.
- 46행: 지금 좌표를 다음 프레임에서 쓸 이전 좌표로 저장해요.
- 47~49행: 손이 없으면 이전 좌표를 (0, 0)으로 되돌려 선을 끊어요.
- 53~54행: 프레임과 도화지를 반씩 섞어 'Draw' 창에 보여 줘요.
- 56\~57행: q 키를 누르면 끝내요. 60\~61행에서 웹캠을 놓아주고 창을 닫아요.

### 심화 실습 코드 읽기

심화 실습은 기본 실습에 "그리기 스위치"를 더한 코드예요. 스위치처럼 누를 때마다 켜짐과 꺼짐이 바뀌는 것을 토글(toggle)이라고 해요. 달라진 곳만 볼게요.

- 11행: 그리기 모드를 기억하는 변수 `drawing_enabled`를 `False`(꺼짐)로 시작해요. 처음에는 그리지 않아요.
- 42~47행: 그리기 모드가 켜져 있을(`True`) 때만 선을 그려요. 꺼져 있으면 이전 좌표를 (0, 0)으로 되돌려요.
- 57행: `key = cv2.waitKey(1)`로 누른 키를 변수에 담아 두고 두 번 비교해요.
- 60~61행: q 키면 반복을 끝내요.
- 64~66행: d 키면 `drawing_enabled = not drawing_enabled`로 켜짐과 꺼짐을 바꾸고, 바뀐 상태를 콘솔에 적어요.

### 기본 실습 실행하고 결과 보기

첫 번째 예제에서 [이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 'Draw' 창에 검지를 보여 주고 허공에서 움직이면, 검지 끝이 지나간 길이 초록 선으로 남아요. 카메라 영상과 도화지가 반씩 섞여서 영상은 조금 어둡게, 선은 초록색으로 보여요.

재생 동작 '검지로 그리기'로 하면 8자 모양이 그려져요. 이 동작은 처음 0.4초 동안 손이 없다가 나타나서, 한 바퀴를 돌 때마다 선이 잠깐 끊겼다가 다시 이어져요.

:::확인
- 'Draw' 창에 영상이 조금 어둡게 보이고, 검지 끝을 따라 초록 선이 그려져요.

:::왜그럴까

손이 사라지면 49행이 이전 좌표를 (0, 0)으로 되돌려요. 손이 다시 나타난 첫 프레임에서는 42행의 조건이 거짓이라 선을 긋지 않고, 좌표만 저장한 뒤 다음 프레임부터 다시 이어요. 그래서 사라지기 전 자리와 새 자리 사이에 엉뚱한 선이 생기지 않아요.

### 심화 실습 실행하고 결과 보기

두 번째 예제에서 [이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 처음에는 검지를 움직여도 아무것도 그려지지 않아요. 출력 화면을 한 번 누른 뒤 d 키를 누르면(또는 출력 칸 아래의 [d] 버튼) 그리기가 켜지고, 콘솔에 상태가 나와요.

```text
Drawing mode: True
```

d 키를 한 번 더 누르면 `Drawing mode: False`가 나오고 선 그리기가 멈춰요. 이미 그린 선은 남아 있어요.

:::확인
- 실행 직후에는 검지를 움직여도 선이 그려지지 않아요.
- d 키를 누르면 콘솔에 `Drawing mode: True`가 나오고 선이 그려져요.
- d 키를 다시 누르면 `Drawing mode: False`가 나오고 그리기가 멈춰요.
:::

:::왜그럴까[왜 처음에는 선이 안 그려질까?]
11행에서 `drawing_enabled`를 `False`로 시작했기 때문이에요. 42행의 `if drawing_enabled:`가 거짓이라 선을 긋는 44행까지 가지 않아요. d 키를 누르면 65행의 `not`이 `False`를 `True`로 뒤집어서, 그다음 프레임부터 선을 그려요.

기본 실습은 손이 보이기만 하면 늘 선이 그려져서, 원하지 않을 때도 선이 생겼어요. 심화 실습은 키로 스위치를 두어 그리고 싶을 때만 그리게 했어요.
:::

:::

:::왜그럴까[왜 (0, 0, 255)는 빨간색일까?]
OpenCV는 색을 (파랑, 초록, 빨강) 순서로 적어요. `(0, 255, 0)`은 초록만 가장 밝아서 초록색이고, `(0, 0, 255)`는 빨강만 가장 밝아서 빨간색이에요. 흔히 쓰는 (빨강, 초록, 파랑) 순서로 생각하면 파란색일 것 같지만, OpenCV에서는 빨간색이 돼요.
:::

:::오류
교과서 037쪽 46행처럼 `cv2.waitKey(1) = = ord('q')`로 등호 사이를 띄어 쓰면 `SyntaxError`가 나요. 같은지 비교하는 기호는 등호 두 개를 붙인 `==`예요. 오류 메시지의 뜻은 [오류 사전](/help/errors/#syntax-error)에서 찾아볼 수 있어요.
:::

## 도전 과제

::::도전[도전 과제 1: 키로 선 색 바꾸고 그림 저장하기]
심화 실습 코드를 고쳐 r 키를 누르면 빨강, g 키는 초록, b 키는 파랑으로 선 색이 바뀌게 해 보세요. 여기에 s 키를 누르면 지금까지 그린 도화지를 그림 파일로 저장하는 기능도 더해 보세요.

:::힌트
선 색을 담을 변수(예: `color = (0, 255, 0)`)를 반복문 앞에 만들고, 44행의 `(0, 255, 0)` 대신 `color`를 써요. 64행 아래에 `elif key == ord('r'):`처럼 키마다 색을 바꾸는 줄을 더해요. 색은 (파랑, 초록, 빨강) 순서라는 것을 잊지 마세요.

그림은 `cv2.imwrite('drawing.png', canvas)`로 저장해요. 실습실에서는 저장한 파일이 파일 패널에 [내려받기] 단추와 함께 올라와요. 키보드가 없는 태블릿은 출력 칸 아래 화면 키([q], [d], [r], [ESC])만 쓸 수 있으니, r 키를 누를 때마다 색이 차례로 바뀌게 만들어도 좋아요.
:::
::::

::::도전[도전 과제 2: 손가락 모양으로 그리기 켜고 끄기]
키보드 대신 손가락 모양으로 그리기를 켜고 꺼 보세요. 검지만 펴면 그리고, 검지와 중지를 함께 펴거나 주먹을 쥐면 멈추게 만들어요.

:::힌트
손가락이 펴졌는지는 손가락 끝과 가운데 관절의 높이로 알 수 있어요. 손을 세웠을 때 검지가 펴져 있으면 끝(8번)이 가운데 관절(6번)보다 위에 있어요. 위쪽일수록 y가 작으니 `lm[8].y < lm[6].y`이면 검지가 펴진 거예요. 중지는 12번과 10번으로 똑같이 확인해요.

심화 실습 42행의 `if drawing_enabled:`를 `if lm[8].y < lm[6].y and lm[12].y > lm[10].y:`처럼 바꾸면 돼요. 카메라가 없으면 재생 동작 '손가락 0~5개 펴기'로 시험해요. 주먹에서 시작해 검지, 중지 순서로 펴지니, 검지만 펴져 있는 잠깐 동안 짧은 선이 생기고 중지가 펴지면 멈추면 성공이에요.
:::
