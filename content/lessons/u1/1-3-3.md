## 학습목표

- 얼굴 가장자리의 랜드마크 네 개로 얼굴을 감싸는 상자를 그릴 수 있어요.
- 투명한 정도(알파 채널)가 있는 그림을 영상 위에 겹쳐 그리는 원리를 설명할 수 있어요.
- 가면 그림을 얼굴의 크기와 자리에 맞춰 얹는 얼굴 필터 프로그램을 만들 수 있어요.

## 왜 배울까

사진 앱에서 얼굴에 가면이나 안경, 동물 귀를 씌우는 필터를 써 본 적 있나요? 필터가 얼굴을 따라다니려면, 컴퓨터가 프레임마다 얼굴이 어디에 얼마나 크게 있는지 알아내 그림의 크기와 자리를 맞춰야 해요. 오늘은 얼굴의 점으로 가면 그림을 얹는 얼굴 필터를 직접 만들어요.

## 핵심 개념

### 점 네 개로 얼굴을 감싸는 상자

얼굴의 자리와 크기를 알려면 얼굴 가장자리의 점을 봐요. :용어[페이스 메시]의 점 가운데 10번은 이마 위 끝, 152번은 턱 끝, 234번은 얼굴 왼쪽 끝, 454번은 얼굴 오른쪽 끝이에요.

이 네 점으로 얼굴을 딱 감싸는 네모를 그릴 수 있어요. 물체를 둘러싼 이런 네모를 :용어[바운딩 박스](bounding box)라고 해요.

<figure>
<img src="/images/lessons/1-3-3/face-box.svg" alt="정면을 보는 얼굴의 이마 위 끝(10번), 턱 끝(152번), 얼굴 왼쪽 끝(234번), 얼굴 오른쪽 끝(454번)에 빨간 점을 찍고, 네 점에 닿는 초록 네모로 얼굴을 감싼 그림. 왼쪽 위 모서리는 (x1, y1), 오른쪽 아래 모서리는 (x2, y2)이고, 오른쪽에 x1 = 234번의 x × w = 209, y1 = 10번의 y × h = 81, x2 = 454번의 x × w = 430, y2 = 152번의 y × h = 379라는 계산이 있다" width="640" height="380">
<figcaption>왼쪽 위 모서리는 234번의 x와 10번의 y, 오른쪽 아래 모서리는 454번의 x와 152번의 y로 정해요. 숫자는 실습실 재생 입력의 정면 얼굴을 가로 640, 세로 480 화면에서 잰 것이에요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

| 모서리 | x | y |
| --- | --- | --- |
| 왼쪽 위 (x1, y1) | 234번(얼굴 왼쪽 끝)의 x × 너비 | 10번(이마 위 끝)의 y × 높이 |
| 오른쪽 아래 (x2, y2) | 454번(얼굴 오른쪽 끝)의 x × 너비 | 152번(턱 끝)의 y × 높이 |

네 점은 모두 :용어[정규화 좌표]라서, 1-2-2에서처럼 화면의 너비와 높이를 곱해 픽셀 좌표로 바꿔요. 이 상자의 가로 길이가 얼굴의 너비, 세로 길이가 얼굴의 높이예요.

### 투명한 곳이 있는 그림: 알파 채널

컬러 사진의 픽셀은 파랑, 초록, 빨강 세 숫자로 색을 나타내요. PNG 그림은 여기에 네 번째 숫자를 하나 더 가질 수 있는데, 이 숫자를 :용어[알파 채널]이라고 해요.

알파는 그 픽셀이 얼마나 불투명한지를 0부터 255까지로 나타내요. 0이면 완전히 투명하고, 255면 완전히 불투명해요.

<figure>
<img src="/images/lessons/1-3-3/alpha-channel.svg" alt="투명한 곳을 바둑판 무늬로 보인 가면 그림에서 보라색 몸통 픽셀은 (184, 63, 91, 255)로 알파 255라 가면 색이 보이고, 눈 구멍 픽셀은 (0, 0, 0, 0)으로 알파 0이라 투명하다는 설명 그림. 오른쪽에 가면 색과 원래 색을 겹친 결과가 a = 1이면 가면 색만, a = 0.5면 반반 섞인 색, a = 0이면 원래 색 그대로인 색 칸 세 개가 있고, 아래에 결과 = 가면 색 × a + 원래 색 × (1 − a), a = 알파 ÷ 255라는 식이 있다" width="640" height="384">
<figcaption>숫자 네 개의 차례는 파랑, 초록, 빨강, 알파예요. 알파를 255로 나눈 a만큼 가면 색을 쓰고, 나머지(1 − a)만큼 원래 영상 색을 써요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

그림을 겹쳐 그릴 때는 픽셀마다 이렇게 계산해요.

```text
a = 알파 ÷ 255              (0부터 1 사이의 수)
결과 색 = 가면 색 × a + 원래 영상 색 × (1 − a)
```

a가 1이면 가면 색만, 0이면 원래 영상 색만 남아요. 그래서 가면의 눈 구멍과 바깥처럼 알파가 0인 곳에서는 뒤의 얼굴이 그대로 보여요. `cv2.imread("mask.png", cv2.IMREAD_UNCHANGED)`처럼 `IMREAD_UNCHANGED`를 붙여야 이 네 번째 숫자까지 읽어요.

### 가면 그림을 얼굴 크기에 맞춰 얹기

가면 그림을 얼굴에 맞추는 일은 세 단계예요.

1. **얼굴의 너비와 높이 재기:** 234번과 454번 사이의 거리가 얼굴 너비, 10번과 152번 사이의 거리가 얼굴 높이예요. 1-2-3에서 배운 :용어[유클리드 거리]로 재요.
2. **가면 그림 크기 바꾸기:** `cv2.resize(가면, (너비, 높이))`로 가면 그림을 얼굴 크기로 늘이거나 줄여요. 괄호 안은 (가로, 세로) 차례예요.
3. **자리 정해 겹치기:** 가면 그림의 왼쪽 위를 얼굴 상자의 왼쪽 위(234번의 x, 10번의 y)에 맞추고, 그 자리부터 픽셀마다 알파로 섞어 그려요.

<figure>
<img src="/images/lessons/1-3-3/mask-fit.svg" alt="가로 400, 세로 500인 mask.png를 resize 화살표로 줄여, 가로 640, 세로 480 화면 속 얼굴 위에 얼굴 너비 220, 얼굴 높이 297 크기로 겹친 그림. 겹친 파란 점선 네모의 왼쪽 위 모서리는 (209, 81)이고, 가면은 네모의 위쪽, 두 눈 위에 온다" width="640" height="372">
<figcaption>실습실이 넣어 주는 mask.png는 그림의 위쪽에만 가면이 있고 나머지는 투명해요. 그래서 얼굴 높이만큼 늘여 이마부터 그리면 가면이 눈 높이에 와요. 사이트가 직접 그린 그림이에요.</figcaption>

## 따라 하기

예제 두 개를 차례로 실행해요. 기본 실습은 얼굴 둘레에 상자를 그리고, 심화 실습은 얼굴에 가면 그림을 씌워요. 아래 줄 번호는 실습실에 보이는 예제 파일의 줄 번호예요.

예제는 교과서 075쪽, 078쪽 코드를 최신 MediaPipe(1.2.0)에 맞게 다시 쓴 것이라 줄 번호가 교과서와 달라요.

심화 실습은 가면을 겹치는 계산도 바꿨어요. 교과서 코드는 픽셀을 하나씩 세는 반복문으로 가면을 겹쳐서, 브라우저에서는 한 장을 그리는 데 0.6초에서 3초쯤(얼굴이 클수록 오래) 걸려 영상이 뚝뚝 끊겨요. 예제는 결과는 같고 계산 방법만 빨라요(실행 결과 아래 "왜 이런 결과가 나올까" 상자).

MediaPipe 최신 판은 모델 파일(`face_landmarker.task`)을 따로 받아 코드와 같은 폴더에 둬요. 실습실에는 이미 들어 있어서 그대로 실행하면 돼요. 컴퓨터(토니)에서 하려면 [모델 파일 받기](/teacher/real-pc/#모델-파일-받기)를 봐요.

가면 그림 `mask.png`는 사이트가 직접 그린 그림이고, 실습실이 파이썬 작업 폴더에 넣어 줘요.

카메라가 없거나 얼굴을 비추고 싶지 않으면 입력 소스를 '재생 입력(합성 좌표)'으로 골라요. 재생 동작은 '고개 돌리기'로 저절로 바뀌어요.

:::주의[가면을 씌운 화면도 내 얼굴 사진이에요]
- 필터를 씌워도 화면에는 내 얼굴이 담겨 있어요. 화면을 찍거나 파일로 저장해 올리지 않아요.
- 친구 얼굴에 필터를 씌울 때는 먼저 허락을 받아요.
:::

### 기본 실습 코드 읽기

- 2\~5행: 시간(`time`), OpenCV, MediaPipe와 MediaPipe의 영상 인식 도구 모음(`vision`)을 불러와요. 8행: 웹캠에 연결해요.
- 9\~12행: 얼굴 인식 설정(모델 파일 `face_landmarker.task`, 프레임을 차례로 넣는 영상 모드, 얼굴 1개)을 만들고, 13행: 그 설정으로 얼굴을 1개만 찾는 도구 `face_mesh`를 만들어요.
- 16\~19행: 웹캠이 열려 있는 동안 프레임을 읽어요.
- 21\~25행: 좌우로 뒤집고, 프레임의 높이(`h`)와 너비(`w`)를 꺼내고, RGB로 바꾸고, MediaPipe가 읽는 사진 형식(`mp.Image`)으로 감싸, 지금 시각(밀리초)과 함께 얼굴의 점을 찾아요.
- 28\~30행: 얼굴을 찾았으면 얼굴마다 점 목록(`landmarks`)을 꺼내요.
- 33\~36행: 얼굴 왼쪽 끝(234번), 오른쪽 끝(454번), 이마 위 끝(10번), 턱 끝(152번) 점을 꺼내요.
- 39\~40행: 왼쪽 위 모서리 (x1, y1)과 오른쪽 아래 모서리 (x2, y2)를 픽셀 좌표로 구해요.
- 43행: `cv2.rectangle()`로 두께 2인 초록 네모를 그려요.
- 46행: 'Face Bounding Box' 창에 보여 주고, 48\~49행: q 키를 누르면 끝내요. 52\~54행: 얼굴 인식 도구를 닫고 정리해요.

### 심화 실습 코드 읽기

- 6행: 배열 계산 라이브러리 `numpy`를 `np`라는 이름으로 불러와요. 2\~5행은 기본 실습과 같아요.
- 9\~14행: 얼굴 인식 설정을 영상 모드, 얼굴 1개, 얼굴 찾기 신뢰도 기준 0.5(`min_face_detection_confidence=0.5`)로 만들어요. 15행: 그 설정으로 얼굴 인식 도구 `face_mesh`를 만들어요.
- 18행: `cv2.imread()`로 가면 그림을 알파 채널까지 읽어요.
- 24행: 얼굴에 가면을 겹치는 함수 `overlay_mask_on_face(frame, landmarks, mask)`를 만들어요.
- 25\~28행: 이마(10번), 턱(152번), 왼쪽 뺨(234번), 오른쪽 뺨(454번) 점을 꺼내요.
- 30\~38행: `np.linalg.norm()`으로 두 뺨 사이의 거리(얼굴 너비)와 이마와 턱 사이의 거리(얼굴 높이)를 구해 픽셀로 바꿔요. `norm`은 두 점의 차이로 유클리드 거리를 구하는 함수예요.
- 41\~42행: 얼굴이 너무 작으면 가면을 그리지 않고 그대로 돌려줘요(교과서 코드에 없던 줄).
- 44행: `cv2.resize()`로 가면 그림을 얼굴 크기로 바꿔요.
- 46\~47행: 가면을 그리기 시작할 왼쪽 위 자리(234번의 x, 10번의 y)를 구해요.
- 50\~56행: 가면 가운데 화면 밖으로 나가는 부분을 잘라 내고, 화면 안에 들어오는 조각(`piece`)만 남겨요.

바꿔 보기 1의 두께 `-1`은 "선이 아니라 속을 채워 그려라"라는 뜻이에요. 그래서 얼굴이 초록 네모로 가려져요. 바꿔 보기 3처럼 그리기 시작하는 자리를 눈 높이로 내리면, 가면 그림 전체가 아래로 내려가 가면이 코와 입 쪽을 덮어요.

::::도전[도전 과제 1: 코드로 선글라스 필터 그리기]
가면 그림 파일을 쓰지 않고, 코드로 투명한 그림을 만들어 선글라스를 그려 보세요. `np.zeros()`로 모든 픽셀이 0인(완전히 투명한) 네 겹 그림을 만들고, 그 위에 알파 255로 동그라미 두 개를 그리면 돼요.

:::힌트
심화 실습 18행을 아래 네 줄로 바꿔요. 줄이 3개 늘어나니, 그 아래 줄 번호는 3씩 밀려요.

```python
mask_image = np.zeros((500, 400, 4), dtype=np.uint8)                  # 세로 500, 가로 400, 네 겹 — 처음엔 모두 투명
cv2.circle(mask_image, (120, 216), 60, (40, 40, 40, 255), -1)        # 왼쪽 렌즈(알파 255)
cv2.circle(mask_image, (280, 216), 60, (40, 40, 40, 255), -1)        # 오른쪽 렌즈
cv2.line(mask_image, (175, 216), (225, 216), (40, 40, 40, 255), 10)   # 두 렌즈를 잇는 다리
```

(120, 216)과 (280, 216)은 실습실의 가면 그림에서 두 눈 구멍이 있던 자리예요. 색의 네 번째 숫자 255가 알파라서 렌즈만 보이고 나머지는 투명해요. 색이나 모양을 바꿔 나만의 필터를 만들어 봐요.
:::
::::

::::도전[도전 과제 2: 얼굴을 가려 주는 모자이크 필터]
사진을 올리기 전에 다른 사람의 얼굴을 가려 주는 기능은 개인정보를 지키는 데 쓰여요. 기본 실습의 얼굴 상자 안을 모자이크로 가려 보세요. 상자 안을 아주 작게(8×8) 줄였다가 다시 원래 크기로 늘리면 네모난 조각 무늬가 돼요.

:::힌트
기본 실습 40행 아래에 아래 줄을 넣어요(12칸 들여쓰기).

```python
            x1, x2 = max(0, min(x1, x2)), min(w, max(x1, x2))
            y1, y2 = max(0, y1), min(h, y2)
            if x2 > x1 and y2 > y1:
                small = cv2.resize(frame[y1:y2, x1:x2], (8, 8))
                frame[y1:y2, x1:x2] = cv2.resize(small, (x2 - x1, y2 - y1), interpolation=cv2.INTER_NEAREST)
```

첫 두 줄은 두 모서리를 작은 값, 큰 값 차례로 맞추고 화면 밖으로 나가지 않게 잘라요. `frame[y1:y2, x1:x2]`는 영상에서 상자 안만 꺼낸 조각이에요.

`INTER_NEAREST`는 늘릴 때 옆 픽셀과 섞지 않아서 조각 무늬가 또렷하게 남아요. `(8, 8)`을 `(16, 16)`으로 바꾸면 조각이 더 잘아져요.
:::

### 원고와 코드 파일

- 원고(교과서 052\~111쪽)가 자료에 없어, 코드 파일(파일명 p75·p78)을 근거로 사이트가 본문을 새로 썼어요. 원고를 받으면 원고 문장으로 바꿔요.
- 두 예제는 코드 파일의 구조, 변수 이름, 화면 글자를 그대로 두고 MediaPipe를 쓰는 줄만 최신 사용법으로 바꿨어요. 그래서 줄 번호가 코드 파일과 달라요. 심화 실습은 여기에 더해 얼굴이 너무 작을 때 넘어가는 세 줄(40\~42행)을 넣고, 픽셀마다 도는 반복문을 화면 안 조각만 자르는 줄(49\~56행)과 `numpy` 한 번 계산(58\~62행)으로 바꿨어요. 판 1.7까지 따로 두던 사이트판(`1-3-3-adv-face-mask-site.py`)의 고친 점을 이 파일에 합쳤어요.
- 교과서 075·078쪽 코드는 옛 MediaPipe(0.10.21 이하)의 `mp.solutions` 사용법이에요. 이 사이트는 토니 5.0(파이썬 3.14)과 mediapipe 1.2.0 기준이라 예제(`examples/vision/u1/1-3-3-face-box.py`, `examples/vision/u1/1-3-3-adv-face-mask.py`)를 Tasks API(`vision.FaceLandmarker`)로 다시 썼어요(판 1.8.0 — 운영자 결정). 교과서 코드는 mediapipe 0.10.30부터 `AttributeError: module 'mediapipe' has no attribute 'solutions'`로 멈춰요.

| 코드 | 교과서 078쪽 코드(파일명 p78) | 예제 |
| --- | --- | --- |
| `cv2.imread("mask.png", …)` | 15행 | 18행 |
| `def overlay_mask_on_face` | 21행 | 24행 |
| 얼굴 너비, 높이 계산 | 27\~35행 | 30\~38행 |
| `cv2.resize()` | 37행 | 44행 |
| 그리기 시작 자리 | 39\~40행 | 46\~47행 |
| 겹쳐 그리기 | 42\~51행(반복문 세 겹) | 49\~62행(`numpy`) |
| `cv2.flip()` | 60행 | 71행 |
| `cv2.imshow()` | 70행 | 82행 |

- 교과서 코드에는 `mask.png` 파일이 자료에 없어서, 사이트가 가면 그림을 직접 그려(SVG) 실습실이 PNG로 바꿔 넣어 줘요. 교과서 코드는 그리기 시작 자리가 화면 왼쪽이나 위쪽 밖이면(음수) 가면이 반대편 가장자리에 그려지는 결함이 있어요. 예제는 화면 안의 조각만 그려서 이 문제가 없어요.
- 그림은 모두 사이트가 그렸고, 얼굴은 실습실 재생 입력과 같은 계산으로 만든 선 그림이에요(사람 사진 없음).
