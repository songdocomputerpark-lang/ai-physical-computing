## 학습목표

- 손가락 위치를 인식하고, 손가락 끝 좌표 사이의 거리를 계산할 수 있어요.
- 손가락 거리 값으로 원의 크기를 실시간으로 조절하는 프로그램을 만들 수 있어요.

## 왜 배울까

스마트폰에서 사진을 크게 보거나 작게 볼 때 두 손가락을 벌리거나 오므려요. 이렇게 두 손가락 사이의 거리로 화면을 다루는 방법은 누구나 쉽게 이해할 수 있어서 일상에서 자주 쓰여요. 컴퓨터가 카메라로 두 손가락 끝의 거리를 계산할 수 있으면, 화면을 만지지 않고 허공에서도 같은 조작을 할 수 있어요.

## 핵심 개념

### 두 손가락 끝의 좌표

손가락 사이의 거리를 재려면 먼저 두 손가락 끝의 위치를 알아야 해요. MediaPipe Hands는 손가락 끝마다 :용어[랜드마크] 번호를 정해 두었는데, 엄지 끝은 4번, 검지 끝은 8번이에요.

MediaPipe가 주는 좌표는 화면 크기를 1로 본 0과 1 사이의 :용어[상대 좌표]{항목=normalized-coordinates}라서, 1-2-2에서 배운 대로 화면의 너비와 높이를 곱해 픽셀 좌표 (x₁, y₁), (x₂, y₂)로 바꿔요. 두 점을 픽셀 좌표로 알면, 그 사이의 거리를 수학으로 계산할 수 있어요.

### 유클리드 거리

두 점 사이의 직선 거리를 :용어[유클리드 거리]라고 해요. 두 점의 가로 차이와 세로 차이를 두 변으로 하는 직각삼각형을 그리면, 두 점을 잇는 선은 빗변이 돼요. 그래서 피타고라스 정리로 길이를 구할 수 있어요.

<figure>
<img src="/images/lessons/1-2-3/euclidean-distance.svg" alt="왼쪽은 엄지 끝(4번)과 검지 끝(8번)을 초록 선 d로 이은 손 그림이다. 오른쪽은 엄지 끝 (300, 400)과 검지 끝 (600, 800)을 잇는 선을 빗변으로 하고, 가로 차이 300과 세로 차이 400을 두 변으로 하는 직각삼각형이며, 아래에 d = √(300² + 400²) = √250000 = 500이라는 계산이 있다" width="640" height="330">
<figcaption>두 손가락 끝 사이의 거리는 가로 차이와 세로 차이로 만든 직각삼각형의 빗변이에요. 교과서 043쪽의 예를 사이트가 다시 그린 그림이에요.</figcaption>
</figure>

```text
유클리드 거리 d = √((x₂ − x₁)² + (y₂ − y₁)²)
```

예를 들어 엄지 끝이 (300, 400), 검지 끝이 (600, 800)이면 거리는 이렇게 계산해요.

```text
d = √((600 − 300)² + (800 − 400)²)
  = √(90000 + 160000)
  = √250000
  = 500(픽셀)
```

파이썬에서는 `math` :용어[라이브러리]의 `math.hypot(x2 - x1, y2 - y1)`이 같은 계산을 해 줘요. 손가락을 오므리면 거리가 작아지고, 벌리면 거리가 커져요.

### 거리 값을 화면에 쓰기

거리는 숫자라서 화면 요소의 크기, 색, 위치에 바로 이을 수 있어요. 이번 차시의 심화 실습은 거리를 원의 반지름으로 써요. OpenCV에서 원은 `cv2.circle()`로 그려요.

<figure>
<img src="/images/lessons/1-2-3/circle-args.svg" alt="가로 640, 세로 480 화면의 한가운데 (320, 240)에 중심 점이 있고, 중심에서 원 둘레까지 그은 화살표에 반지름 = distance라고 적힌 노란 원 그림. 오른쪽에 cv2.circle(frame, (cx, cy), distance, (0, 255, 255), 3)의 값마다 그릴 사진, 중심, 반지름, 색(노랑), 굵기라는 설명이 붙어 있다" width="640" height="280">
<figcaption>원의 중심은 화면 한가운데로 두고, 반지름 자리에 손가락 사이 거리를 넣어요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

| `cv2.circle()`의 값 | 뜻 | 심화 실습에서 |
| --- | --- | --- |
| `frame` | 원을 그릴 사진 | 웹캠 프레임 |
| `(cx, cy)` | 원의 중심 | 화면 한가운데 `(w // 2, h // 2)` |
| `distance` | 반지름(픽셀, 정수) | 두 손가락 사이 거리 |
| `(0, 255, 255)` | 색(파랑, 초록, 빨강 순서) | 노랑(초록과 빨강을 섞은 색) |
| `3` | 선의 굵기(픽셀) | 3픽셀 |

`w // 2`의 `//`는 나눗셈의 몫만 구하는 기호예요. 640 // 2는 320이라, 화면 한가운데의 x 좌표가 돼요. 픽셀 좌표는 정수여야 해서 `/` 대신 `//`를 써요.

`cv2.error: … Argument 'radius' is required to be an integer`가 나면 원의 반지름에 소수가 들어간 거예요. 43행의 `int()`를 지웠거나 반지름에 `/`로 나눈 값을 넣으면 생겨요. `int(distance)`처럼 정수로 바꿔 넣어요. 오류 메시지의 뜻은 [오류 사전](/help/errors/#cv2-bad-argument)에서 찾아볼 수 있어요.
:::

::::도전[도전 과제 1: 거리를 2초 동안 지키면 통과]
두 손가락 사이 거리가 100픽셀보다 작은 상태가 2초 넘게 이어질 때만 화면에 `PASS`가 나타나게 기본 실습을 고쳐 보세요. 거리가 100 이상이 되면 처음부터 다시 재요. 먼저 "거리가 몇 픽셀보다 작으면 무엇을 할지"처럼 숫자가 든 조건을 하나 정해 보는 것부터 시작해요(교과서 043쪽 해 보기).

:::힌트
`import time`을 더하고 반복문 앞에 `start = None`을 두어, 거리가 100보다 작아진 첫 순간의 시각을 `start = time.time()`으로 적어 둬요. 그 뒤에는 `time.time() - start`가 지나간 초예요. 2 이상이면 `cv2.putText(frame, 'PASS', (10, 100), cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 255, 0), 3)`로 글자를 적고, 거리가 100 이상이 되면 `start = None`으로 되돌려요.

`cv2.putText()`는 한글을 쓰지 못해 `?`로 보여요. 그래서 "통과" 대신 `PASS`처럼 영어로 적거나, 한글은 `print()`로 콘솔에 적어요. 카메라가 없으면 재생 동작 '검지로 그리기'(거리가 80 안팎으로 계속 작아요)와 '엄지·검지 핀치'(100보다 작은 때가 2초보다 짧아요)로 결과를 견주어 봐요.

### 자주 막히는 곳

- 거리 숫자가 친구와 달라요. 거리는 픽셀 단위라 카메라와 손 사이 거리, 화면 크기에 따라 바뀌어요. 실습실 영상은 640×480이에요.
- 기본 실습의 거리 글자가 두 개 겹쳐 보여요. `Hands()`의 기본값이 손 2개까지라서예요. 바꿔보기 3의 풀이 상자를 함께 보세요.
- `//`(몫)와 `/`(나눗셈)를 헷갈려요. 픽셀 좌표와 반지름은 정수여야 해서 `//`나 `int()`를 써요. 반지름에 소수가 들어가면 오류가 나요.
- `(0, 255, 255)`가 노랑인 까닭을 물어요. OpenCV의 색 순서는 (파랑, 초록, 빨강)이라 초록과 빨강을 섞은 노랑이에요.
- 기본 실습의 파란 거리 글자는 재생 입력의 어두운 바탕에서 잘 안 보여요. 심화 실습은 노란 글자라 잘 보여요.
- `cv2.putText()`에 한글을 넣으면 `?`로 나와요. 도전 과제 1은 영어 글자나 `print()`를 쓰게 해요.
