## 핵심 개념

### 영상 인식과 특징 추출

인공지능 영상 인식은 컴퓨터가 이미지나 동영상을 분석해서 사람처럼 내용을 알아보고 이해하는 기술이에요. 영상을 화면에 보여 주는 데서 그치지 않고, 영상 속 사물이나 사람, 장소를 구별하고 그 뜻을 파악해요. 보안, 의료, 스마트 시티, 자율주행 같은 여러 분야에서 쓰여요.

영상을 알아보려면 영상 속에서 의미 있는 특징을 뽑아내야 해요. 손을 알아볼 때는 손가락 끝과 마디의 위치를, 얼굴을 알아볼 때는 눈, 코, 입의 위치와 모양을 살피는 것처럼요. 이렇게 영상에서 알아보는 데 필요한 특징을 뽑아내는 일을 :용어[특징 추출](Feature Extraction)이라고 하고, 특징을 잘 뽑을수록 인식이 정확하고 믿을 만해져요.

<figure>
<img src="/images/lessons/1-1-2/feature-flow.svg" alt="영상 인식의 세 단계 그림: ① 카메라가 찍은 편 손 영상에서 ② 손가락 끝, 마디, 손목 자리를 파란 점과 선으로 뽑아내고(특징 추출) ③ 그 특징으로 손가락 다섯 개가 모두 펴진 편 손이라고 판단한다" width="640" height="290">
<figcaption>영상(①)에서 손가락 끝, 마디, 손목처럼 의미 있는 부분만 뽑아내고(②), 그 특징으로 무엇인지 판단해요(③). 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

인공지능 영상 인식은 이런 특징 추출을 바탕으로 여러 응용 기술과 함께 쓰여요. 대표적인 기술과 쓰임은 다음과 같아요.

| 기술 종류 | 기술 설명 | 기술 활용 예 |
| --- | --- | --- |
| 물체 인식 | 영상 속에서 특정 물체를 찾아 구별해요. | 주변 환경을 알아보거나 작업을 자동으로 하는 데 써요. |
| 얼굴 인식 | 사람 얼굴의 특징을 분석해 누구인지 알아봐요. | 얼굴 특징을 뽑아 데이터베이스(모아 둔 자료)의 정보와 비교해요. |
| 행동 인식 | 사람이나 사물의 움직임을 분석해 행동을 해석해요. | 걷기, 뛰기처럼 이어지는 행동을 알아차려요. |
| 문자 인식 | 영상 속 글자를 디지털 데이터로 바꿔요. | 글자 모양을 분석해 컴퓨터가 읽을 수 있게 바꿔요. |
| 의료 영상 분석 | 의료 영상을 분석해 병을 진단하거나 치료를 도와요. | 몸속 조직이나 이상한 부위를 찾아 변화를 살펴요. |

:::참고[얼굴 사진은 개인정보예요]
얼굴 사진으로는 그 사람이 누구인지 알 수 있어요. 그래서 얼굴 사진은 함부로 모으거나 공개하면 안 되는 개인정보예요. 이 사이트의 실습에는 얼굴로 사람을 알아보는 활동이 없어요.
:::

### 딥러닝과 합성곱 신경망(CNN)

인공지능 영상 인식은 :용어[기계학습]과 :용어[딥러닝]이라는 학습 방법으로 움직여요. 기계학습은 컴퓨터가 데이터에서 규칙을 스스로 배우는 방법이고, 딥러닝은 여러 층으로 쌓은 인공 신경망(사람 뇌의 신경 세포가 이어진 모습을 흉내 낸 계산 구조)으로 배우는 기계학습이에요. 이렇게 데이터로 학습해서 판단하는 프로그램을 인공지능 **모델**이라고 해요.

딥러닝 모델 가운데 :용어[합성곱 신경망](CNN, Convolutional Neural Network)은 이미지와 영상을 분석하는 데 특히 뛰어나서 영상 인식의 핵심 역할을 해요.

CNN은 사람이 사물을 알아보는 과정을 흉내 내요. 사람은 먼저 선, 색, 모양 같은 단순한 특징을 보고 그것을 모아 전체를 알아봐요. CNN도 처음에는 단순한 윤곽선을 찾고, 뒤로 갈수록 그것을 합쳐 더 복잡한 패턴과 물체를 알아봐요.

<figure>
<img src="/images/lessons/1-1-2/cnn-stages.webp" alt="고양이 그림을 입력으로 받아 초기 단계에서 선과 모서리 같은 단순한 특징을, 중간 단계에서 눈, 코, 귀 같은 부분을 찾고, 최종 단계에서 고양이라고 예측하는 CNN의 세 단계 그림" width="960" height="486">
<figcaption>아래(입력)에서 위(예측 결과)로 올라갈수록 더 복잡한 특징을 찾아요. 교과서 014쪽 그림이에요.</figcaption>
</figure>

| 단계 | 하는 일 |
| --- | --- |
| 초기 단계 | 선이나 모서리처럼 단순하고 기본적인 특징을 찾아요. |
| 중간 단계 | 찾은 특징을 조합해 더 복잡한 패턴이나 질감(눈, 코, 귀 같은 부분)을 알아봐요. |
| 최종 단계 | 전체 형태를 분석해 영상 속 물체가 무엇인지 분류해요(예: 고양이). |

예전의 :용어[컴퓨터 비전] 기술은 사람이 색, 모서리, 질감 같은 특징을 하나하나 정해 주어야 했어요. CNN은 데이터만 충분하면 중요한 특징을 스스로 배워 찾아요. 1-1-1에서 본 "사람이 정한 규칙"과 "데이터에서 배운 기준"의 차이와 같아요.

:::참고[CNN을 활용한 예]
미국 스탠퍼드 대학교가 개발한 CheXNet(2017)은 CNN으로 가슴 엑스레이 영상을 보고 병을 진단하는 모델이에요. 엑스레이 영상 10만 장 넘게 학습해서, 영상 의학 전문의에 가까운 정확도를 보여 주었어요.
:::

### 합성곱과 필터

CNN에서 가장 중요한 계산은 :용어[합성곱](Convolution)이에요. 합성곱은 이미지 위에 작은 :용어[필터](커널이라고도 해요)를 한 칸씩 옮겨 가며 계산해서 중요한 특징을 뽑아내는 방법이에요. 돋보기를 옮겨 가며 이미지를 구석구석 살펴보는 것과 비슷해요.

<figure>
<img src="/images/lessons/supplement/s10-filter-slide.svg" alt="왼쪽 6×6 숫자 격자 위를 파란 3×3 필터 창이 한 칸씩 옮겨 다니고, 창이 지나간 자리마다 겹친 아홉 칸을 계산한 새 숫자가 오른쪽 4×4 결과 격자에 하나씩 채워지는 그림" width="660" height="320">
<figcaption>필터(파란 네모)가 숫자 표 위를 한 칸씩 옮겨 다니며, 겹친 아홉 칸을 계산해 결과 표에 숫자를 하나씩 적어요. 이 그림의 필터는 아홉 칸의 평균을 내어 사진을 흐리게 하는 필터예요. CNN은 선이나 모서리를 찾는 필터의 숫자를 데이터에서 스스로 배워요. 움직임 줄이기 설정에서는 마지막 장면만 보여요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

이 계산을 거치면 중요한 정보는 강조되고 필요 없는 정보는 줄어들어 물체를 더 정확하게 알아볼 수 있어요. 컴퓨터는 이미지를 수많은 픽셀의 모임으로 받고, CNN은 픽셀 숫자에서 윤곽선, 색, 질감 같은 특징을 단계별로 배워 그 뜻을 알아내요. 사진이 숫자라는 것은 [V1 사진은 숫자다](/learn/u1/v1/)에서, 필터로 사진을 흐리게 하는 것은 [V4 블러와 에지](/learn/u1/v4/)에서 직접 확인해요.

### CNN을 바탕으로 한 기술: YOLO와 MediaPipe

CNN을 바탕으로 한 영상 인식 기술은 여러 분야에서 쓰여요. 대표적인 예가 딥러닝 물체 인식 모델인 YOLO(You Only Look Once)와 영상 처리 :용어[프레임워크]인 MediaPipe예요. 프레임워크는 어떤 기능을 쉽게 만들 수 있도록 미리 만들어 둔 도구와 뼈대예요.

아래 표의 **증강 현실**(AR, Augmented Reality)은 실제 화면 위에 가상의 그림을 겹쳐 보여 주는 기술이에요.

| 기술 | 특징 | 쓰이는 곳 |
| --- | --- | --- |
| YOLO | 이미지를 한 번만 분석해서 여러 물체를 실시간으로 빠르게 찾아요. | 자율주행 자동차(보행자, 장애물, 신호등 찾기), 보안 시스템(침입자 찾기), 증강 현실 게임 |
| MediaPipe | 얼굴, 손, 자세 같은 몸의 특징을 실시간으로 따라가요. 가벼운 CNN 모델을 써서 스마트폰에서도 잘 돌아가요. | 증강 현실 필터(얼굴에 가상 그림 씌우기), 피트니스 앱(운동 자세 분석) |

MediaPipe는 누구나 코드를 보고 쓸 수 있게 공개한 **오픈 소스**이고, 미리 학습시킨 인공지능 모델을 함께 줘요. 그래서 따로 학습시키지 않아도 복잡한 영상 인식 기능을 쉽게 만들 수 있어요.

### MediaPipe의 주요 기능

MediaPipe가 주는 기능은 크게 두 가지로 나눌 수 있어요. 먼저 영상 속 물체와 구조를 알아보는 기능이에요.

### 랜드마크

:용어[랜드마크]는 이미지나 영상 속에서 사람의 얼굴, 손, 몸 같은 특정 부위의 위치를 숫자로 나타낸 기준점이에요. 손가락 마디, 눈, 코, 입, 몸의 관절이 저마다 랜드마크 하나로 표시되고, 인공지능은 이 점들로 사람의 움직임이나 표정을 알아봐요.

| 랜드마크 | 점의 수 | 알 수 있는 것 |
| --- | --- | --- |
| 손 랜드마크(Hand Landmark) | 21곳 | 손가락의 움직임과 손 모양 |
| 얼굴 랜드마크(Face Landmark) | 468곳 | 얼굴 표정, 시선 방향, 입 모양 |
| 자세 랜드마크(Pose Landmark) | 33곳 | 온몸의 자세와 움직임 |

<img src="/images/lessons/1-1-2/hand-landmarks.webp" alt="손목(0번)부터 손가락 끝까지 마디마다 0~20번 번호가 붙은 점 21개를 선으로 이은 손 랜드마크 그림" width="355" height="367">
<figcaption>손 랜드마크 21곳이에요. 손목이 0번, 엄지 끝이 4번, 검지 끝이 8번이에요. 교과서 016쪽 그림이에요.</figcaption>
</figure>

MediaPipe는 안드로이드, iOS, 데스크톱 컴퓨터 같은 여러 기기에서 잘 돌아가고, 파이썬, 자바스크립트, C++ 같은 여러 프로그래밍 언어를 지원해요. 웹캠과 파이썬 코드 몇 줄만 있으면 손의 21개 관절 위치를 찾아 화면에 보여 줄 수 있어요. 따라하기에서 직접 해 봐요.

## 따라하기

교과서 017쪽의 손 인식 코드를 실습실에서 돌려 봐요. 카메라가 없어도 실습실이 만든 손 좌표(재생 입력)로 똑같이 할 수 있어요.

### 코드 읽기

코드의 줄 번호는 교과서 017쪽과 같아요.

- 1~2행: OpenCV(`cv2`)와 MediaPipe(`mp`) :용어[라이브러리]를 불러와요.
- 4~5행: 손 인식 모델을 준비하고(`Hands()`), 랜드마크를 그리는 도구(`drawing_utils`)를 불러와요.
- 7행: 웹캠(0번 카메라)에 연결해요.
- 9~12행: 계속 반복하면서 :용어[프레임](영상을 이루는 사진 한 장)을 읽어요. 읽지 못하면 반복을 끝내요.
- 13행: 색 순서를 파랑, 초록, 빨강(BGR)에서 빨강, 초록, 파랑(RGB)으로 바꿔요. 손 인식 모델이 RGB 순서의 사진을 받기 때문이에요. 교과서 017쪽에는 이 줄이 빠져 있어서 사이트가 채웠어요.
- 14행: 손 인식을 실행해 결과(`result`)를 받아요.
- 16~22행: 손을 찾았으면 찾은 손마다 관절 점과 이음선을 그려요.
- 24행: 결과 영상을 'Hand' 창에 보여 줘요. 26~27행: q 키를 누르면 반복을 끝내요.
- 29~30행: 웹캠을 놓아주고 창을 모두 닫아요.

### 실행하고 결과 보기

[이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 처음 한 번은 파이썬과 OpenCV를 받느라 조금 걸려요. 브라우저가 카메라 사용을 물으면 "허용"을 눌러요.

![프로그램 창 속 편 손바닥 위에 손가락 마디마다 빨간 점이 찍히고 점들이 흰 선으로 이어진 손 인식 결과 화면](/images/lessons/1-1-2/hand-tracking-result.webp)

:::확인
- 'Hand' 창에 영상이 보이고, 손이 보이면 관절마다 빨간 점이 찍혀요.

## 바꿔보기

:::바꿔보기
1. 4행을 `hands = mp.solutions.hands.Hands(max_num_hands=1)`로 바꾸고, 재생 동작 '두 손'으로 실행해 보세요. 빨간 점이 몇 개의 손에 찍히나요?
2. 26행의 `cv2.waitKey(1)`을 `cv2.waitKey(500)`으로 바꿔 보세요. 'Hand' 창의 영상이 어떻게 달라지나요?
3. 13행의 글자를 모두 지워 빈 줄로 만들고 실행해 보세요. 교과서 017쪽 코드와 똑같아져요. 어떤 오류가 나나요?
:::

:::왜그럴까[왜 waitKey(500)이면 영상이 뚝뚝 끊길까?]
`cv2.waitKey(1)`은 키 입력을 1밀리초(1000분의 1초)만 기다리고 다음 프레임으로 넘어가요. 500으로 바꾸면 프레임마다 0.5초씩 기다리니 1초에 두 장만 보여요. 영상은 사진을 빠르게 이어서 보여 주는 것이라, 1초에 보여 주는 장수가 줄면 뚝뚝 끊겨 보여요.
:::

:::오류
13행을 비우면 14행에서 `NameError: name 'img_rgb' is not defined`가 나요. 14행이 쓰는 `img_rgb`를 만든 적이 없다는 뜻이에요. 교과서 017쪽 코드에 이 줄이 빠져 있어서 생기는 오류라, 사이트는 13행에 이 줄을 채웠어요. 오류 메시지의 뜻은 [오류 사전](/help/errors/#name-error)에서 찾아볼 수 있어요.
:::

### 지도안 요약(50분, 사이트가 제안하는 흐름)

1. 도입(5분): "왜 배울까" 그림으로 사람이 보는 사진과 컴퓨터가 받는 숫자 표를 견주고, "컴퓨터는 숫자에서 어떻게 손을 알아볼까?"를 물어요.

- 인공지능 영상 인식 기술의 원리와 주요 활용 분야를 설명할 수 있는가?
- MediaPipe를 활용하여 손 인식 프로그램을 구현할 수 있는가?

관찰할 곳: CNN 그림을 "단순한 특징 → 복잡한 특징 → 분류" 순서로 말하는지 봐요. 따라하기 코드에서 "손 찾기(14행)"와 "그리기(18~22행)"를 나눠 설명하는지, 도전 과제 2에서 고른 기능과 해결할 문제를 알맞게 잇는지도 봐요.

### 자주 막히는 곳

- 특징 추출과 CNN의 관계를 헷갈려요. "예전 방법은 사람이 특징을 정하고, CNN은 특징을 스스로 배운다"로 1-1-1의 규칙 기반·학습 기반 비교와 이어 주세요.
- 합성곱을 어려운 수학으로 느껴요. 필터가 숫자 표 위를 옮겨 다니며 계산한다는 그림만 이해하면 충분해요. 보충 V4에서 같은 필터를 코드로 직접 써 봐요.
- 카메라가 없거나 손 인식 모델 파일을 받지 못한 컴퓨터에서는 손이 잡히지 않아요. 입력 소스를 '재생 입력(합성 좌표)'으로 바꾸면 카메라와 모델 없이 끝까지 할 수 있어요.
- 재생 입력 화면에는 실습실이 그린 손(흰 뼈대와 하늘색 점)이 원래 보여요. 학생 코드가 그린 것은 빨간 점이라는 것을 짚어 주세요(바꿔보기 1에서 특히 헷갈려요).
- 13행을 왜 넣었는지 물으면 보충 V2(색공간과 흑백)의 BGR·RGB 그림으로 설명해요.
- 실습실의 "인식(mediapipe)" 칸에는 얼굴 점이 478개라고 나와요. 교과서의 468개에 눈동자 점 10개를 더한 수라서, 둘 다 맞는 말이라고 알려 주세요(얼굴 랜드마크는 03 중단원에서 다뤄요).

### 원고에서 바꾼 곳

- 원고 013~018쪽(학습 목표, 본문, 표, 코드, 학습 활동, 자기 평가)을 차시 틀에 맞게 옮기고 문장을 다듬었어요. 학습 활동 1·2는 도전 과제 1로, 학습 활동 3은 도전 과제 2로, 자기 평가와 성취 계획은 위 평가 포인트로 옮겼어요.
- 013쪽의 특징 추출 도식은 학생 얼굴 사진이라 쓰지 않고(개인정보), 같은 과정을 손으로 바꿔 사이트가 그렸어요(영상 인식의 세 단계 그림). 015쪽 기능 카드의 사진(강아지와 고양이, 백로, 인물)과 016쪽 얼굴 랜드마크·자세 추적·동작 인식 카드의 사진도 쓰지 않고 사이트가 그린 그림과 표로 바꿨어요. 인물 사진은 개인정보라서, 나머지는 원고 그림 도구의 엄격한 얼굴 검사를 통과하지 못해서예요.
- 014쪽 CNN 단계 그림, 016쪽 손 랜드마크 그림과 달걀 쥔 손 사진, 017쪽 실행 결과 화면은 원고 그대로예요(앞의 셋은 출판사가 조판할 때 넣은 그림). 017쪽 결과 화면은 옆의 캐릭터와 말풍선을 빼고 잘랐어요.
- 016쪽 얼굴 랜드마크 번호 그림은 쓰지 않았어요. 그림의 번호(약 106개)가 본문의 468개와 달라 헷갈리기 때문이에요.
- 017쪽 코드 14행의 `img_rgb`는 만드는 줄이 없어서 그대로 돌리면 NameError가 나요. 교과서 코드 파일(`examples/vision/u1/1-1-2-hands-first.py`, 코드 id f026)은 14행이 `hands.process(img)`라 색 순서를 바꾸지 않고 넘겨요. 따라하기의 사이트판(`1-1-2-hands-first-site.py`)은 빈 줄이던 13행에 `img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`를 채워서, 줄 번호가 원고와 같고 원고 14행이 그대로 돌아요. 원본과 사이트판은 예제 갤러리에서 견줄 수 있어요.
- 018쪽 학습 활동의 사진 세 장(석고상, 얼룩말, 자전거)은 쓰지 않고, 같은 세 기법을 사이트가 그린 그림(특징을 찾는 세 가지 방법)으로 바꿨어요. 석고상은 판매용 그림 사이트(스톡)의 사진이고, 얼룩말과 자전거도 스톡 사진으로 보여 웹에서 쓸 권리를 확인할 수 없기 때문이에요.
- 015쪽 이미지 분류 카드의 "백로 95%"는 사이트 그림에서 "새 95%"로 바꿨어요. "왜 배울까" 그림, 세 가지 방법 그림, 기능 그림은 사이트가 새로 그렸고, 합성곱 그림은 보충 V4와 같은 그림이에요.
