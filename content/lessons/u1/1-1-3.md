## 왜 배울까

컴퓨터가 영상에서 손을 알아보게 하려면 복잡한 수학 계산이 많이 필요해요. 그래도 코드를 쓰고 실행하는 도구와, 필요한 기능을 미리 만들어 둔 코드 묶음이 있으면 몇 줄의 코드로 손 인식 프로그램을 만들 수 있어요. 이 차시에서는 그 도구들이 무엇인지, 그리고 이 사이트에서는 설치 없이 어떻게 쓰는지 알아봐요.

## 핵심 개념

### 개발 환경과 통합 개발 환경

인공지능 인식 기능을 만들려면 그 일을 돕는 도구가 필요해요. 특히 영상을 실시간으로 처리하려면 카메라 입력을 분석하는 소프트웨어 도구가 꼭 있어야 해요. 이렇게 프로그램을 만들고 실행하는 데 쓰는 도구를 모두 합쳐 **개발 환경**이라고 해요.

인공지능 기술은 대부분 복잡한 수학 계산과 **알고리즘**(문제를 푸는 순서와 방법)을 바탕으로 움직여요. 처음부터 직접 만들려면 높은 수준의 프로그래밍 지식과 수학 실력이 필요하지만, 이미 만들어 둔 도구를 쓰면 비교적 쉽게 만들 수 있어요. 대표적인 도구가 토니(Thonny)라는 통합 개발 환경과 OpenCV, MediaPipe 같은 인공지능 :용어[라이브러리]예요.

:용어[통합 개발 환경](IDE, Integrated Development Environment)은 코드를 쓰고, 실행하고, 오류를 고치고, 결과를 내보내는 일처럼 소프트웨어를 만드는 데 필요한 기능을 한 화면에 모아 둔 개발 도구예요.

토니는 파이썬을 처음 배우는 사람이 쉽게 쓰도록 만든 통합 개발 환경이라, 복잡한 설정 없이 바로 코딩을 시작할 수 있어요. 오류를 찾아 고치는 **디버깅**(debugging) 기능도 있어요. 프로그램의 오류를 벌레(bug)라고 부르는 데서 나온 말이에요.

| 토니의 기능 | 좋은 점 |
| --- | --- |
| 코드를 한 줄씩 실행하기 | 프로그램이 어떤 차례로 도는지 눈으로 따라갈 수 있어요. |
| 변수 값 보기 | 변수 값이 어떻게 바뀌는지 볼 수 있어 작동 원리를 이해하기 좋아요. |
| 디버깅 | 오류가 났을 때 원인을 찾아 고치도록 도와줘요. |
| 패키지 관리자 | 명령어를 입력하지 않고도 OpenCV, MediaPipe 같은 라이브러리를 설치해요. |
| :용어[마이크로파이썬] 지원 | :용어[ESP32] 같은 :용어[마이크로컨트롤러]와 이어 하드웨어 프로젝트로 넓힐 수 있어요. |

:::참고[토니는 누가 만들었을까?]
토니(Thonny)는 2015년 에스토니아 타르투 대학교의 연구원 아이바르 안나마아가 만든 파이썬 통합 개발 환경이에요.

### 인공지능 라이브러리: OpenCV와 MediaPipe

인공지능 라이브러리는 인공지능 기능을 쉽게 만들 수 있도록 여러 가지 기능과 도구를 미리 만들어 둔 코드의 묶음이에요. 라이브러리를 쓰면 복잡한 알고리즘이나 처리 과정을 직접 만들지 않고도 이미지 인식, 음성 처리, 자연어 처리(사람이 쓰는 말을 컴퓨터가 다루는 기술) 같은 기능을 비교적 간단한 코드로 만들 수 있어요. 레고 부품으로 집을 짓듯, 잘 만들어 둔 부품을 가져다 조립하는 거예요.

대표적인 인공지능 라이브러리는 OpenCV와 MediaPipe예요. OpenCV는 영상 처리를 잘하도록 만든 **오픈 소스**(누구나 코드를 보고 고쳐 쓸 수 있게 공개한 소프트웨어) 라이브러리예요. 영상 필터, 얼굴 인식, 물체 추적 같은 기능이 있고, 특히 :용어[픽셀] 단위로 이미지를 분석하거나 특정 색이나 모양을 기준으로 영상을 처리할 때 쓸모가 있어요.

MediaPipe는 구글이 만든 라이브러리로, 손가락 관절, 얼굴 윤곽, 자세 인식 같은 고급 인공지능 기능을 줘요. 웹캠 영상에서 실시간으로 사람의 손이나 얼굴 위치를 찾고, 그것으로 여러 가지 상호작용 기능을 만들 수 있어요. 두 라이브러리는 쓰는 법이 간단하고 참고 자료가 많아서 프로그래밍을 처음 배우는 사람도 어렵지 않게 쓸 수 있어요.

| 구분 | OpenCV | MediaPipe |
| --- | --- | --- |
| 쓰는 목적 | 사진이나 영상에서 특정 대상을 알아보고 따라가거나, 원하는 영역을 찾아내요. | 사람의 손, 얼굴, 자세 같은 움직임을 실시간으로 알아봐요. |
| 좋은 점 | 여러 가지 영상 처리 기능을 직접 조절하며 배울 수 있어요. | 복잡한 설정 없이도 고급 인공지능 기능을 쉽게 만들 수 있어요. |
| 배움의 효과 | 영상 처리 원리나 알고리즘을 깊이 있게 이해할 수 있어요. | 실제 응용 예가 많아 실생활과 이어 배우기 쉬워요. |
| 쓰이는 곳 | 이미지 보정, 물체 추적, 로봇 비전(로봇이 카메라로 사물의 위치와 모양을 알아보는 기술) | 증강 현실과 가상 현실(AR, VR), 피트니스 앱, 제스처(몸짓) 인식 앱 |

손 인식 프로그램에서는 두 라이브러리가 일을 나눠 맡아요.

### 카메라 프로그램의 기본 구조

아래 그림은 OpenCV로 웹캠 영상을 실시간으로 화면에 보여 주는 프로그램의 기본 구조예요(교과서 023쪽 코드). 얼굴 인식이나 제스처 인식 같은 인공지능 기능도 이 구조에 코드를 더해 만들 수 있어요.

<figure>
<img src="/images/lessons/1-1-3/program-structure.svg" alt="카메라 프로그램을 위에서 아래로 일곱 칸으로 나눈 그림: 1 라이브러리 불러오기(import cv2), 2 상수와 설정(창 이름), 3 초기화(웹캠 연결), 4 함수 정의(show_frame), 5 외부 연동(선택, 점선 칸), 6 메인 실행(while True로 읽기, 보여 주기, q 키 확인을 되풀이하는 파란 칸), 7 종료 처리(cap.release)" width="640" height="432">
<figcaption>일곱 영역이 위에서 아래로 차례대로 놓여요. 파란 ⑥ 메인 실행 영역만 프레임마다 되풀이돼요. 점선 ⑤는 나중에 쓰려고 비워 둔 자리예요. 사이트가 직접 그린 그림이에요.</figcaption>
</figure>

| 영역 | 줄 | 하는 일 |
| --- | --- | --- |
| ① 라이브러리 불러오기 | 1~2행 | 영상 처리에 쓸 OpenCV(`cv2`)를 불러와요. |
| ② 상수와 설정 | 4~5행 | 프로그램 내내 쓸 값(창 이름)을 정해 둬요. |
| ③ 초기화 | 7~8행 | 프로그램을 시작할 때 한 번, 기본 웹캠(장치 번호 0)과 연결해요. |
| ④ 함수 정의 | 10~12행 | 프레임(사진 한 장)을 창에 보여 주는 함수를 만들어 둬요. |
| ⑤ 외부 연동 설정(선택) | 14~16행 | 나중에 네트워크나 다른 기기와 이어 쓸 자리를 비워 둬요. |
| ⑥ 메인 실행 | 18~27행 | 프레임 읽기 → 창에 보여 주기 → q 키 확인을 되풀이해요. |
| ⑦ 종료 처리 | 29~31행 | 웹캠 연결을 끊고 창을 모두 닫아요. |

**상수**는 프로그램이 도는 동안 바꾸지 않는 값이에요. 파이썬에서는 `WINDOW_NAME`처럼 이름을 대문자로 적어 상수라는 것을 알려요. **함수**는 이름을 붙여 둔 코드 묶음이라, 만들어 두기만 하면 실행되지 않고 이름을 불러야 실행돼요. 영역을 나눠 두면 코드가 길어져도 어디를 고칠지 찾기 쉬워요. 1-1-2의 손 인식 코드도 불러오기 → 초기화 → 반복 → 종료 차례로 되어 있어요.

### 코드 읽기

줄 번호는 실습실에 보이는 코드 파일 기준이에요. 교과서 023쪽 코드보다 빈 줄이 두 개 더 있어서, 23행부터는 교과서 번호보다 1~2씩 커요.

- 1~2행: 영상 처리 라이브러리 OpenCV(`cv2`)를 불러와요.
- 5행: 창 이름 `'Camera View'`를 상수 `WINDOW_NAME`에 넣어요.
- 8행: 기본 웹캠(장치 번호 0)과 연결해 `cap`에 담아요.
- 11~12행: `show_frame` 함수를 만들어요. 받은 프레임을 `WINDOW_NAME` 창에 보여 줘요.
- 15~16행: `setup_external_services` 함수를 만들어요. `pass`는 "아무것도 하지 않음"이라는 뜻이라 지금은 빈자리예요.
- 19~22행: 계속 되풀이하면서 :용어[프레임]을 읽어요. `ret`에는 읽었는지(True, False)가, `frame`에는 사진 한 장이 들어가요. 읽지 못하면 반복을 끝내요.
- 24행: 읽은 프레임을 `show_frame` 함수로 창에 보여 줘요.
- 26~27행: q 키를 누르면 반복을 끝내요.
- 30~31행: 웹캠을 놓아주고 창을 모두 닫아요.

::예제

### 실행하고 결과 보기

[이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 처음 한 번은 파이썬과 OpenCV를 받느라 조금 걸려요. 브라우저가 카메라 사용을 물으면 "허용"을 눌러요. 카메라가 없거나 허용하지 않으면 실습실이 입력 소스를 샘플 입력(움직이는 도형)으로 바꿔 줘요.

오른쪽 출력 칸에 'Camera View' 창이 생기고 영상이 움직여요. 창 아래에는 창 크기와 1초에 보여 주는 장수(fps)가 나와요. 출력 화면을 누른 뒤 q 키를 누르거나 화면의 [q]를 누르면 실행이 끝나고 "실행이 끝났어요."가 보여요.

:::확인
- 출력 칸에 'Camera View' 창이 생기고 영상(또는 샘플 입력의 도형)이 움직여요.
- q 키나 화면의 [q]를 누르면 "실행이 끝났어요."가 보여요.
- 콘솔에 빨간 오류 글이 없어요.
:::

:::왜그럴까
19행의 `while True:`는 멈추라고 할 때까지 같은 일을 되풀이해요. 한 바퀴마다 20행이 프레임(사진 한 장)을 읽고 24행이 창에 보여 주는데, 1초에도 여러 번 되풀이하니 사진이 움직이는 영상으로 보여요.

26행의 `cv2.waitKey(1)`은 키 입력을 1밀리초(1000분의 1초) 동안 기다려요. 그사이 q 키가 들어오면 27행의 `break`가 반복을 끝내고, 30~31행이 웹캠과 창을 정리해요.
:::

## 바꿔보기

:::바꿔보기
1. 5행의 `'Camera View'`를 `'My Camera'`로 바꿔 실행해 보세요. 출력 창의 이름이 어떻게 바뀌나요? 창을 띄우는 12행은 고치지 않았는데 왜 바뀔까요?
2. 12행을 `cv2.imshow(WINDOW_NAME, cv2.flip(frame, 1))`로 바꿔 보세요. 영상이 어떻게 달라지나요? 1-2-1에서 쓰는 좌우 반전이에요.
3. 16행의 `pass`를 `print("외부 연동 준비 완료")`로 바꿔 실행해 보세요. 콘솔에 글이 나오나요? 그다음 18행 아래에 새 줄을 넣어 `setup_external_services()`라고 적고(들여쓰기 없이) 다시 실행해 보세요.
:::

:::왜그럴까[왜 처음에는 콘솔에 아무것도 나오지 않을까?]
15~16행은 함수를 만들어 두기만 해요. 함수는 이름을 불러야 실행돼요. 교과서 코드는 나중에 네트워크나 다른 기기와 이어 쓸 자리를 미리 마련해 둔 것이라, 아직 부르지 않아요.

19행 앞에서 `setup_external_services()`로 이름을 부르면 반복이 시작되기 전에 한 번 실행돼 글이 나와요. 바꿔보기 1도 같은 원리예요. 12행은 창 이름을 `WINDOW_NAME`이라는 이름으로만 쓰기 때문에, 5행 한 곳만 고치면 창 이름이 바뀌어요.
:::

:::오류
새 줄을 넣은 뒤 `IndentationError`가 나면 들여쓰기를 확인해요. 함수 안의 `print(...)`는 네 칸 들여쓰고, 19행 앞에 넣는 `setup_external_services()`는 맨 앞에서 시작해요. 오류 메시지의 뜻은 [오류 사전](/help/errors/#indentation-expected)에서 찾아볼 수 있어요.
:::

## 도전 과제

::::도전[도전 과제 1: 설정 하나로 회색 화면 켜고 끄기]
② 상수와 설정 영역(5행 아래)에 `GRAY = False  # @toggle 회색으로 보기`를 한 줄 더하세요. 그리고 ④ 함수 정의 영역의 `show_frame`이 `GRAY`가 `True`일 때 회색 영상을 보여 주게 고쳐 보세요. 줄 끝의 `# @toggle`은 실습실 조절 패널에 켜기, 끄기 단추를 만들어요. 실행 중에 단추를 눌러 화면이 바뀌는지 확인해요.

:::힌트
`show_frame` 안에서 `cv2.imshow(...)` 줄 위에 두 줄을 넣어요. `if GRAY:`를 적고, 그 아래 줄에 한 번 더 들여써서 `frame = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)`를 적어요. 회색으로 바꾸는 방법은 보충 차시 [V2 색공간과 흑백](/learn/u1/v2/)에 자세히 있어요.
:::

### 자주 막히는 곳

- "토니를 설치해야 하나요?"라고 물어요. 이 사이트는 설치 없이 브라우저에서 실습해요. 컴퓨터에 설치해 보고 싶은 학생은 교사용 자료실의 ["진짜 PC에서 돌리기"](/teacher/real-pc/#1-토니와-파이썬-설치하기) 안내를 따르게 해요.

- 바꿔보기 3에서 새 줄을 넣다가 들여쓰기를 틀려 `IndentationError`가 나요. 함수 안(16행)은 네 칸, 19행 앞의 새 줄은 맨 앞에서 시작한다는 것을 짚어 주세요.
