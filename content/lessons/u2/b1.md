## 학습목표

- 지금 값과 바로 전 값을 견줘 터치 센서가 눌린 순간을 알아채는 방법을 설명할 수 있어요.
- 누를 때마다 내장 LED를 켜고 끄는 코드를 실행하고 조건을 바꿔 결과를 견줄 수 있어요.

## 왜 배울까

전등 스위치처럼 한 번 누르면 켜지고 한 번 더 누르면 꺼지는 장치가 우리 주변에 많아요. 이런 장치는 누르고 있는 동안이 아니라 "누른 순간"을 알아채야 만들 수 있어요. 2-1-2에서 터치 횟수를 셀 때 쓴 방법을 이번에는 LED를 켜고 끄는 데 써 봐요.

## 핵심 개념

### 터치 센서와 내장 LED

이 차시의 터치 센서는 손가락이 닿아 있는 동안 1, 떨어지면 0을 보내는 디지털 :용어[센서]예요. 보드의 17번 :용어[GPIO] 핀에 신호선을 이어 입력으로 읽어요. 출력은 보드에 이미 붙어 있는 내장 LED(2번 핀)를 써서 LED를 따로 잇지 않아도 돼요.

### 바뀌는 순간 알아채기

보드는 0.05초마다 터치 값을 읽어서, 한 번 누르는 동안에도 1을 여러 번 읽어요. 그래서 지금 값(`touch_state`)과 바로 전 값(`prev_touch`)을 함께 봐요. 바로 전에는 0이었는데 지금 1이면 "방금 눌렀다"예요. 누르고 있는 동안에는 두 값이 모두 1이라 다시 참이 되지 않아요.

<figure>
<img src="/images/lessons/2-1-2/touch-edge.svg" alt="0.05초마다 읽은 값을 세 줄로 적은 그림: 지금 값(touch_state)은 0, 0, 1, 1, 1, 1, 0, 0, 0, 1, 1, 0, 0, 0이고 이전 값(prev_touch)은 한 칸씩 늦게 따라온다. 지금 값이 1이고 이전 값이 0인 두 칸에서만 셈(counter)이 1과 2로 늘고, 누르고 있는 동안에는 늘지 않는다" width="640" height="312">
<figcaption>파랗게 강조한 두 칸이 0에서 1로 바뀐 순간이에요. 2-1-2에서는 이 순간마다 셈을 1씩 늘렸고, 이 차시에서는 이 순간마다 LED를 켜고 꺼요. 2-1-2와 같은 그림이에요(사이트가 직접 그린 그림).</figcaption>

## 따라하기

가상 보드의 터치 센서를 눌러 내장 LED를 켜고 꺼 봐요. 실제 보드가 있으면 실습실의 [실제 보드]에서 같은 코드가 돌아요.

### 코드 읽기

코드는 주석의 동그라미 번호로 네 부분으로 나뉘어요.

- ① 핀 정하기: 17번은 터치 센서(입력), 2번은 내장 LED(출력)로 정해요.
- ② 기억할 값: LED가 켜졌는지(`led_on`)와 바로 전에 읽은 터치 값(`prev_touch`)을 둬요.
- ③ 되풀이: 0.05초마다 터치 값을 읽어 `touch_state`에 넣어요.
- ④ 바뀌는 순간: `prev_touch`가 0이고 `touch_state`가 1일 때만 `led_on`을 뒤집고 LED를 켜거나 꺼요. 되풀이 끝에서 지금 값을 `prev_touch`에 기억해요.

::예제

### 실행하고 결과 보기

[이 자리에서 실습실 열기]를 누르고 [실행]을 눌러요. 보드 아래 터치 센서를 마우스나 손가락으로 한 번 눌렀다 떼요. 키보드로는 Tab으로 터치 센서에 간 뒤 Space를 눌렀다 떼요. 두 번 누르면 콘솔에 이렇게 나와요.

```text
터치 센서를 한 번씩 눌렀다 떼 보세요.
눌렀어요 → LED 켜짐
눌렀어요 → LED 꺼짐
```

:::확인
- 한 번 누를 때마다 보드 그림의 내장 LED가 켜지거나 꺼져요.
- 누르고 있는 동안에는 LED가 더 바뀌지 않아요.
- 다 봤으면 [정지]를 눌러요.
:::

:::왜그럴까
누르고 있는 동안 `touch_state`는 계속 1이에요. 하지만 `prev_touch`가 0이고 `touch_state`가 1인 때는 누르기 시작한 한 번뿐이에요. 그래서 한 번 누르면 LED도 한 번만 바뀌어요.
:::

## 바꿔보기

:::바꿔보기
1. 조건을 `if touch_state == 1:`로 바꿔 보세요. 터치 센서를 누르고 있는 동안 LED가 어떻게 되나요?
2. 조건을 `if prev_touch == 1 and touch_state == 0:`으로 바꿔 보세요. LED가 누를 때 바뀌나요, 뗄 때 바뀌나요?
3. ②에 `count = 0`을 더하고 누를 때마다 `count = count + 1`로 늘려 `print(count, "번째 눌렀어요")`로 찍어 보세요.
:::

:::왜그럴까[왜 누르고 있으면 LED가 깜빡일까?]
조건이 `touch_state == 1`뿐이면 누르고 있는 동안 되풀이할 때마다(0.05초마다) 조건이 참이 돼요. 그래서 LED가 켜졌다 꺼졌다를 계속 되풀이해요. 한 번 누름을 한 번으로 치려면 바로 전 값을 함께 봐야 해요.
:::

:::오류
`NameError: name 'count' is not defined`가 나면 `count = 0`을 `while True:` 앞(②)에 적었는지 확인해요. 오류 메시지의 뜻은 [오류 사전](/help/errors/)에서 찾아볼 수 있어요.
:::

:::

1. 도입(3분): 전등 스위치처럼 "한 번 누르면 켜짐, 또 누르면 꺼짐"인 장치를 떠올려요.

### 평가 포인트

- 지금 값과 바로 전 값을 함께 보는 까닭을 "누르고 있는 동안에는 다시 참이 되지 않게"로 설명하는지 봐요.
- 바꿔보기 1과 2의 결과(누르고 있으면 깜빡임, 뗄 때 바뀜)를 실행하기 전에 예상해 말하는지 봐요.

### 자주 막히는 곳

- `prev_touch = touch_state`를 if 안에 넣으면 처음 한 번만 LED가 바뀌고 그 뒤로는 바뀌지 않아요. `prev_touch`가 1에서 다시 0으로 돌아오지 못하기 때문이에요. 되풀이마다 if 밖에서 기억하게 짚어 주세요.
- 기계식 버튼으로 바꾸면 누르는 순간 접점이 짧게 떨려 한 번에 두 번 바뀌는 일이 생길 수 있어요(디바운싱이 필요한 까닭). 그때는 LED를 바꾼 뒤 잠깐 더 기다리게 해요.
