II단원 피지컬 컴퓨팅에서 배운 내용을 교과서 180\~181쪽 문제로 점검해요. 1\~6번은 보기를 고르고 [답 확인하기]를 누르면 바로 풀이가 나와요. 7\~13번은 먼저 스스로 답을 적어 본 뒤 [정답과 풀이 보기]를 열어요. 문항 번호는 교과서와 같아요.

## 한눈에 보기

문제를 풀기 전에 II단원에서 다룬 출력 장치와 제어 방법을 한 번에 정리해 봐요. 괄호 안은 그 장치를 배운 차시예요.

- **LED, 레이저**(2-1-1, 2-1-4): 핀을 켜고 꺼요(1, 0). 예: `led.on()`, `laser.value(1)`
- **LCD, OLED**(2-1-2, 2-1-3): I2C의 두 선(SDA, SCL)으로 잇고, 라이브러리로 글자와 그림을 보내요. 예: `lcd.putstr('Hello LCD!')`, `oled.show()`
- **RGB LED 밝기**(2-1-4): PWM의 duty(0\~1023)로 색마다 밝기를 정해요. 예: `r.duty(512)`
- **네오픽셀**(2-1-5): 데이터 선 하나로 LED마다 색을 정해 한꺼번에 보내요. 예: `np.write()`
- **버저**(2-2-1): PWM 주파수가 음 높이를 정해요. 예: `buzzer.freq(262)`
- **MP3 플레이어**(2-2-2): UART로 8바이트 명령을 보내요. 예: `uart.write(…)`
- **팬 모터**(2-2-3): INA, INB로 방향을, PWM으로 속도를 정해요. 예: `fan.rotate('cw', 70)`
- **서보모터**(2-2-4): PWM 펄스 폭이 팔의 각도를 정해요. 예: `servo_1.rotate(90)`

장치마다 제어 방법은 달라도, 입력(센서) → 처리(ESP32) → 출력(이 장치들)의 흐름은 모두 같아요.

### 7번(단답형)

OLED 디스플레이를 I2C 방식으로 제어할 때 필요한 두 개의 핀 이름을 써 보세요.

:::정답
**SDA, SCL**이에요. SDA는 데이터를 싣는 선(ESP32의 21번 핀), SCL은 주고받는 박자를 맞추는 선(22번 핀)이에요. 여기에 전원 VCC와 GND를 더해 네 핀으로 이어요. 다시 보기: [2-1-3 OLED 제어하기](/learn/u2/2-1-3/)
:::

### 8번

서보모터가 다른 모터와 구별되는 가장 큰 특징은 무엇일까요?

①&nbsp;속도가 빨라요. ②&nbsp;진동을 만들어 내요. ③&nbsp;오래 써도 잘 닳지 않아요. ④&nbsp;늘 360°로 이어서 돌아요. ⑤&nbsp;회전 각도를 정밀하게 제어할 수 있어요.

:::정답
**⑤ 회전 각도를 정밀하게 제어할 수 있어요.** 서보모터는 PWM 펄스 폭으로 목표 각도를 받고, 안의 위치 센서와 제어 회로가 팔의 지금 각도를 재서 목표 각도에서 멈춰요. 팬 모터처럼 계속 도는 것이 아니라 0°\~180° 사이의 정한 각도로 움직여요. 다시 보기: [2-2-4 서보모터 활용하기](/learn/u2/2-2-4/)
:::

### 9번

ESP32에서 팬 모터의 속도를 제어하려고 가장 많이 쓰는 방식은 무엇일까요?

①&nbsp;ADC ②&nbsp;I2C ③&nbsp;PWM ④&nbsp;SPI ⑤&nbsp;UART

:::정답
**③ PWM**이에요. 신호를 아주 빠르게 켰다 껐다 하면서 켜진 시간의 비율(duty)을 바꾸면, 모터가 받는 힘이 달라져 팬의 속도가 바뀌어요. 교과서 라이브러리의 `fan.rotate('cw', 70)`은 speed 70을 duty 716으로 바꿔 보내요. 다시 보기: [2-2-3 팬 모터 활용하기](/learn/u2/2-2-3/)
:::

### 10번(단답형)

네오픽셀을 제어할 때, LED의 색 값을 나타내는 세 가지 기본 색 채널을 써 보세요.

:::정답
정답은 **빨강(R), 초록(G), 파랑(B)** 세 가지예요. `np[0] = (255, 0, 0)`처럼 세 색의 밝기를 0\~255의 숫자로 적어요. 세 값의 비율로 색이, 크기로 밝기가 정해져요. 다시 보기: [2-1-5 네오픽셀 제어하기](/learn/u2/2-1-5/)
:::

### 11번(서술형)

팬 모터를 PWM으로 제어하면 어떤 장점이 있는지 써 보세요.

:::정답
예시 답안: 핀을 켜고 끄기만 하면 팬은 가장 빠르게 돌거나 멈추는 두 가지뿐이에요. PWM으로 켜진 시간의 비율(duty)을 바꾸면 모터가 받는 힘을 조절해 팬의 속도를 약풍, 중풍, 강풍처럼 여러 단계로 바꿀 수 있어요. 그래서 필요한 만큼만 빠르게 돌려 전기를 아끼고 소음도 줄일 수 있어요. 스마트 가전이 센서값에 따라 팬 속도를 스스로 바꾸는 것도 이 방법이에요.
:::

## 프로그래밍으로 점검

### 12번

다음 코드는 ESP32에서 네오픽셀 LED 8개를 빨강, 초록, 파랑 차례로 되풀이해 켜는 프로그램이에요. 빈칸 ①\~③에 들어갈 알맞은 코드를 써 보세요.

```python
import machine, neopixel, time
np = neopixel.NeoPixel(machine.Pin(5), ___①___)
colors = [(255, 0, 0), (0, 255, 0), (0, 0, 255)]
while True:
    for i in range(np.n):
        color = colors[i % ___②___]
        np[i] = color
    np.___③___()
    time.sleep(0.5)
```

:::정답
① `8` ② `3`(또는 `len(colors)`) ③ `write`

① 이은 LED가 8개라 `NeoPixel(machine.Pin(5), 8)`로 만들어요. `np.n`에는 이 LED 개수(8)가 들어 있어요. ② `i`를 3으로 나눈 나머지는 0, 1, 2, 0, 1, 2 …로 되풀이되니 `colors`의 빨강, 초록, 파랑이 차례로 골라져요. ③ `np[i] = color`는 보드 안의 색 목록에 적기만 하므로, `np.write()`를 불러야 링의 불빛이 바뀌어요.
:::

:::참고[직접 돌려 확인하기]
빈칸을 채운 코드 맨 위에 `# @part neopixel 5`를 한 줄 더해 [ESP32 실습실](/labs/esp32/)의 편집칸에 붙여 넣고 [실행]하면, 가상 네오픽셀 링의 0\~7번 LED가 빨강, 초록, 파랑 차례로 켜져요. 5번 핀은 보드가 켜질 때 쓰는 스트래핑 핀이라 가상 보드가 "주의"를 보여 주지만 실행에는 문제없어요.
:::

### 13번

다음은 ESP32에서 버저로 도, 레, 미를 차례로 0.5초씩 연주하는 코드예요. 빈칸 ①, ②에 들어갈 알맞은 코드를 써 보세요.

```python
from machine import Pin, PWM
import time
buzzer = PWM(Pin(15))
notes = [262, 294, 330]
for n in notes:
    buzzer.freq(___①___)
    buzzer.duty(512)
    time.sleep(0.5)
    buzzer.___②___(0)
    time.sleep(0.1)
```

:::정답
① `n` ② `duty`

① `for n in notes:`가 262, 294, 330을 차례로 `n`에 담으니, `buzzer.freq(n)`으로 그 주파수를 정해 도, 레, 미 소리를 내요. ② `buzzer.duty(0)`은 켜진 시간을 0으로 만들어 소리를 꺼요. 그래서 음마다 0.1초씩 끊겨 들려요. 2-2-1 예제 2를 연 [ESP32 실습실](/labs/esp32/?example=esp32/u2/2-2-1-buzzer-scale.py) 편집칸에 붙여 넣으면 가상 버저로 직접 들어 볼 수 있어요.
:::

| 11 | 속도를 여러 단계로 조절(전기 절약, 소음 감소) | 2-2-3 |
| 12 | ① 8 ② 3(또는 len(colors)) ③ write | 2-1-5 |
| 13 | ① n ② duty | 2-2-1 |

### 채점할 때 볼 곳(사이트 제안)

- 7번: 두 핀의 이름(SDA, SCL)이 모두 맞으면 정답이에요. 핀 번호(21번, 22번)까지 쓰면 더 좋아요.
- 10번: 세 색을 모두 쓰면 정답이에요. R, G, B처럼 영어 첫 글자만 써도 돼요.
- 11번(서술형): ① 속도(세기)를 여러 단계로 조절할 수 있다 ② 켜진 시간의 비율(duty)로 모터가 받는 힘을 바꾼다 ③ 전기 절약, 소음 감소, 상황에 맞춘 세기 같은 쓰임, 이 가운데 두 가지 이상이 들어가면 돼요.
- 12번: ②는 `3`과 `len(colors)` 모두 정답으로 봐요. ③은 괄호를 뺀 `write`예요(코드에 `()`가 이미 있어요).
- 12, 13번은 ESP32 실습실에서 직접 돌려 보게 하면, 답을 외우기보다 코드가 어떻게 도는지 설명하게 할 수 있어요.

### 원고에서 바꾼 곳

- 원고에는 II단원 마무리의 정답과 해설이 없어서 사이트가 새로 썼어요(PLAN §2.2). 풀이는 II단원 차시 본문과 실습실에서 실제로 돌려 본 결과를 근거로 했어요.
- 1\~6번은 누르면 바로 채점되는 퀴즈로, 7\~13번은 정답 접기로 만들었어요. 8, 9번은 객관식이지만 교과서 번호를 그대로 두려고 정답 접기에 넣었어요(화면 퀴즈는 번호를 1부터 차례로 매겨요).
- 문제와 보기의 문장 끝을 해요체로 다듬었어요. 뜻은 바꾸지 않았어요.
- 12번 코드의 `neopixel.NeoPixel(machine, Pin(5), …)`과 `range(np, n)`은 조판 오류라 `machine.Pin(5)`, `range(np.n)`으로 바로잡았어요(INVENTORY §10.4). 원고대로면 가상 보드와 실제 보드 모두에서 오류가 나요.
- 13번 코드의 줄 번호가 1\~7 뒤에 4, 5, 6으로 다시 시작하는 것은 조판 오류라 줄 번호 없이 옮겼어요.
- 6번의 "피에조 버저"는 2-2-1 원고가 설명한 버저(전자기장으로 진동판을 떨게 함)와 소리를 만드는 부품이 달라요(피에조는 전압을 걸면 휘는 판을 떨게 함). 두 가지 모두 PWM 주파수만큼 떨려 그 높이의 소리를 내므로 정답은 같아요.
