## 문제로 점검

III단원 "인공지능 피지컬 통신 방법"에서 배운 내용을 점검해요. 1\~7번은 보기를 고르고 [답 확인하기]를 누르면 바로 풀이가 나와요. 8\~13번은 스스로 답을 적은 뒤 [정답과 풀이 보기]를 펼쳐 견줘 봐요. 문항 번호는 교과서(원고 208\~209쪽)와 같아요.

::퀴즈

### 8. 블루투스 통신에서 PC 쪽 파이썬이 쓰는 대표적인 라이브러리는 무엇일까요?

:::정답
**bleak**이에요. 교과서의 컴퓨터 쪽 코드는 `import bluetooth`로 bluetooth.py 파일을 불러 쓰는데, 그 파일이 bleak 라이브러리로 BLE 기기와 통신해요(3-1-3). 이 사이트는 설치 없이 브라우저에서 돌리려고, 같은 이름의 흉내 모듈이 가상 보드나 브라우저의 블루투스 연결로 보내요. 시리얼 통신은 bleak이 아니라 pyserial(`import serial`)을 써요(3-1-2).
:::

### 9. (서술형) ESP32에서 boot.py 파일의 역할을 설명해 보세요.

:::정답
예시 답안: boot.py는 보드에 전원이 들어오거나 리셋될 때 가장 먼저 저절로 실행되는 파일이에요. 통신을 받는 코드를 boot.py에 저장해 두면, 컴퓨터에서 따로 실행하지 않아도 보드가 켜지자마자 글자를 받을 준비를 해요.

채점 도움말: "전원을 켜거나 리셋할 때"와 "저절로(가장 먼저) 실행된다"가 들어가면 돼요. 이 사이트의 [보드에 저장]은 같은 일을 main.py로 해요. main.py도 전원을 켜면 boot.py 다음에 저절로 실행돼요(3-1-2).
:::

### 10. (서술형) UART 통신에서 COM 포트 번호를 확인하는 까닭은 무엇일까요?

:::정답
예시 답안: 컴퓨터에 꽂힌 USB 장치마다 COM 포트 번호가 붙고, 그 번호는 컴퓨터와 꽂은 자리에 따라 달라요. 코드의 `serial.Serial('COM10', 115200)`에 USB-UART 변환기가 연결된 번호를 정확히 적어야 그 장치와 통신할 수 있어요.

채점 도움말: "통신할 장치(변환기)를 찾아 연결하려고"와 "컴퓨터마다 번호가 달라서"가 들어가면 돼요. 보드에 코드를 넣는 포트와 변환기 포트는 번호가 서로 달라요. 이 사이트는 포트 번호를 적는 대신, 연결할 때 뜨는 선택 창에서 장치를 골라요.
:::

## 프로그래밍으로 점검

### 11. 시리얼 통신으로 글자를 보내는 코드의 빈칸 채우기

컴퓨터(Local Python)에서 시리얼 통신으로 글자를 보내는 코드예요. 빈칸 ①, ②를 채워 보세요.

```python
import serial
ser = serial.Serial('COM3', 115200, timeout=0.1)

msg = input('입력 (a/b): ')
ser.①((msg + '\n').②('utf-8'))
```

:::정답
① `write` ② `encode`

`encode('utf-8')`로 글자를 바이트로 바꾸고, `write()`로 시리얼 포트에 보내요. 끝에 `'\n'`을 붙여서 받는 쪽이 한 줄씩 끊어 읽을 수 있어요. 완성한 줄은 `ser.write((msg + '\n').encode('utf-8'))`예요.
:::

### 12. 받은 데이터를 처리한 결과 쓰기

다음 데이터가 ESP32에 도착했어요. 이 프로그램이 출력하는 결과를 써 보세요.

```python
data = '120, 250\n'
values = data.strip().split(',')
x = int(values[0])
y = int(values[1])
print(x, y)
```

:::정답
`120 250`

`strip()`이 끝의 줄바꿈을 떼고, `split(',')`가 `['120', ' 250']`으로 나눠요. `int()`는 앞뒤 빈칸을 무시하므로 `' 250'`도 정수 250이 돼요. `print(x, y)`는 두 값을 빈칸 하나로 띄어 찍어요.
:::

### 13. 좌표로 LED를 켜는 조건문 빈칸 채우기

블루투스로 보낸 글자 `'80,200\n'`을 받아 좌표를 꺼내는 프로그램이에요. x가 100보다 작을 때 LED를 켜도록 빈칸을 채워 보세요.

```python
data = '80, 200\n'
values = data.strip().split(',')
x = int(values[0])
y = int(values[1])

if ________:
    print('LED ON')
```

:::정답
`x < 100`

x는 80이라 조건이 참이 되어 `LED ON`이 찍혀요. 3-1-3 보드 코드의 `if finger_x < 100:`과 같은 모양이에요. 문제 글의 `'80,200\n'`과 코드의 `'80, 200\n'`은 쉼표 뒤 빈칸만 달라요. 12번에서 본 것처럼 `int()`가 빈칸을 무시해서 결과는 같아요.
:::

:::참고[직접 돌려 확인하기]
12번과 13번 코드는 보드 없이도 돌아요. [영상처리 실습실](/labs/vision/)의 편집칸에 붙여 넣고 [실행]하면 결과를 바로 볼 수 있어요(13번은 빈칸을 채운 뒤에 실행해요).
:::

### 평가에 쓸 때

- 1\~7번은 화면에서 바로 채점되고 풀이가 보이므로 형성 평가나 복습에 알맞아요. 교과서 번호와 같아서 종이 교과서와 함께 써도 돼요.
- 보기 차례를 원고 그대로 두어서 4\~7번의 정답이 모두 ⑤예요. 종이로 따로 낼 때는 보기 차례를 섞어 내면 답 자리로 짐작하는 일을 막을 수 있어요.
- 8\~10번은 짧은 답과 서술형이에요. 예시 답안과 채점 도움말은 사이트가 새로 쓴 것이에요.
- 11\~13번은 영상처리 실습실에서 직접 돌려 확인하게 하면, 답을 외우기보다 코드가 어떻게 도는지 설명하게 할 수 있어요.

### 원고에서 바꾼 곳

- 원고에는 III단원 마무리의 정답과 해설이 없어서 사이트가 새로 썼어요. 1\~7번 보기 문장은 사이트의 다른 쪽처럼 해요체("\~해요")로 옮겼어요(뜻은 같아요).
- 2번: 원고 보기 ① "저장 방식이 다르다"도 맞는 답으로 읽혀서(교사용 자료실 원고 정정 목록), ①을 "화면에 보이는 모양이 다르다"로 바꾸고 ④ "아스키코드 값이 서로 다르다"를 "컴퓨터 안에 저장되는 값(바이트)이 서로 다르다"로 풀어 썼어요. 숫자 1은 아스키코드가 아니라 값 1 그대로 저장되기 때문이에요.
- 3번 ④ "UART0은 Thonny와 연결되어 있다"는 "컴퓨터(Thonny)와 코드를 주고받는 데 이미 쓰이고 있다"로 풀어 썼어요.
- 12번 코드 5번 줄 `print(x, y)` 앞의 들여쓰기는 그대로 치면 IndentationError가 나서 뺐어요.
- 1\~7번은 누르면 바로 채점되는 퀴즈로, 8\~13번은 정답 접기로 만들었어요.
:::
