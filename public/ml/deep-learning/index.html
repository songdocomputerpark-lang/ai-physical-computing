01

딥러닝은 어디쯤?

뉴스에서 인공지능, 기계학습, 딥러닝이라는 말을 모두 들어 봤을 거예요. 셋은 서로 포함하는 관계예요.

규칙을 짜는 프로그램 vs 데이터로 배우는 프로그램

사진 속에서 고양이를 찾는 프로그램을 만든다고 해 봐요.

규칙을 짜는 프로그램

사람이 규칙을 하나하나 적어요. “귀가 뾰족하면 고양이, 수염이 있으면 고양이…”

사진→사람이 쓴 규칙→고양이? 아니야

규칙 때문에 털 색이 다른 고양이나 옆모습에서 쉽게 틀려요.

데이터로 배우는 프로그램

정답이 붙은 사진을 많이 보여 줘요. 프로그램이 스스로 규칙(숫자)을 찾아요.

사진 + 정답→배우기→규칙(숫자들)

사진이 늘수록 규칙이 다듬어져요.

이 쪽에서는 정답이 있는 데이터로 배우는 지도 학습을 다뤄요. K-평균은 정답 없이 무리를 찾는 비지도 학습이었어요. 딥러닝에도 정답 없이 배우는 방법이 있어요.

02

인공 뉴런 하나

신경망의 가장 작은 부품은 인공 뉴런이에요. 하는 일은 단순해요. 숫자를 받아서, 중요도를 곱하고, 모두 더한 뒤, 출력 숫자 하나를 내보내요.

예: 운동장에서 축구를 할까?

  • x1 = 날씨가 맑으면 1, 아니면 0
  • x2 = 남은 숙제가 있으면 1, 없으면 0
  • 가중치 w1 = 3(맑으면 찬성), w2 = −2(숙제는 반대), 편향 b = −1
  • 활성화 함수는 계단 함수예요. 합이 0보다 크면 1(한다), 아니면 0(안 한다).

활성화 함수는 왜 필요할까요?

계단 함수는 이해하기 쉬워요. 하지만 0과 1 사이를 갑자기 뛰어요. 그러면 숫자를 조금 고쳤을 때 결과가 얼마나 나아졌는지 알기 어려워요. 그래서 실제로는 부드럽게 변하는 함수를 써요.

시그모이드는 σ(z) = 1 ÷ (1 + e−z)예요. 아주 작은 수는 0에 가깝게, 아주 큰 수는 1에 가깝게 눌러 줘요. 그래서 “1일 확률”처럼 읽을 수 있어요.

가중치는 입력의 중요도(그리고 찬성·반대)예요. 편향은 입력과 상관없이 가진 기본 성향이에요.

그러니까 “배운다” = 이 숫자들(가중치와 편향)을 고치는 것이에요.

03

실습 1 · 내 손으로 선 긋기

뉴런 하나가 점 (x, y)를 보고 “1일 확률” p를 내놓아요.

p = σ( w1·x + w2·y + b )

p가 0.5인 곳이 파랑과 주황이 갈리는 경계선이에요. 슬라이더로 w1, w2, b를 돌려서 모든 점을 맞혀 보세요.

1969년에 뉴런 하나(퍼셉트론)의 이런 한계가 널리 알려졌어요. 그 영향 등으로 신경망 연구가 한동안 주춤했다고 해요.

04

학습 · 오차를 줄이는 방향으로 조금씩

슬라이더를 손으로 돌리는 대신, 컴퓨터가 스스로 돌리게 할 수는 없을까요? 방법이 있어요. 안개 낀 산을 떠올려 봐요.

안개 때문에 앞이 안 보여요. 그래도 발밑의 기울기는 느낄 수 있어요. 내리막 쪽으로 한 걸음씩 가면 결국 골짜기 바닥에 닿아요.

이것이 경사 하강법이에요. 한 걸음의 크기가 학습률(η, “에타”)이에요. 산의 높이가 오차이고, 골짜기 바닥이 오차가 가장 작은 곳이에요.

숫자 하나로 해 보기

오차가 L(w) = (w − 3)² + 1이라고 해 봐요. 바닥은 w = 3일 때 L = 1이에요. 기울기(미분)는 L′(w) = 2(w − 3)이에요. 규칙은 이거예요.

w ← w − η · L′(w)

w = −2에서 출발해요. 학습률 η를 골라 [한 걸음]을 눌러 보세요. 학습률을 바꾸면 처음으로 돌아가요.

학습률 η
걸음 수0
w−2.000
오차 L(w)26.000
기울기 L′(w)−10.000

  • η = 0.5: 한 걸음에 바닥(w = 3)으로 가요. 새 w = w − 0.5·2(w − 3) = 3이거든요.
  • η = 0.9: 바닥을 지나쳐서 양쪽을 오가요. 그래도 오가는 폭이 줄어서 결국 모여요.
  • η = 1.05: 오갈 때마다 폭이 커져요. 바닥에서 점점 멀어져요(발산).
  • η가 작을 때(0.05): 방향은 맞지만 아주 느려요.

한 걸음을 손으로 계산해 보기

뉴런 하나, 입력 x = 2, 정답 1, 처음 w = 0.5, b = 0, η = 0.5예요. 교차 엔트로피 오차를 쓰면 w의 기울기는 (p − 정답) × x예요.

σ(z) = 1 ÷ (1 + e−z)

  1. z = w·x = 0.5 × 2 = 1
  2. p = σ(1) = 0.731 (정답 1에 아직 못 미쳐요)
  3. 기울기 = (0.731 − 1) × 2 = −0.538
  4. 새 w = 0.5 − 0.5 × (−0.538) = 0.769
  5. 새 p = σ(0.769 × 2) = σ(1.538) = 0.823 (정답에 가까워졌어요)

p가 1에 가까워질수록 기울기가 작아져서, 걸음도 점점 짧아져요.

3절의 놀이터에서 같은 방법을 써요. 전체 점의 오차를 계산해서 w1, w2, b를 한 걸음씩 고쳐요. 기울기는 점마다 구한 값의 평균이에요.

05

층을 쌓으면 · 신경망 놀이터

뉴런 하나로는 직선밖에 못 그려요. 그래서 뉴런을 여러 개, 여러 층으로 이어 붙여요.

  • 입력층: 데이터가 들어오는 곳이에요. 여기서는 x, y 두 개예요.
  • 은닉층: 입력과 출력 사이의 층이에요. 뉴런들이 숨어서 중간 계산을 해요.
  • 출력층: 마지막 답이에요. 여기서는 “1일 확률” 하나예요.

은닉층이 여러 개인 신경망을 깊은 신경망이라고 해요. 그래서 이름이 딥러닝이에요.

층 사이에 활성화 함수가 없으면, 층을 아무리 쌓아도 결국 직선 하나로 나누는 것과 같아져요. 곡선을 만드는 힘은 활성화 함수에서 나와요.

연결선: 파랑 = 양수 가중치, 주황 = 음수 가중치, 굵을수록 절댓값이 커요. 타일은 그 뉴런이 평면 위에서 어떤 값을 내는지 보여 줘요(어두울수록 값이 커요).

안내 과제

과제 2: 같은 데이터에서 은닉층 1개, 뉴런 4개로 학습해 보세요. 정확도가 크게 올라요.

과제 3: [과제 3]을 누르면 노이즈 0.30, 은닉층 8·8, 학습률 0.3으로 맞춰져요. 학습을 1,000에포크 넘게 돌리며 두 정확도를 견줘 보세요. 학습 정확도는 90%를 넘는데 시험 정확도는 70% 안팎에 머물러요. 학습 데이터의 우연한 흔들림까지 외운 것이 과대적합이에요. 점이 달라지면 숫자는 조금씩 달라져요.

위의 [과제 1~3] 버튼을 누르면 설정이 한 번에 바뀌어요.

06

역전파 · 오차를 거꾸로 나눠 주기

층이 많으면 가중치도 많아요. 놀이터의 신경망도 수십 개예요. 가중치마다 “오차를 줄이려면 어느 쪽으로 고쳐야 하지?”를 어떻게 알까요? 그 답이 역전파예요.

  1. 앞으로 계산(순전파): 입력을 넣고 층마다 계산해서 예측을 얻어요.
  2. 오차: 예측과 정답이 얼마나 다른지 재요.
  3. 뒤로 전달(역전파): 출력의 오차를 거꾸로 나눠 줘요. “이 가중치가 오차에 얼마나 책임이 있나?”, 곧 가중치마다의 기울기를 구해요. 수학의 미분의 연쇄 법칙(겹쳐진 함수의 미분은 구간마다의 기울기를 곱한다)을 써요.
  4. 경사 하강법으로 고치기: 구한 기울기의 반대쪽으로 가중치를 조금씩 고쳐요.

비유를 하나 들어 볼게요. 릴레이 경주에서 기록이 나쁘게 나왔어요. 마지막 주자부터 거꾸로 “각자 기록에 얼마나 영향을 줬지?” 하고 따져 보는 거예요. 영향이 큰 사람이 더 많이 고쳐요.

다만 비유일 뿐이에요. 실제로는 사람 탓을 나누는 게 아니라, 기울기 곱셈으로 정확히 계산해요.

8절의 파이썬 코드에서 “뒤로 계산(역전파)” 부분이 바로 이 단계예요. dz2가 출력의 오차이고, dz1은 그 오차를 은닉층으로 거꾸로 보낸 값이에요.

07

조심할 점과 쓰이는 곳

조심할 점

  • 과대적합: 학습 데이터는 잘 맞히는데 새 데이터(시험)에서 틀려요. 문제집 답만 외운 것과 비슷해요. 해결: 데이터를 더 모으기, 모델을 더 단순하게 하기, 시험 오차가 오르기 시작하면 일찍 멈추기.
  • 데이터와 계산이 많이 필요해요: 큰 모델은 GPU 같은 장치로 오래 계산해야 해요.
  • 데이터 편향: 배운 데이터가 치우쳐 있으면 결과도 치우쳐요.
  • 설명하기 어려워요: 가중치가 수없이 많아서 “왜 이렇게 판단했는지” 말하기 어려워요.

쓰이는 곳

  • 사진 속 물체 찾기: 합성곱 신경망(CNN)을 써요. 이미지 인식 수업에서 만나요.
  • 음성 인식, 번역
  • 챗GPT 같은 대화형 AI도 아주 큰 심층 신경망(트랜스포머)을 바탕으로 해요.

08

파이썬으로 확인하기

A. numpy로 XOR 배우기

5절에서 본 과정을 코드로 옮겼어요. 순전파, 역전파, 경사 하강법이 차례로 나와요. 뉴런 하나로는 못 풀던 XOR을 은닉층 하나로 풀어요.

numpy · XOR
# 신경망으로 XOR 배우기: 입력 2개 → 은닉층 뉴런 4개(tanh) → 출력 1개(시그모이드)
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)  # 입력
y = np.array([[0], [1], [1], [0]], dtype=float)              # 정답(XOR)

# 처음 가중치: 작은 수(늘 같은 결과가 나오게 직접 적었어요)
W1 = np.array([[0.5, -0.6, 0.3, -0.2],
               [-0.4, 0.7, 0.2, 0.6]])
b1 = np.zeros(4)
W2 = np.array([[0.6], [0.5], [-0.4], [0.3]])
b2 = np.zeros(1)
lr = 0.5  # 학습률: 한 걸음의 크기

for epoch in range(1, 2001):
    # 1) 앞으로 계산(순전파)
    h = np.tanh(X @ W1 + b1)              # 은닉층의 출력
    p = 1 / (1 + np.exp(-(h @ W2 + b2)))  # 예측(0~1)
    loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))  # 오차(교차 엔트로피)

    # 2) 뒤로 계산(역전파): 가중치마다 오차를 줄이는 방향 구하기
    dz2 = (p - y) / len(X)
    dW2 = h.T @ dz2
    db2 = dz2.sum(axis=0)
    dz1 = (dz2 @ W2.T) * (1 - h ** 2)     # tanh의 기울기를 곱해요
    dW1 = X.T @ dz1
    db1 = dz1.sum(axis=0)

    # 3) 경사 하강법: 기울기의 반대쪽으로 조금씩 고치기
    W1 -= lr * dW1
    b1 -= lr * db1
    W2 -= lr * dW2
    b2 -= lr * db2

    if epoch % 400 == 0:
        print(f"에포크 {epoch}: 오차 {loss:.4f}")

print("예측:", p.ravel().round(3))
print("정답:", y.ravel())

B. scikit-learn으로 원 데이터 비교 (코랩)

은닉층이 없을 때, 1개일 때, 2개일 때를 비교해요. 학습에 쓰지 않은 시험 데이터로도 점수를 매겨요.

scikit-learn · 원 데이터
from sklearn.datasets import make_circles
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier

# 원 안(1)과 원 밖(0) 점 400개 — 60%로 배우고 40%로 시험
X, y = make_circles(n_samples=400, noise=0.1, factor=0.4, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.4, random_state=0)

for hidden in [(), (8,), (8, 8)]:   # 은닉층 없음 / 1개(뉴런 8) / 2개(뉴런 8, 8)
    model = MLPClassifier(hidden_layer_sizes=hidden, activation="tanh",
                          max_iter=2000, random_state=0)
    model.fit(X_train, y_train)
    print(f"은닉층 {hidden}: 학습 정확도 {model.score(X_train, y_train):.2f}, "
          f"시험 정확도 {model.score(X_test, y_test):.2f}")

코랩에서 케라스로

같은 XOR을 케라스(Keras)로 풀어요. 실행 결과는 적지 않았어요. 대부분 0과 1에 가까워져요. 아니면 한 번 더 실행해 보세요.

keras · XOR
import numpy as np
import keras

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype="float32")
y = np.array([0, 1, 1, 0], dtype="float32")

model = keras.Sequential([
    keras.Input(shape=(2,)),
    keras.layers.Dense(8, activation="tanh"),
    keras.layers.Dense(1, activation="sigmoid"),
])
model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.05),
              loss="binary_crossentropy", metrics=["accuracy"])
model.fit(X, y, epochs=300, verbose=0)
print(model.predict(X, verbose=0).round(3))

정리

  • 딥러닝 ⊂ 기계학습 ⊂ 인공지능이에요.
  • 뉴런 하나는 입력 × 가중치를 더하고 편향을 더해서 활성화 함수에 넣어요. 경계는 늘 직선이에요.
  • 배운다는 건 오차를 줄이는 방향으로 가중치와 편향을 조금씩 고치는 일이에요(경사 하강법). 학습률이 너무 크면 오가거나 발산해요.
  • 은닉층과 활성화 함수를 쌓으면 곡선 경계도 만들 수 있어요.
  • 역전파는 출력의 오차를 거꾸로 나눠 가중치마다 기울기를 구하는 방법이에요.
  • 학습 데이터만 잘 맞히면 안 돼요. 시험 데이터로 확인해야 해요.

정답 없이 비슷한 데이터끼리 묶는 방법이 궁금하다면 K-평균 군집화도 살펴보세요.

선생님용

수업 흐름

  • 1차시(약 25분): 1~4절. 뉴런 계산기 → 선 긋기 → 경사 하강법 미니 체험(학습률 0.5, 0.9, 1.05를 꼭 비교).
  • 2차시(약 25분): 5~9절. 신경망 놀이터 → 역전파 설명 → 코드 확인 → 확인 문제.

탐구 과제

  • 나선 데이터를 풀려면 층과 뉴런을 얼마나 써야 할까요? 활성화 함수를 바꾸면 어떨까요?
  • 학습률 1에서 학습이 불안정해지는 모습을 관찰하고, 4절의 η=1.05와 연결해 설명해 보기.
  • 같은 설정으로 “가중치 새로 시작”을 여러 번 눌러 결과가 얼마나 달라지는지 기록하기.

자주 하는 오해

  • “인공 신경망은 사람 뇌와 똑같이 생각해요.” → 뇌에서 이름과 아이디어를 빌렸을 뿐, 수학적인 계산 구조예요.
  • “오차가 0이면 무조건 좋은 모델이에요.” → 학습 데이터에만 맞은 과대적합일 수 있어요. 시험 데이터를 꼭 봐요.
  • “층이 많을수록 늘 좋아요.” → 데이터가 적으면 과대적합, 학습이 어려워지는 문제도 생겨요.
  • “한 번에 정답을 찾아요.” → 조금씩 여러 번 고치며 가까워지는 과정이에요.
