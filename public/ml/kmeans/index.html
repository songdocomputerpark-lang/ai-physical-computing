01

이런 문제를 풀어요

떡볶이 트럭 3대를 어디에 세울까?

동네에 손님 집이 흩어져 있어요. 각 손님은 가장 가까운 트럭으로 가요. 트럭을 어디에 세워야 손님들이 덜 걸을까요?

용어 네 가지

데이터 점
표 위에 찍은 점 하나. 여기서는 손님 집 하나예요.
무리 (군집, 클러스터)
서로 가까이 모여 있는 점들의 묶음이에요.
중심점
무리에 속한 점들의 평균 위치예요. 트럭을 세울 자리예요.
K
무리의 개수예요. 사람이 미리 정해 줘요. 트럭이 3대면 K=3이에요.

어디에 쓰일까요

  • 고객 나누기 — 비슷하게 사는 손님끼리 묶어서 맞춤 안내를 보내요.
  • 사진 색 줄이기 (색상 양자화) — 사진 속 수많은 색을 K가지 대표 색으로 묶어요.
  • 글 묶기 — 글을 숫자로 바꾼 뒤, 비슷한 글끼리 묶어요.
  • 체육복 치수 정하기 — 키와 몸무게를 점으로 보고 K개의 치수로 묶어요.

정답을 주는 학습, 주지 않는 학습

K-평균은 비지도 학습이에요. 정답표 없이 데이터의 모양만 보고 묶어요. 무리에는 1번, 2번 같은 번호만 붙어요. 그 무리가 무슨 뜻인지는 사람이 살펴보고 해석해요.

이 쪽의 내용은 수업 단원 바로 가기와 이어져요.

02

네 단계로 돌아가요

  1. ① 놓기중심점 K개를 아무 데나 놓아요. 보통은 무작위로 놓아요.
  2. ② 나누기점마다 가장 가까운 중심점의 무리가 돼요.
  3. ③ 옮기기중심점을 그 무리 점들의 평균 위치로 옮겨요.
  4. ④ 되풀이바뀌는 점이 없을 때까지 ②와 ③을 되풀이해요.

평균 위치 구하기

점 (1, 2), (3, 2), (2, 5)의 평균 위치를 구해 봐요. x끼리, y끼리 따로 평균을 내요.

x: (1 + 3 + 2) ÷ 3 = 2    y: (2 + 2 + 5) ÷ 3 = 3  →  (2, 3)

거리 구하기

거리 = √( (x₁ − x₂)² + (y₁ − y₂)² )

예: (1, 1)과 (4, 5) 사이는 √(3² + 4²) = √25 = 5예요.

어느 쪽이 더 가까운지 비교만 할 때는 제곱근을 씌우지 않고 제곱값(d²)끼리 비교해도 결과가 같아요. 계산이 편해요.

SSE: 얼마나 촘촘한지 재는 값

SSE는 “각 점과 자기 중심점 사이 거리의 제곱”을 모두 더한 값이에요. 작을수록 점들이 중심점에 촘촘히 모여 있어요. scikit-learn에서는 inertia_라는 이름으로 알려 줘요.

예: 위의 세 점과 중심점 (2, 3)이면 (1−2)²+(2−3)²=2, (3−2)²+(2−3)²=2, (2−2)²+(5−3)²=4 이므로 SSE = 2+2+4 = 8이에요.

왜 언젠가는 끝이 날까요?

나누기를 하면 SSE는 줄거나 그대로예요. 점마다 더 가까운 중심점을 고르기 때문이에요. 옮기기를 해도 SSE는 줄거나 그대로예요. 평균 위치가 거리 제곱의 합을 가장 작게 만드는 자리이기 때문이에요.

점을 무리로 나누는 방법은 유한한 가지수뿐이에요. 같은 나눔이 두 번 나오면 더 바뀔 게 없어서 멈춰요.

하지만 멈춘 결과가 가장 좋은 답이라는 보장은 없어요. 시작 위치에 따라 다른 곳에서 멈출 수 있어요.

    05

    시작 위치와 K 고르기

    (a) 같은 데이터로 10번 돌려 보기

    중심점을 어디서 시작하느냐에 따라 멈추는 곳이 달라질 수 있어요. 어떤 결과는 지역 최적해예요. 근처에서는 더 나아질 수 없지만, 전체로 보면 더 좋은 답이 따로 있는 상태예요.

    그래서 시작 위치를 바꿔 여러 번 돌리고, SSE가 가장 작은 결과를 골라요. k-means++는 처음 중심점을 서로 멀리 떨어지게 골라서 이런 일을 줄여 줘요. scikit-learn의 KMeans는 기본으로 k-means++로 시작하고, n_init으로 몇 번 돌려 볼지 정해요.

    지금 놀이터의 데이터와 K를 그대로 써요. 누를 때마다 다른 시작 위치로 돌려요.

    버튼을 눌러 봐요.

      (b) 엘보 방법으로 K 고르기

      K를 어떻게 정할까요? K마다 가장 좋은 SSE를 구해서 그래프로 그려 봐요.

      K마다 k-means++로 10번씩 돌려 가장 작은 SSE를 써요. 현재 놀이터의 데이터를 써요.

      버튼을 눌러 봐요.

      K가 커질수록 가장 좋은 SSE는 작아지거나 같아져요. K가 점 개수와 같으면 SSE는 0이에요. 그래서 SSE가 가장 작은 K를 고르면 안 돼요.

      그래프가 팔꿈치처럼 꺾이는 곳을 참고해요. 하지만 뚜렷하게 꺾이지 않을 때가 많아요. 결국 K는 쓰는 목적에 맞춰 정해요. 예를 들어 체육복이 3가지 치수로만 나온다면 K=3이에요.

      06

      K-평균이 어려워하는 데이터

      아래 버튼을 누르면 놀이터에 데이터가 불려 와요. [영역 색칠]을 켜고 돌려 보면 경계가 잘 보여요.

      초승달·고리 모양

      K-평균의 경계는 늘 곧은 선이에요. 두 중심점 사이의 수직이등분선이에요. 그래서 휘어진 모양은 제대로 나누지 못해요. 이런 데이터에는 DBSCAN 같은 다른 군집 방법을 써요.

      크기·흩어짐이 다른 무리

      중심점과의 거리만 보기 때문에, 큰 무리 가장자리의 점이 이웃한 작은 무리의 중심점에 더 가까우면 그쪽 무리가 돼요. 영역 색칠로 경계가 어디 있는지 살펴봐요.

      멀리 떨어진 점

      중심점은 평균이라서 멀리 떨어진 점에 끌려가요. 오른쪽 위의 점 3개 때문에 이웃한 무리의 중심점이 그쪽으로 조금 끌려가는 것을 볼 수 있어요. K를 바꿔 가며 어떻게 달라지는지 봐요.

      단위가 다른 특징

      키(cm)와 몸무게(kg)처럼 단위가 다른 값을 함께 쓰면, 숫자 폭이 큰 쪽이 거리를 좌우해요. 예를 들어 키를 mm로 적으면 160cm와 170cm의 차이는 100이 되어, 몸무게 20kg 차이(20)보다 훨씬 커 보여요. 그래서 K-평균을 쓰기 전에 범위를 맞추는 표준화를 먼저 해요.

      표준화한 값 = (값 − 평균) ÷ 표준편차

      07

      파이썬으로 확인하기

      방금 손으로 한 일을 코드로 해 봐요. 먼저 numpy로 직접 만들고, 다음에 scikit-learn을 써요.

      코드 A. numpy로 직접 만들기

      # K-평균을 numpy로 직접 만들어 보기 — ① 놓기 → ② 나누기 → ③ 옮기기 → ④ 되풀이
import numpy as np

# 손님 집 위치 12곳 (x, y)
X = np.array([[2, 3], [3, 4], [4, 2], [3, 3],
              [8, 8], [9, 7], [8, 9], [9, 9],
              [2, 8], [3, 9], [2, 9], [3, 8]], dtype=float)
K = 3

# ① 처음 중심점: 0번, 4번, 5번 점에서 시작해요
centers = X[[0, 4, 5]].copy()

for step in range(1, 21):
    # ② 나누기: 점마다 가장 가까운 중심점의 번호(0, 1, 2)
    dist = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)
    labels = dist.argmin(axis=1)
    print(f"반복 {step}: 무리 {labels.tolist()}")

    # ③ 옮기기: 무리마다 점들의 평균 위치 (점이 없는 무리는 그대로)
    new_centers = np.array([X[labels == k].mean(axis=0) if np.any(labels == k)
                            else centers[k] for k in range(K)])

    # ④ 중심점이 더 움직이지 않으면 끝
    if np.allclose(new_centers, centers):
        break
    centers = new_centers

sse = ((X - centers[labels]) ** 2).sum()   # 거리 제곱의 합
print("중심점:", centers.round(2).tolist())
print("거리 제곱의 합(SSE):", round(float(sse), 2))

반복 2: 무리 [0, 0, 0, 0, 2, 2, 1, 2, 0, 1, 1, 0]
반복 3: 무리 [0, 0, 0, 0, 2, 2, 2, 2, 1, 1, 1, 1]

      사이트 실습실에서 바로 실행

      실습실은 영상처리 실습실이지만 파이썬 코드를 그대로 돌릴 수 있어요.

      바꿔 보기

      • centers = X[[1, 2, 3]].copy()로 바꿔 봐요. 모두 왼쪽 아래 무리에서 시작해서, SSE가 79.21인 다른(더 나쁜) 결과가 나와요. 시작 위치가 중요해요.
      • K = 2로 바꾸고 centers = X[[0, 4]].copy()로 시작해 봐요. 무리가 어떻게 달라지는지 봐요.

      코드 B. scikit-learn으로 (코랩에서)

      import numpy as np
from sklearn.cluster import KMeans

X = np.array([[2, 3], [3, 4], [4, 2], [3, 3],
              [8, 8], [9, 7], [8, 9], [9, 9],
              [2, 8], [3, 9], [2, 9], [3, 8]], dtype=float)

km = KMeans(n_clusters=3, n_init=10, random_state=0)  # 10번 돌려 가장 좋은 결과
km.fit(X)

print("무리 번호:", km.labels_)
print("중심점:", km.cluster_centers_.round(2))
print("SSE(inertia_):", round(km.inertia_, 2))
print("새 손님 (5, 5)은", km.predict([[5, 5]])[0], "번 무리")

      정리

      • K-평균은 정답 없이 점을 K개 무리로 묶는 비지도 학습이에요.
      • ① 중심점 놓기 → ② 나누기 → ③ 옮기기 → ④ 바뀌는 점이 없을 때까지 되풀이, 이렇게 돌아가요.
      • 중심점은 무리 점들의 평균 위치예요. 꼭 데이터 점 중 하나일 필요는 없어요.
      • SSE는 작을수록 촘촘해요. 하지만 시작 위치에 따라 결과가 달라지므로 여러 번 돌려 SSE가 가장 작은 것을 골라요.
      • K는 사람이 정해요. 엘보 그래프를 참고하되 목적에 맞춰 정해요. 휘어진 모양이나 크기가 다른 무리는 어려워해요.

      이어서 데이터에서 스스로 규칙을 배우는 딥러닝 이야기로 가 봐요.

      탐구 과제 3개

      1. 같은 데이터, 같은 K에서 [중심점 직접 놓기]로 서로 다른 결과를 만들어 SSE를 비교해 봐요.
      2. 엘보 그래프를 그려 K를 정하고, 그렇게 정한 이유를 한 문장으로 써 봐요.
      3. 초승달 데이터에서 K-평균이 잘 안 되는 까닭을 “경계가 곧은 선”이라는 말을 써서 설명해 봐요.

      자주 하는 오해

      • “K-평균이 무리의 이름을 알아낸다” → 아니에요. 번호만 붙고, 뜻은 사람이 해석해요.
      • “중심점은 데이터 점 중 하나다” → 아니에요. 평균 위치예요. 데이터 점 중 하나를 중심으로 쓰는 방법은 K-메도이드예요.
      • “항상 최선의 답이 나온다” → 아니에요. 시작 위치에 따라 지역 최적해에서 멈출 수 있어요.
      • “K는 알고리즘이 정한다” → 아니에요. 사람이 정해 줘요.

      평가 포인트: ① 네 단계를 순서대로 말하고 평균·거리 계산을 할 수 있는가 ② 시작 위치에 따라 결과가 달라질 수 있음을 놀이터 결과로 설명하는가 ③ K를 고르는 근거(엘보와 목적)를 말하는가 ④ K-평균이 어려워하는 데이터의 예와 까닭을 말하는가
