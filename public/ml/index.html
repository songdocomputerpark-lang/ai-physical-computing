인공지능 원리 체험

공식을 외우기보다 직접 움직여 보며 인공지능이 배우는 원리를 익혀요. 설치할 것 없이 브라우저에서 모두 해 볼 수 있어요.

비지도 학습 · 약 45분

K-평균 알고리즘

정답 이름표 없이, 비슷한 데이터끼리 K개의 무리로 묶어요. 중심점을 놓고 옮기며 무리가 찾아지는 과정을 한 단계씩 지켜봐요.

K-평균 체험하기
지도 학습 · 약 50분

딥러닝

뉴런 하나의 계산부터 층을 쌓은 신경망까지, 오차를 줄이며 스스로 배우는 과정을 직접 조절하고 학습시켜 봐요.

딥러닝 체험하기

두 방법 한눈에 견주기

K-평균딥러닝(신경망)
학습 종류비지도 학습 — 정답 없이 데이터만여기서는 지도 학습 — 데이터와 정답
하는 일비슷한 것끼리 K개의 무리로 묶기새 데이터의 답(분류·예측)을 맞히기
사람이 정할 것무리 개수 K층 수, 뉴런 수, 학습률 등
배우며 바뀌는 것중심점의 위치가중치와 편향

두 방법 모두 기계학습이에요. 컴퓨터가 사람이 짜 준 규칙이 아니라 데이터에서 규칙을 찾아요. 영상 인식에 쓰이는 합성곱 신경망은 1-1-2 차시에서 이어서 볼 수 있어요.
